# Current Discoveries

New items discovered since the last newsletter.

- **`anthropic-workspace-id` API response header** — Every Claude API response now includes an `anthropic-workspace-id` header carrying the `wrkspc_`-prefixed ID of the workspace that the request's API key or access token resolved to (including the Default Workspace). Useful for routing, debugging, and audit logging in multi-workspace deployments. Added August 11, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Compliance API remote Cowork sessions endpoint** — As of August 3, 2026, the Compliance API returns transcripts for Cowork sessions started on claude.ai web or mobile (in beta for Claude Enterprise organizations). `GET /v1/compliance/apps/sessions/remote` lists sessions; `GET /v1/compliance/apps/sessions/remote/{session_id}/messages` returns one session's transcript. Uses the existing Compliance Access Key with `read:compliance_user_data` scope. Preceded the August 11 extension to local Claude Code sessions. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`code_execution_20260120` SDK support for REPL state persistence** — Python, TypeScript, Go, Java, Ruby, PHP, C#, and CLI SDKs now include support for the `code_execution_20260120` code execution tool, which adds REPL state persistence across cells and is the minimum required version for programmatic tool calling. Set the tool's `type` to `code_execution_20260120`; no beta header required. Available on Claude Fable 5, Mythos 5, Opus 4.5+, and Sonnet 4.5+. Added June 18, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
