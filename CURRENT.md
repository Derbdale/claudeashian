# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.269** — Released September 11, 2026. New features: `claude plugin eval` runs a plugin's eval suite against Claude Code and produces scored JSON and HTML reports; `/output-style [name]` lists and switches output styles across Remote Control, cloud, and headless sessions; `/focus` view shows just your prompt, one-line work summary, and Claude's response; agent map in VS Code shows all sub-agents with per-agent cards and Stop buttons; `bashEditDiffEnabled` setting shows file change diffs when Bash handles edits; `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` (1–256) raises concurrent workflow agent limits; `OTEL_METRICS_INCLUDE_REPOSITORY` tags OpenTelemetry metrics with VCS repository attributes. Key fixes: prompt cache stability (partial invalidation after output-token-limit cutoffs fixed, Fable 5.1 effort changes no longer bust cache); terminal key handling in kitty, rxvt-unicode, WezTerm; `!`-negated permission rules now scope correctly to their settings source; CMYK JPEG images no longer fail on attachment; plugin LSP servers (e.g. rust-analyzer) no longer left running after rejected shutdown. (Source: https://code.claude.com/docs/en/changelog)
- **Enterprise smart reports (beta)** — Launched September 10, 2026 for Claude Enterprise plans. Automatically analyses team usage, costs, friction points, and reusable skill patterns, surfacing actionable insights about how teams are using Claude without manual data extraction. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **`ant beta:sessions connect` for terminal session monitoring** — New `ant` CLI command (September 10, 2026) that connects a local terminal to a live Claude Managed Agents session for real-time monitoring and interaction, without needing a browser or the Claude Console. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Anthropic IPO timeline shifts to mid-October** — Reported September 5, 2026: Anthropic's S-1 prospectus is expected to go public in late September, with IPO marketing beginning in mid-October and a Nasdaq listing targeted just before the US midterm elections in November. The company has already raised $130 billion ahead of the offering. A wave of AI-driven IPOs is expected to accompany the listing. Bloomberg reported that market sentiment had shifted away from a September listing. (Source: https://www.cnbc.com/2026/09/05/anthropic-ipo-launch-shifts-toward-mid-october-reuters.html)
- **`/output-style` command** — List all available output styles or switch to a named one from the prompt bar; works in interactive sessions, Remote Control, cloud, and other headless sessions. Introduced in Claude Code v2.1.269 (September 11, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`/focus` command** — Minimal view showing just your prompt, a one-line work summary, and Claude's response — reduces visual clutter while Claude works. Introduced in Claude Code v2.1.269 (September 11, 2026). (Source: https://code.claude.com/docs/en/changelog)
