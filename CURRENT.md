# Current Discoveries

New items discovered since the last newsletter.

- **Streaming paragraphs render line-by-line** — Long paragraphs now stream to the terminal line-by-line instead of waiting for the first newline before displaying, reducing perceived latency on verbose responses (v2.1.191, June 24, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **~37% CPU reduction during streaming** — CPU usage during streaming responses reduced by approximately 37% through text-update coalescing at 100 ms intervals, improving performance on long outputs (v2.1.191, June 24, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Auto-retry for API connection drops mid-thinking** — Claude Code now automatically retries when the connection drops while Claude is in an extended thinking phase, instead of surfacing a "Connection closed while thinking" error (v2.1.191, June 24, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Trusted Devices for Remote Control Admins** — Team and Enterprise plan admins can now require device verification before team members can view or steer local Claude Code sessions remotely, preventing unauthorised access to live coding sessions (June 25, 2026). (Source: https://releasebot.io/updates/anthropic)
- **`autoMode.classifyAllShell` setting** — Routes all Bash/PowerShell commands through the auto-mode classifier rather than only arbitrary-code-execution patterns, giving auto mode broader visibility into shell activity (v2.1.193, June 25, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Live file path autocomplete in bash mode** — When using `!` to run shell commands, Claude Code now autocompletes file paths as you type (v2.1.193, June 25, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Automatic memory-pressure reaping for idle background shells** — Idle background shell commands are automatically reaped under memory pressure to prevent long-session memory bloat; disable with `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1` (v2.1.193, June 25, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`claude_code.assistant_response` OpenTelemetry log event** — New OTEL event containing Claude's response text for observability pipelines; redacted by default unless `OTEL_LOG_ASSISTANT_RESPONSES=1` is set. Deployments already logging user prompts via `OTEL_LOG_USER_PROMPTS` will automatically receive response logs on upgrade (v2.1.193, June 25, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **SpaceX acquires Cursor for $60B** — SpaceX entered a formal all-stock agreement on June 16, 2026 to acquire AI coding startup Cursor (Anysphere) for $60 billion — the largest VC-backed acquisition on record. Cursor had reached ~$4 billion in annualised revenue. The deal is expected to close Q3 2026 and extends SpaceX's xAI division to compete directly with Anthropic and OpenAI in AI coding tools. (Source: https://techcrunch.com/2026/06/16/spacex-to-acquire-cursor-for-60b-in-stock-days-after-blockbuster-ipo/)
- **Snowflake-Anthropic $200M expanded partnership** — Announced at Snowflake Summit 26 (June 2026), the multi-year $200M agreement makes Claude models available in Snowflake Cortex AI to 12,600+ global customers across AWS, GCP, and Azure. Claude achieves >90% accuracy on complex text-to-SQL in Snowflake's internal benchmarks, powering governed AI agents that query text, images, audio, and tabular data via SQL. (Source: https://www.anthropic.com/news/snowflake-anthropic-expanded-partnership)
- **`/rewind` command** — Resumes a conversation from a point before `/clear` was run, allowing you to recover context that would otherwise be lost (v2.1.191, June 2026). (Source: https://code.claude.com/docs/en/changelog)
