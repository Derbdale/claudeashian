# Current Discoveries

New items discovered since the last newsletter.

- **Claude memory expanded across Chat and Cowork with editable topics** — As of August 25, 2026, Claude's memory works seamlessly across Chat and Claude Cowork in the cloud. Users can view everything Claude remembers topic by topic and edit or delete any entry. New sensitive-topics controls let users choose whether Claude remembers health or belief-related information. Enabled by default for Free, Pro, and Max plans. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.245** — Released August 25, 2026. Fixes a critical startup crash on Linux distributions shipping glibc 2.44 (Arch Linux, CachyOS, Fedora Rawhide). (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.246** — Released August 25–26, 2026. Adds an Auto mode tab to `/permissions` for viewing and editing auto mode classifier rules; adds a turn completion timestamp to end-of-turn lines. Key fixes: severe transcript slowdown with very long single lines (e.g. base64 strings); erratic fullscreen scrolling; background sessions failing to open with "EACCES" errors; MCP tool arguments being sent as JSON strings instead of real types; auto mode safety-check deadline scaled on very large sessions; telemetry requests incorrectly carrying third-party gateway API keys. Also improves `/cd` so new directory settings, hooks, MCP servers, skills, and agents take effect immediately without restart. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic IPO filing to list "AI backlash" as risk factor** — Reported August 21, 2026 (CNBC). Anthropic's forthcoming public prospectus will explicitly flag public resistance to AI and data center construction as a material business risk. A Gallup survey found 7 in 10 Americans oppose AI data centers in their area; growing opposition could constrain capacity expansion — closely tied to revenue growth. Anthropic's most recent private valuation was $965 billion; secondary markets priced it at $1.05–1.15 trillion ahead of the listing. (Source: https://www.cnbc.com/2026/08/21/-anthropic-ipo-filing-will-show-ai-backlash-as-risk-sources-say.html)
