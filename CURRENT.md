# Current Discoveries

New items discovered since the last newsletter.

## Features & Model Updates

- **Claude Haiku 5.5 launched** — Released October 7, 2026 as Anthropic's fastest and most capable small model, targeted at summarization, subagents, and browser-use tasks. (Source: https://www.orcarouter.ai/blog/claude-news-what-anthropic-shipped-in-october-2026)
- **Fable 5.2 and Mythos 5.2 launched** — Released November 9, 2026. Fable 5.2 is generally available; Mythos 5.2 restricted to vetted organizations via Life Sciences and Cyber Verification Programs. Both are up to 30% faster than 5.1 versions. Fable 5.2 input price dropped 20% (from $10 to $8/MTok; output $50→$40/MTok); Fast mode available at 2× standard pricing. Fable 5.2 supports zero data retention through Enterprise Frontier Safeguards (private beta). Mythos 5.2 roughly doubled Mozilla's vulnerability discovery rate vs 5.1. (Source: https://www.siliconreport.com/anthropic-releases-mythos-5-2-and-fable-5-2)
- **Fast mode on Claude Opus 4.8 deprecated** — Deprecated in v2.1.316 (October 2026); `speed: "fast"` on Opus 4.8 will return an error after November 30, 2026 with no silent fallback. Migrate to Opus 5 or Fable 5.2 to continue using fast mode. (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
- **`ultrathink` runs at xhigh effort on 5.x generation models** — The `ultrathink` keyword triggers xhigh effort in both the interactive terminal and VS Code on Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1+. Extend with `CLAUDE_CODE_SUBAGENT_EFFORT` to set a default effort for all subagents; set `CLAUDE_CODE_DISABLE_ULTRATHINK=1` to turn off the keyword entirely (v2.1.311/v2.1.316). (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
- **`permissions.blockWritesOutsideWorkingDirectories` setting** — New security setting that restricts the Write, Edit, and NotebookEdit tools to declared working directories only, preventing accidental or malicious out-of-scope file writes (v2.1.314). (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
- **Sign-in expiry 10-day warning** — Claude Code v2.1.318 adds `loginExpiresAt` to `claude auth status` output and prints a stderr warning starting 10 days before the credential expires, preventing silent auth failures in long-running pipelines. Also available as `credential_expires_at` in `claude -p` JSON output. (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
- **Cloud sessions start without a repository** — Anthropic-hosted cloud Claude Code sessions can now initialize without a git repository present (v2.1.318), expanding cloud session use beyond coding workflows. (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)

## News & Announcements

- **Claude Docs, Slides, and Design generally available on all plans** — Announced October 8, 2026. Docs, Slides, and Design capabilities are now generally available on all Claude plans, including Free. Claude Dashboards and Claude Motion simultaneously entered public beta. (Source: https://www.orcarouter.ai/blog/claude-news-what-anthropic-shipped-in-october-2026)
- **Code Review generally available on Team and Enterprise** — Announced October 15, 2026. Claude Code Review — inline PR comments, CI-triggered review, and the `/code-review` command — is now generally available for Team and Enterprise plan users. Pro and Max access is in limited beta. (Source: https://www.orcarouter.ai/blog/claude-news-what-anthropic-shipped-in-october-2026)
- **Claude Duet research preview launched** — Announced October 21, 2026. Claude Duet is a collaborative research feature pairing two specialized Claude agents (one focused on reasoning, one on retrieval) working in parallel on a single task. Available to Pro and Max subscribers in the US via a waitlist. (Source: https://www.orcarouter.ai/blog/claude-news-what-anthropic-shipped-in-october-2026)
- **Agent Skills standard donated to Agentic AI Foundation** — Announced October 22, 2026. Anthropic donated the Agent Skills specification to the Agentic AI Foundation, a new working group under the Linux Foundation. Founding members include AWS, Google, Microsoft, and Salesforce. The donation aims to standardize how skills and slash commands are packaged and distributed across AI agent ecosystems. (Source: https://www.orcarouter.ai/blog/claude-news-what-anthropic-shipped-in-october-2026)
- **Fable 5.2 and Mythos 5.2 launched** — Released November 9, 2026. Fable 5.2 is generally available; Mythos 5.2 restricted to vetted organizations via Life Sciences and Cyber Verification Programs. Both models are up to 30% faster than their 5.1 predecessors. Fable 5.2 input pricing dropped 20% ($10→$8/MTok; output $50→$40/MTok). Fable 5.2 supports zero data retention through Enterprise Frontier Safeguards (private beta). Mythos 5.2 roughly doubled Mozilla's vulnerability discovery rate versus Mythos 5.1. (Source: https://www.siliconreport.com/anthropic-releases-mythos-5-2-and-fable-5-2)

## Integrations & API

- **Monitor tool available on Bedrock, Vertex, and Foundry** — The Monitor tool (for streaming background process output as turn notifications) is now supported on Amazon Bedrock, Google Vertex AI, and Anthropic Foundry in addition to the direct Claude API (v2.1.310). (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
- **`pooled_budget` gateway feature for shared group budgets** — New `pooled_budget` parameter added to gateway configuration in v2.1.316, enabling a single spend budget to be shared across a defined group of sessions or users. Useful for team-level cost controls without per-session limits. (Source: https://claude-world.com/articles/claude-code-november-2026-whats-new/)
