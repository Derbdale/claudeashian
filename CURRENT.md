# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.270** — Released September 12, 2026. Fixes a regression introduced in v2.1.269 where read-only git commands in Bash were unexpectedly asking for permission in long-running sessions, restoring expected automatic approval for safe git read operations. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude autonomously designs protein binders in wet-lab-validated study** — Published August 18, 2026. Claude (Mythos preview) autonomously designed protein binders against 14 of 15 target proteins with minimal human oversight, yielding 354 confirmed binders from 1,320 designs. Hit rates of 22–35% (single-target sequential) are 2–3× the industry benchmark of 10–15%. On the RBX1 target, Claude hit a 40% success rate against a 3.7% average in Adaptyv Bio's open competition. Claude orchestrated specialised protein-design tools end-to-end, completing work that typically takes weeks of expert effort. (Source: https://www.anthropic.com/research/Claude-accelerates-protein-design)
- **Auto permission policies for Managed Agents** — Released September 10, 2026. Managed Agents can now automatically evaluate each agent or MCP tool call and either run it, deny it, or pause for human approval, replacing the previous all-or-nothing approval model. New `agent.tool_use` and `agent.mcp_tool_use` webhook events include an `evaluation` field recording how each call was handled. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
