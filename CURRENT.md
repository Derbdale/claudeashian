# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.251** — Released August 28, 2026. New `PreModelSwitch` and `PostModelSwitch` hook events let hooks block, confirm, or annotate model switches. Live streaming of foreground subagent tool calls and results to Remote Control clients. Spend limit bar added to `/usage` and `rate_limits.spend_limit` status line field; per-session prompt-cache stats line in `/cost` showing hit ratio, misses, tokens re-cached, and warm/cold state. Adds `attach`, `logs`, `stop`, `respawn`, and `rm` to `claude --help`. Default model for seat-based Enterprise subscriptions changed to Opus 5. Native binary ~5 MB smaller. Security: fixes path traversal via symlinks in file tools (Read/Write/Edit), plugin commands pointing outside their directory, Grep/Glob not applying deny rules to symlinked search paths, Workflow tool reading `scriptPath` outside approved location pre-permission-check, and project settings bypassing OTLP collector pinning. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic wins federal court battle over Pentagon's supply-chain risk label** — A California federal judge ruled on August 28, 2026 that the Pentagon's designation of Anthropic as a supply-chain risk constituted "unlawful retaliation in violation of the First Amendment" and denied due process under the Fifth Amendment. The dispute arose when Anthropic refused a Pentagon contract that conflicted with the company's restrictions on use in fully autonomous lethal weapons and domestic mass surveillance. Judge Rita Lin ordered the designation removed. Anthropic's second related lawsuit before a D.C. appellate court remains pending. (Source: https://techcrunch.com/2026/08/28/anthropic-gets-its-first-court-win-over-the-pentagons-supply-chain-risk-label/)
- **Claude Code 50% weekly limit boost extended through August 31** — Anthropic extended the temporary 50% weekly usage limit increase for Claude Code through August 31, 2026 at 11:59 PM PT — the third such extension since the promotion launched in May 2026. Applies to Pro, Max, Team, and seat-based Enterprise plans across CLI, IDE extensions, desktop, and web. Free plans and consumption-based Enterprise seats are excluded. Anthropic stated it hopes to make the boost permanent once capacity allows. (Source: https://pasqualepillitteri.it/en/news/11913/claude-code-limits-extended-max-20x)
