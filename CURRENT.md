# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.332** — Released November 25, 2026. Skills from MCP servers now appear as `server:skill` entries in the slash menu (beta); a new PreSkillShellCommand hook fires before a skill's inline shell commands run and can refuse them. Claude Sonnet 5.5 set as the default model on Microsoft Foundry (deploy with `claude-sonnet-5-5` or set `ANTHROPIC_DEFAULT_SONNET_MODEL`). A new Cyber Verification Program tier expands vetted access to Mythos 5.2 for eligible security research organizations. (Source: https://code.claude.com/docs/en/changelog)
- **Skills over MCP public beta** — MCP servers can now deliver packaged workflow instructions ("skills") alongside their tools; skills from connected servers appear as `server:skill` entries in the Claude and Claude Code slash menu. Part of the broader Agent Skills open standard (now under the Agentic AI Foundation). Available in Claude Code v2.1.332+, launched November 25, 2026. (Source: https://code.claude.com/docs/en/changelog)
- **SDK error codes** — Each API error now includes a machine-readable `error_code` string alongside the existing error type and message, with its own exception class in the SDK. Update to the latest SDK to use typed error codes in error-handling logic. Released November 4, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **IP allowlist for Claude API (beta)** — Restrict Claude API access by IPv4 address, IPv6 address, or CIDR range; up to 1,000 entries per organization. Configure under Organization settings in the Claude Console. Available from November 5, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Opus 4.5 deprecated** — `claude-opus-4-5` announced for retirement on the Claude API on January 22, 2027. Anthropic recommends migrating to Claude Opus 5.5. Announced November 23, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`claude mcp add-json <name> -`** — Reads MCP server JSON configuration from stdin rather than from a command-line flag, keeping tokens and secrets off the shell history and process list. Not available inside a running Claude Code session. Added in v2.1.327 (November 17, 2026). (Source: https://code.claude.com/docs/en/changelog)
