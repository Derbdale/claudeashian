# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.207** — Released July 11, 2026. Auto mode now defaults to enabled on Bedrock, Vertex AI, and Foundry without the `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in flag; disable via `disableAutoMode` in settings. Fixed terminal freezing and keystroke lag when streaming responses containing very long lists, tables, paragraphs, or code blocks. Fixed auto-updater overwriting custom launcher scripts at `~/.local/bin/claude`. Fixed remote managed settings being permanently recorded as consented without showing the security consent dialog. Fixed spurious prompt-injection warnings triggered by benign system-generated conversation updates. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **"The Making of Claude Code" published** — Anthropic published a long-form feature on July 6, 2026 tracing how Claude Code evolved from an internal CLI experiment into Anthropic's flagship coding agent. Written with contributions from researchers, engineers, and early users who built it. (Source: https://www.anthropic.com/features/making-of-claude-code)
- **Ben Bernanke appointed to Anthropic's Long-Term Benefit Trust** — Former Federal Reserve Chair (2006–2014) and 2022 Nobel laureate in economics joined Anthropic's LTBT on July 9, 2026. The trust holds no equity, receives no profits, and holds authority to appoint Anthropic board members while advising on AI risks and societal impacts. Bernanke's primary focus will be economic analysis and tracking AI's broader macroeconomic effects. He joins trustees Neil Buddy Shah, Richard Fontaine, and Mariano-Florentino Cuéllar. (Source: https://www.anthropic.com/news/ben-bernanke)
