# Current Discoveries

New items discovered since the last newsletter.

- **All Claude.ai connectors auto-available in Claude Code and Artifacts** — As of August 5, 2026, any connector configured for Claude.ai (Gmail, Calendar, Slack, and all others) is automatically available inside Claude Code sessions and inside published Artifacts without any additional setup. (Source: MCP integrations guide 2026)
- **Cloudflare MCP for Durable Objects and Email Routing** — Cloudflare released an MCP integration (in beta) covering Durable Objects and Email Routing, enabling Claude to interact with Cloudflare's edge infrastructure directly via MCP. (Source: Claude MCP server integrations 2026)
- **"Claude as critic" beats "Claude as author"** — Sharing your own draft solution and asking Claude to improve it often produces better results than asking Claude to generate from scratch. Claude's analytical and critique abilities are highly calibrated; use them to elevate your own thinking rather than bypassing it entirely. (Source: Claude Code workflows guide 2026)
