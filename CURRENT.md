# Current Discoveries

New items discovered since the last newsletter.

- **Claude Certification Program expands to four role-based credentials** — Anthropic launched four certifications via Pearson VUE (proctored, identity-verified): Claude Certified Associate: Foundations (broad practical use), Claude Certified Developer: Foundations (API and agent development), Claude Certified Architect: Foundations, and Claude Certified Architect: Professional (integration architecture and governance). Passing candidates receive digital badges via Credly by Pearson. Certified practitioner counts factor into Claude Partner Network standing (Global Premier tier requires 1,000 certified practitioners). Announced July 23, 2026. (Source: https://claude.com/blog/four-role-based-claude-certifications)
- **New context engineering rules for Claude 5-generation models** — Anthropic's July 2026 guidance on adapting context engineering for Sonnet 5/Opus 5: (1) Replace explicit guardrails with judgment prompts ("match surrounding code style" vs "never write docstrings"); (2) Remove tool usage examples — well-designed parameters and clear enum options guide behavior better; (3) Use progressive disclosure — load detailed guidance in skills activated on demand, not front-loaded in system prompts; (4) Eliminate redundant instructions across system prompts and tool descriptions; (5) Let Claude use auto-memory rather than requiring manual CLAUDE.md updates; (6) Reference actual code, test suites, and HTML mockups instead of markdown descriptions — code gives higher-fidelity instruction. Anthropic removed over 80% of Claude Code's system prompt for advanced models. (Source: https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)
