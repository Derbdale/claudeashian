# Current Discoveries

New items discovered since the last newsletter.
- **Sub-agents can spawn nested sub-agents up to 5 levels deep** — In v2.1.172 (June 10, 2026), Claude Code sub-agents gained the ability to recursively spawn their own sub-agents, up to 5 levels of nesting. Enables more sophisticated multi-agent hierarchies without manual orchestration. (Source: https://github.com/anthropics/claude-code/releases)
- **Fable 5 / Mythos 5: adaptive thinking only, `thinking: disabled` not supported** — On Claude Fable 5 and Claude Mythos 5, adaptive thinking is the sole thinking mode. Setting `thinking: {"type": "disabled"}` returns a 400 error, as do manual extended thinking budgets and assistant prefill. Pass thinking blocks back unchanged in multi-turn conversations; set `display: "summarized"` to receive readable thinking summaries. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents: update MCP server and tool configs on active sessions** — Claude Managed Agents now allows updating the agent's MCP server and tool configurations on an already-running session, enabling dynamic reconfiguration without restarting the agent (May 19, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents: large tool outputs auto-spilled to file** — Tool outputs from `agent_toolset` and MCP tools exceeding 100K tokens are now automatically written to a file in the sandbox; the model receives a truncated preview with the file path and can read the full content from there, preventing context window overflow (May 19, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Amazon Bedrock reads AWS region from `~/.aws` config** — In Claude Code v2.1.172, Amazon Bedrock integration now reads the AWS region from `~/.aws/config` when the `AWS_REGION` environment variable isn't set, removing the need to set the env var manually for users with a standard AWS CLI configuration. (Source: https://github.com/anthropics/claude-code/releases)
- **Claude Fable 5 free on subscription plans until June 22** — From June 9 through June 22, 2026, Claude Fable 5 is included at no extra cost on Pro, Max, Team, and seat-based Enterprise plans. On June 23, it is removed from plan limits; continued access requires usage credits billed at API rates ($10/$50 per MTok). Anthropic aims to restore Fable 5 as a standard part of subscription plans once capacity allows. (Source: https://www.ghacks.net/2026/06/10/anthropic-releases-claude-fable-5-to-pro-max-and-enterprise-users-free-until-june-22/)
- **Search bar in `/plugin` for browsing marketplace plugins** — The `/plugin` command now includes a search bar to filter and find plugins in the marketplace without scrolling through the full list (v2.1.172). (Source: https://github.com/anthropics/claude-code/releases)
