# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.222** — Released August 5, 2026. Security: fixed worktree-isolated sessions and subagents being able to run destructive git commands against the main checkout; fixed PreToolUse auto-allow hooks bypassing tool restrictions in background agent tasks; `SendMessage` calls now evaluated by the permission classifier before dispatch. Removes the ultraplan feature. Fixes: startup connectivity check hanging behind HTTPS proxy; "Connection closed mid-response" errors on completed responses; stream idle timeout firing on custom gateway endpoints despite keep-alive pings; `/usage` overattributing usage to MCP servers; sessions not linking to pull requests created after a branch push via GitHub REST API; org-restricted model aliases dropping to parent model instead of stepping down correctly; `SendMessage` rejecting long summaries (now truncates). Also improves `/diff` to use raw git blob content, ignoring workspace diff drivers. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Tino Cuéllar joins Anthropic as Chief Global Affairs Officer** — Announced August 4, 2026. Mariano-Florentino (Tino) Cuéllar joins Anthropic as its first-ever Chief Global Affairs Officer, a newly created role leading policy, strategic international engagement, and government relationships worldwide. He steps down from his seat on Anthropic's Long-Term Benefit Trust to take the employee role, reporting to President Daniela Amodei. Cuéllar was previously President of the Carnegie Endowment for International Peace, a Justice of the Supreme Court of California, and director of Stanford's Freeman Spogli Institute for International Studies; he also served in three presidential administrations. (Source: https://www.anthropic.com/news/tino-cuellar)
