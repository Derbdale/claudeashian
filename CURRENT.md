# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.260** — Released September 4, 2026. Adds a fullscreen diff panel accessible via the `/diff` command; improved prompt caching diagnostics and enhanced auto-compact for 1M-context models; expanded headless and desktop command support. Multiple bug fixes across permissions, sessions, plugins, and VS Code integration. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude Code v2.1.261** — Released September 4-5, 2026. New `bashOutputMaxChars` and `taskOutputMaxChars` settings raise the inline command output limit to 128K characters before file-saving kicks in. New `--append-subagent-system-prompt-file` flag feeds large system prompts to subagents from a file. Organisation policy loading status added to `/status` and `claude doctor` output. VS Code gains a custom output style builder walkthrough, MCP server Add/Remove actions in dialogs, and "Archive session" functionality (replacing "Delete session"). Key fixes: characters occasionally landing out of order during fast typing; Remote Control permission mode display staleness; session resumption losing hook output and parallel tool call context; TLS-inspecting proxy failures on Bedrock setup. (Source: https://code.claude.com/docs/en/changelog)
- **`/skill-doctor` command** — Diagnoses unused skills and reports their per-skill context cost, helping identify bloat in your skill directory that consumes tokens on every turn without contributing to active tasks (v2.1.261, September 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic public S-1 prospectus planned for after Labor Day; IPO targets October 2026 Nasdaq listing** — Reported September 3, 2026. Anthropic is planning to publicly release its IPO prospectus after Labor Day (September 2, 2026), targeting a Nasdaq listing in October 2026. Goldman Sachs, JPMorgan, and Morgan Stanley are leading an offering expected to raise $60+ billion at a target valuation of up to $2 trillion. New financial disclosures accompanying pre-IPO investor meetings: Anthropic posted its first-ever operating profit ($559 million) in Q2 2026 on $10.9 billion in quarterly revenue, and its annualised revenue run-rate crossed $65 billion by the end of July 2026 — up from $47 billion in May. (Source: https://www.fool.com/investing/2026/09/03/anthropic-planning-unveil-ipo-details-labor-day/)
