# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.285** — Released September 29, 2026. New `CLAUDE_CODE_DISABLE_WEB_FETCH` env var disables the WebFetch tool entirely for restricted environments. New `claude --desktop` command opens the Claude Code Desktop app on the current directory, or on a specific session with `--continue`/`--resume`. New `claude plugin configure` and `claude plugin install --config` allow a bundled `.mcpb` MCP server's settings to be configured at install time. New `allowedProviders` managed setting restricts which API providers a machine may use (Anthropic API, custom endpoint, Bedrock, Mantle, Vertex AI, Foundry, Claude Platform on AWS, or Cloud gateway). (Source: https://ccleaks.com/news/claude-code-2-1-285-sep-2026)
- **Anthropic service outage on September 29, 2026** — A partial outage affecting claude.ai, Claude Code, Claude Cowork, and the Claude API opened at approximately 14:21 UTC on September 29, 2026. Users experienced failed requests, conversation errors, and sign-in failures. Anthropic applied a mitigation by 14:41 UTC; all services were fully restored by approximately 14:59 UTC, making the total disruption roughly 38 minutes. (Source: https://www.unite.ai/anthropic-reports-service-disruption-across-claude-ai-code-cowork-and-api/)
