# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.275 and v2.1.276** — Released September 17–18, 2026. v2.1.275 highlights: `Ctrl+Enter` send-now key interrupts the current turn and immediately sends all queued messages; skills and plugins enabled on claude.ai now sync to terminal sessions (opt out with `syncClaudeAiSkills: false` / `syncClaudeAiPlugins: false`); artifact watch limit per session raised from 5 to 10; VS Code gains agent map with per-agent cards, a Hooks dialog, and a Permission rules dialog. Dozens of bug fixes across memory/caching, file permission checks, session resumption, MCP, Remote Control, and VS Code. v2.1.276 (September 18) single fix: 400 errors when `ANTHROPIC_BASE_URL` points at a proxy or gateway, a regression introduced in v2.1.275. (Source: https://code.claude.com/docs/en/changelog)
- **Claude leads 26% of Anthropic's model R&D; new AI-pace transparency metrics proposed** — Disclosed September 17–18, 2026. Claude now autonomously leads 26% of Anthropic's model research and development (up from ~0% in February 2026), completing most tasks end-to-end from a high-level prompt under human supervision. Approximately 30,000 AI agents were concurrently running R&D work as of August. Anthropic simultaneously published new transparency metrics calling for industry-wide reporting on how much AI contributes to its own development, framing it as a prerequisite for detecting when recursive self-improvement is occurring. (Source: https://www.bloomberg.com/news/articles/2026-09-17/anthropic-says-claude-drives-26-of-its-research-and-development)
- **Life Sciences Verification Program launched** — Beta program announced September 17, 2026, granting verified life science organizations access to Claude Mythos, Opus, and Sonnet under more permissive biology safeguards. Designed to unblock drug discovery, research biology, clinical development, and manufacturing tasks currently restricted in generally available models. Initially open to teams and institutions; individual Pro/Max plan access planned. Enforcement shifts from real-time request blocking to offline behavioral-pattern monitoring; carries a 30-day data retention requirement, strictly compartmentalized and excluded from model training. (Source: https://www.anthropic.com/news/life-sciences-verification-program)
- **`Ctrl+Enter` send-now key** — Introduced in Claude Code v2.1.275 (September 17, 2026). Press `Ctrl+Enter` (or `Ctrl+X Ctrl+S`) to interrupt the current model turn and immediately send all messages queued in the prompt bar; sent and queued messages display in grey until the model receives them. Useful for redirecting Claude mid-response without waiting for it to finish. (Source: https://code.claude.com/docs/en/changelog)
