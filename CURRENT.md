# Current Discoveries

New items discovered since the last newsletter.

- **MCP 2026-07-28 specification release** — The Model Context Protocol's 2026-07-28 revision is a major breaking update that shifts MCP from a bidirectional stateful protocol to a stateless request/response model, enabling servers to deploy on serverless and edge infrastructure. Key changes: OAuth 2.0/OIDC authorization alignment for enterprise IdPs; routing metadata now mirrored in HTTP headers (not just the JSON-RPC body) so network infrastructure can route without inspecting payloads; new versioned extensions framework debuts MCP Apps (JavaScript-based embedded UI) and Tasks (long-running operation management); three features removed — Sampling (servers requesting model completions), Roots (client file-system hints), and Logging (replaced by stderr/stdio/OpenTelemetry). Both client and server must update to maintain interoperability. (Source: https://www.theregister.com/devops/2026/07/23/model-context-protocol-prepares-to-break-with-its-stateful-past/5276722)
- **MCP surpasses 400M monthly SDK downloads** — The Model Context Protocol exceeded 400M monthly SDK installs by July 2026, a 4× increase year-over-year since Anthropic donated MCP to the Linux Foundation's Agentic AI Foundation in December 2025. Over 950 MCP servers are now listed in Claude's official connectors directory, used by millions of developers daily. MCP is now widely regarded as the industry standard for connecting AI agents to external tools and applications. (Source: https://releasebot.io/updates/anthropic)
