# Current Discoveries

New items discovered since the last newsletter.

- **Refreshed Claude Mobile design and computer use beta** — Rolling out from November 20, 2026. A redesigned Claude for iOS mobile app (requires iOS 26 or later) is launching gradually. Computer use is now in beta for Team and Enterprise plans across desktop, web, and mobile, rolling out to organisations gradually. (Source: https://releasebot.io/updates/anthropic/claude)
- **Enterprise Frontier Safeguards (EFS) moves to public beta** — Announced November 23, 2026. EFS advances from private beta (available as an opt-in with Fable 5.2 from November 9) to public beta. Automated misuse monitoring runs across requests while customer data stays in customer-controlled storage under zero data retention. Available on Claude Platform, AWS, Amazon Bedrock, and Google Cloud (Microsoft Foundry coming soon); eligible enterprise customers are notified. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.331** — Released November 23, 2026. Code Mode is now available in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. `claude doctor` gains an API connectivity check. Plugin manifests accept `optionalDependencies`. Fixes MCP tool calls hanging for up to 30 minutes on some malformed server replies. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Ship launched** — Announced November 23, 2026; rolling out to Claude Team and Enterprise plan customers for GitHub repositories. A beta suite of three AI agents that automate code review and PR management: Code Review (GA, reviews proposed changes and flags issues), PR Steward (beta, handles failing CI checks, merge conflicts, and review feedback after each push), and Claude Approvals (beta, applies a team-written natural-language policy file in the repository to decide whether to approve PRs). Teams control review depth (Quick, Standard, or Deep) and which changes escalate to humans. Anthropic recommends starting in observe-only mode with a single repository and a monthly spend limit. (Source: https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)
- **Claude VP≠VNP proof claim posted (unverified)** — Around November 23, 2026, Anthropic posted a GitHub repository crediting "Claude (Anthropic)" as sole author of a claimed proof of Valiant's VP≠VNP conjecture "over every field," accompanied by a Lean 4 formalization. The claim specifically proves a lower bound for the Hamiltonian cycle polynomial and the permanent (outside characteristic 2) and "does not settle P vs NP." Status: unverified by humans — no human mathematician has checked the proof. Lean verifies the formal structure, but no machine check confirms the Lean statement matches the claimed result. The repository is marked "not accepting contributions." (Source: https://casrai.org/news/anthropic-claude-authored-vp-vnp-proof-unverified-lean-2026)
