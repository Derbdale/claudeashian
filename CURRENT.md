# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.187** — Released June 24, 2026. New `sandbox.credentials` setting blocks sandboxed commands from reading credential files; org-configured model restrictions surface in the model picker with a "restricted by your organisation's settings" message; `/btw` gains arrow-key navigation to review previous answers; `/plugin` redesigned to surface unused plugins for cleanup; remote MCP tool calls now auto-abort after 5 minutes instead of hanging indefinitely; structured output tool calls can no longer loop infinitely after a successful call; `--resume` fixed for "No conversation found" errors; Korean/CJK text corruption in terminal paste events resolved. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Fable 5 model ID `[1m]` suffix auto-stripped** — Claude Code v2.1.173 (June 24, 2026) automatically normalises Fable 5 model names by stripping the `[1m]` suffix before sending requests to the API, resolving 400 errors that appeared when the suffix was passed verbatim. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude Tag launched on Slack** — Anthropic's Slack-native AI teammate, launched June 23, 2026 in beta for Enterprise and Team plans. Teams tag @Claude in channels to delegate tasks; one Claude instance per channel builds shared context over time, works asynchronously, and can schedule follow-up work. Scoped per channel with admin token controls and separate Claude identities per department. Existing Claude Slack integration retires August 3, 2026. Internally, 65% of Anthropic's product team code is created using their own version. (Source: https://www.anthropic.com/news/introducing-claude-tag)
- **Anthropic accuses Alibaba of largest known distillation attack on Claude** — In a June 24, 2026 letter to the US Senate Banking Committee, Anthropic accused Alibaba-linked operators of running 28.8 million exchanges using ~25,000 fraudulent accounts between April 22 and June 5, 2026, targeting Claude's software engineering and agentic reasoning capabilities via model distillation — "the largest known distillation attack" on Anthropic to date. Anthropic had previously reported three similar industrial-scale campaigns from DeepSeek, Moonshot, and MiniMax in February 2026. (Source: https://www.cnbc.com/2026/06/24/anthropic-alibaba-distillation-campaign.html)
- **Anthropic ID verification policy effective July 8, 2026** — Updated privacy policy allows collection of government-issued ID and biometric data (facial images, geometry templates) via Persona Identities. Widely interpreted as the compliance mechanism for a US-only Fable 5 restoration path under the June 12 export control directive. As of June 25, Fable 5 remains suspended worldwide; Anthropic's international MD Chris Ciauri indicated restoration "in the coming days" at a Seoul press conference on June 17. (Source: https://www.cio.com/article/4185510/anthropics-new-privacy-policy-offers-us-consumers-a-way-around-fable-ban.html)
