# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.268** — Released September 10, 2026. New features: gateway pricing parity (signed-in clients receive managed rates matching the spend meter); startup warnings for empty access control lists and public address access detection; `--remove-session-state` flag for self-hosted runner session directory cleanup; `--json` output and enhanced details for plugin commands (install, uninstall, update, enable, disable); browser-tab icons for published artifacts; `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` env var to configure WebFetch timeout (default 300 seconds). Key fixes: HTTP 400 errors on third-party Anthropic-compatible endpoints since v2.1.265 fixed; WebFetch indefinitely hanging resolved; high CPU from busy loops in idle sessions; permission rules on symlinked directories; MCP server OAuth sign-in failures; prompt caching breaking for SDK sessions using `excludeDynamicSections`; stale model-access denials; incorrect consent prompts on 429 errors for Fable models. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic Threat Intelligence Report September 2026** — Published September 10, 2026. Covers disrupted Claude misuse from December 2025 through August 2026 across seven categories: cyber operations, influence operations, surveillance, scams and fraud, biological weapons misuse, conventional weapons development, and model distillation. Key incidents: Russian espionage cluster GTG-20006 ran AI-assisted operations against Ukrainian, European, and diplomatic targets; a Chinese-speaking group in Changsha, Hunan targeted approximately 50 organisations. Biological misuse: scientists in China and Russia sought Claude's help with research supportive of bioweapons development, including one case of gain-of-function research on chikungunya virus at a military institute. Conventional weapons: requests for software for autonomous firearms, missile guidance, and armed drone design spanning China, Russia, and Yemen. A Yemeni cell test-fired a guided rocket and returned to Claude to analyse why it failed. Distillation: Moonshot and DeepSeek allegedly routed live customer conversations through Claude to use responses as training data. (Source: https://www.anthropic.com/news/threat-intelligence-september-2026)
