# Current Discoveries

New items discovered since the last newsletter.
- **Claude Dreaming (Managed Agents) adds Opus 5 support** — As of August 1, 2026, the Claude Dreaming research preview supports Claude Opus 5 in addition to previously supported Fable 5, Sonnet 5, and Opus 4.8. See the Managed Agents dreams documentation for the full supported-models list. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Code v2.1.221** — Released August 4, 2026. New features: Focus view — a VS Code chat-menu toggle (Ctrl+Alt+F or "Claude Code: Toggle Focus view") that hides tool activity behind an expandable per-turn summary with a live running-tool indicator; sandbox credential masking (`mode: "mask"` for Linux/WSL) where sandboxed commands read a sentinel copy while the proxy substitutes the real value on egress; plugin name validation warnings in `claude plugin validate`. Key improvements: auto mode permission checks for parallel tool calls are now cache-efficient, cutting prompt-cache costs; Stats panel shows cache token breakdown by input, output, cache read, and cache write; background sessions commit, push, and follow CLAUDE.md git instructions; `/plugin install` refreshes stale marketplace catalog before reporting not found; plugins activate immediately when safe without needing `/reload-plugins`; `/fork` now creates a new worktree instead of working in the original session's checkout. Security fixes: Bash permission-check bypass in zsh `[[ ]]` regex conditionals; PowerShell permission checks with quote-containing paths; WebSearch 400 errors at xhigh/max effort with thinking disabled; sandboxed large upload TLS errors through sandbox proxy. (Source: https://code.claude.com/docs/en/changelog)
- **$15 billion Texas data center financing for Anthropic** — Reported July 30, 2026: Morgan Stanley is leading a consortium of banks in talks to arrange $15 billion in debt (a $14 billion bridge loan plus a revolving credit facility) for Nexus Data Centers to build a campus in Hubbard, Texas, dedicated to Anthropic. Google has agreed to guarantee billions of dollars of Anthropic's lease and power-payment obligations, and would receive an approximately 20% equity stake in the project. The campus includes an on-site natural-gas-fired power plant capable of producing 1.6 gigawatts of electricity. The deal represents one of the largest single AI infrastructure financing packages to date. (Source: https://www.bloomberg.com/news/articles/2026-07-30/banks-line-up-15-billion-of-debt-for-anthropic-with-google-aid)
- **`prompt-audit` subcommand in claude-api skill** — New subcommand (v2.1.221, August 4, 2026) for auditing prompts and tool descriptions for patterns written for older models, helping identify instructions that are no longer necessary or may degrade performance on Claude 5-generation models. (Source: https://code.claude.com/docs/en/changelog)
