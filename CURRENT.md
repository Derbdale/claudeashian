# Current Discoveries

New items discovered since the last newsletter.
- **Smart Reports (Beta) for Enterprise** — Launched September 10, 2026. Analyses team usage patterns and costs, identifies workflow friction points, and highlights repeated patterns worth packaging as shared skills to help organisations optimise their Claude deployment. Available to Claude Enterprise customers. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.269** — Released September 11, 2026. New features: `claude plugin eval` runs a plugin's eval suite with scored, reproducible results (JSON + HTML report); `/output-style [name]` lists and switches output styles in Remote Control and headless sessions; Bash diff in results shows changed files when Bash handles edits (`bashEditDiffEnabled` setting); `OTEL_METRICS_INCLUDE_REPOSITORY` tags OpenTelemetry metrics with repository attributes; `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS` extends LLM gateway model-discovery timeout. 50+ bug fixes including: prompt cache partial-invalidation after interruptions; `deny`/`ask` permission rules with `!` prefix applying beyond their source file; git status showing outdated info after compaction; plugin LSP servers left running at session end; `/btw` answers containing made-up tool calls now flagged as not executed. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.270** — Released September 12, 2026. Single bug fix: read-only git commands in Bash were unexpectedly requesting permission after long sessions — a regression introduced in v2.1.269. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.271** — Released September 14, 2026. New features: fast mode now available in Claude Code Remote sessions (cloud and self-hosted runners) with organisation-level controls; mouse support in fullscreen `/config` panel (scroll, click to change values, row highlighting); per-command `allowed_domains` for Bash, PowerShell, and Monitor in auto mode with sandboxing — reviewed per-command and applied only to that command; `omitClaudeMd` in agent frontmatter runs subagents without CLAUDE.md files; `--accept-command <sha256>` for `claude plugin install/update` enables automation-friendly non-interactive plugin installs; `multiplier` above 1 (up to 10×) in `modelPricing` managed setting for internal chargeback rates. Multiple bug fixes: org policy refresh after account/key switches; `managed-mcp.json` parse failures no longer silently ignored; cloud sessions rejecting subagent tool calls after workflow approval; stale `.git/config.lock` breaking git commands (Linux); cross-session message delivery now produces sender notices. (Source: https://code.claude.com/docs/en/changelog)
- **Auto permission policies for Managed Agents** — As of September 10, 2026, the Managed Agents server can evaluate tool calls and automatically allow, deny, or pause them for human approval server-side, removing the need for clients to implement approval logic themselves. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **`ant beta:sessions connect`** — Released September 10, 2026. New `ant` CLI command that attaches a terminal to a live Managed Agents session, letting developers watch session activity and interactively approve or deny tool calls. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Claude for Financial Advisors** — Launched September 14, 2026. A plugin with connectors to Charles Schwab, Addepar, and BlackRock, plus workflow skills for meeting prep, portfolio analysis, and compliance reviews. Automates documentation and research tasks so advisors can spend more time with clients. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude API: workspace ID header, Managed Agents spend budgets, Admin API GA, domain restrictions** — Updates from September 11–15, 2026. (1) The `anthropic-workspace-id` response header now carries the `wrkspc_`-prefixed workspace ID for every API request, aiding audit trails. (2) Managed Agents sessions support a hard spend budget cap: a session that reaches its limit pauses with the `budget_reached` stop reason. (3) Admin API user-management endpoints for Claude Enterprise organisations are out of beta — the `anthropic-beta: ce-user-management-2026-07-13` header is no longer required. (4) `web_search` and `web_fetch` tools in Managed Agents now support `allowed_domains`/`blocked_domains` per-tool domain restrictions. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Sonnet 5 introductory pricing made permanent** — Announced September 2026. The scheduled price increase for Claude Sonnet 5 from $2/$10 per MTok to $3/$15 per MTok (input/output), originally planned for September 1, 2026, will not occur. The introductory price is now the permanent standard price. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Anthropic confirms Nasdaq listing, forecasts second consecutive profitable quarter** — Reported September 13, 2026. Anthropic selected Nasdaq as its IPO listing venue and told shareholders it expects an adjusted operating profit in Q3 2026, which would be its second consecutive profitable quarter (Q2 2026 revenue was $11.5 billion, a 14× year-over-year increase). Gross margins exceed 80% before revenue-sharing payments to partners such as Amazon. Annualised revenue run rate exceeds $65 billion. The offering targets a $2 trillion+ valuation, aiming to match or exceed SpaceX's record $86.3 billion IPO from earlier in 2026. (Source: https://www.bloomberg.com/news/articles/2026-09-13/anthropic-sees-adjusted-operating-profit-this-quarter-ft-says)
- **`claude plugin eval`** — Runs a plugin's eval suite locally and produces a scored, reproducible results report in both JSON and HTML format. Useful for testing and validating plugin behaviour before shipping. Introduced in Claude Code v2.1.269 (September 11, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`/output-style [name]`** — Lists available output styles or switches to a named one in Remote Control and headless Claude Code sessions. Introduced in Claude Code v2.1.269 (September 11, 2026). (Source: https://code.claude.com/docs/en/changelog)
