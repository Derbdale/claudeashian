# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.216** — Released July 20, 2026. New `sandbox.filesystem.disabled` setting allows skipping filesystem isolation for specific sandboxed commands. Also fixes: message normalization slowdown in long sessions; auto mode OAuth token expiration issues; Claude Code on web re-asking questions after idle periods; background agent session restoration failures. (Source: https://github.com/anthropics/claude-code/releases)
- **Artifacts call viewer MCP connectors (Week 29)** — Published artifacts can now pull live data and take actions through each viewer's own MCP connectors at view time, enabling live-data dashboards and interactive pages rather than static snapshots. Also added: public sharing links, editor roles for collaborative artifact editing on Team and Enterprise, and artifacts created directly from Claude Tag channel sessions. (v2.1.207–v2.1.212, Week 29, July 13–17, 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Claude's new constitution published** — Anthropic published an 84-page model spec on January 22, 2026, shifting from rule-based to reason-based AI alignment. Written primarily for Claude and used directly in training, it explains the *why* behind ethical principles rather than prescribing behaviours. Establishes a four-tier priority hierarchy (safety, ethics, compliance, helpfulness), formally acknowledges the possibility of AI consciousness and moral status, and is released under a Creative Commons CC0 license. (Source: https://anthropic.com/news/claude-new-constitution)
