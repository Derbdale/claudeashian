# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.179 stability release** — Released June 16, 2026. Key fixes: partial responses now preserved on mid-stream connection drops instead of showing raw errors; WSL2 mouse-wheel scroll regression (introduced in v2.1.172) fixed in Windows Terminal and VS Code; Linux sandbox `denyRead`/`allowRead` glob patterns over large directory trees no longer cause enormous Bash tool descriptions and unusable sessions; Ctrl+O now correctly shows subagent transcripts; remote session background tasks no longer appear stuck between turns. (Source: https://code.claude.com/docs/en/changelog)
- **Harness MCP connector in Claude Connectors Directory** — Harness's official MCP connector, added to Anthropic's Claude Connectors Directory on June 1, 2026, gives Claude structured real-time access to CI/CD pipelines, deployments, approvals, and delivery workflows, enabling natural-language querying and management of Harness-based engineering infrastructure. (Source: https://www.harness.io/blog/harness-claude-connector)
- **`ant` CLI for the Claude API** — Anthropic released the `ant` CLI (June 2, 2026), an open-source Go-based command-line tool that exposes every Claude API endpoint from the terminal: send messages, manage Managed Agent sessions, upload files, and pipe results into shell pipelines. Install via `brew install anthropics/tap/ant` or `go install github.com/anthropics/anthropic-cli/cmd/ant@latest`. (Source: https://pasqualepillitteri.it/en/news/4046/ant-cli-claude-platform-api-terminal)
- **Agent SDK billing split paused on June 15** — Anthropic reversed course on its announced plan to move Agent SDK, `claude -p`, Claude Code GitHub Actions, and third-party agent usage to a separate monthly credit pool on June 15, 2026. The change did not take effect; all programmatic usage continues drawing from existing subscription limits unchanged. Anthropic cited the need to "better support how users build with Claude subscriptions" and pledged to provide advance notice before any revised version launches. (Source: https://www.digitalapplied.com/blog/anthropic-claude-credit-overhaul-june-15-2026)
