# Current Discoveries

New items discovered since the last newsletter.

- **Self-hosted sandboxes for Managed Agents** — Tool execution now runs in your own infrastructure while orchestration stays on Anthropic's servers, keeping files within your security perimeter. Available as public beta on Claude Platform on AWS (announced May 2026). (Source: https://claude.com/blog/code-w-claude-london-2026-rethinking-how-we-build)
- **Security-guidance plugin** — Automatically reviews Claude's changes for security vulnerabilities as it works, surfacing issues inline without a separate review step. Bundled in Week 22 (v2.1.150–v2.1.157). (Source: https://code.claude.com/docs/en/whats-new)
- **Safety warning before writing shell startup files** — Claude now prompts for confirmation before writing to shell startup files (e.g. `.bashrc`, `.zshrc`) or build-tool config files, preventing accidental environment changes (v2.1.160). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **MCP tunnels for private network access** — Managed Agents can now securely reach private-network MCP servers without exposing them to the public internet, announced as research preview at Code w/ Claude London 2026. (Source: https://claude.com/blog/code-w-claude-london-2026-rethinking-how-we-build)
- **Advisor tool `max_tokens` parameter** — The advisor tool now accepts `max_tokens` in its tool definition to cap output per call, reducing latency and cost for workloads that don't need full-length advisor responses. Set `tools[].max_tokens` on the definition (June 2, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Refusal requests no longer billed** — API requests that return `stop_reason: "refusal"` without Claude generating any output are not charged. Reduces cost for applications with safety guardrails that trigger frequently (June 2, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Higgsfield MCP** — Generate AI images and video from 30+ models via a single MCP interface, covering Higgsfield's full model library including motion, lip sync, and consistent character tools. Launched April 29, 2026. (Source: https://medium.com/@docat0209/7-mcp-servers-every-claude-user-should-know-about-2026-9d17a0f5db73)
- **Agent SDK and `claude -p` billing split (June 15, 2026)** — Starting June 15, Agent SDK calls, `claude -p`, Claude Code GitHub Actions, and third-party agent usage move to a separate monthly credit pool ($20 Pro / $100 Max 5x / $200 Max 20x), metered at full API rates. Interactive terminal usage is unaffected. Credits don't carry over. (Source: https://devtoolpicks.com/blog/anthropic-splits-claude-subscriptions-agent-sdk-credit-june-2026)
- **Code w/ Claude London 2026** — Developer conference held in London, May 26, 2026, themed "rethinking how we build." Announcements included self-hosted sandboxes for Managed Agents (public beta) and MCP tunnels (research preview). Featured customer stories from Spotify, Base44, and Legora. (Source: https://claude.com/blog/code-w-claude-london-2026-rethinking-how-we-build)
- **Project Glasswing expanded to 150+ organisations** — Anthropic's cybersecurity initiative expanded to approximately 150 new organisations across 15+ countries. Partners have collectively identified 10,000+ high- or critical-severity security flaws. Claude Security for automated codebase scanning was introduced alongside the expansion. (Source: https://releasebot.io/updates/anthropic)
