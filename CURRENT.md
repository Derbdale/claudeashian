# Current Discoveries

New items discovered since the last newsletter.

- **Stacked slash-skill invocations** — Claude Code v2.1.199 (July 2, 2026) adds support for stacking multiple slash-skill invocations in sequence, enabling chained skill execution in a single prompt. (Source: https://github.com/anthropics/claude-code/releases)
- **Default permission mode renamed to "Manual"** — In Claude Code v2.1.200 (July 3, 2026), the "default" permission mode was renamed to "Manual" across the CLI, `--help`, VS Code, and JetBrains; `--permission-mode manual` and `"defaultMode": "manual"` are accepted alongside the legacy `"default"` value. AskUserQuestion dialogs now no longer auto-continue by default — opt into an idle timeout via `/config`. (Source: https://github.com/anthropics/claude-code/releases)
- **Claude Enterprise Analytics API and spend controls** — Launched July 2, 2026. Admins can query usage and cost per group and per user via a programmatic Analytics API (filterable by date, team, product, or model), with new endpoints tracking plugin adoption and artifact creation. Model-level entitlements let admins set default models and restrict which models each role can access across chat, Cowork, and Claude Code. Spend-threshold alerts fire at 75% and 90% of org-level limits; an Admin API supports automated spend-limit workflows. Claude Code value metrics include active developers, session counts, cost per commit, and estimated productivity lift. (Source: https://claude.com/blog/giving-admins-more-visibility-and-control-over-claude-usage-and-spend)
- **Fable 5 cybersecurity classifier tiers and CJS jailbreak severity framework** — Published July 2, 2026. Anthropic detailed Fable 5's safety classifiers across four tiers: Prohibited use (ransomware, malware), High-risk dual use (pen testing/exploitation), Low-risk dual use (OSINT), and Benign use (patch management, secure coding). Separately, Anthropic published the Cyber Jailbreak Severity (CJS) scale — CJS-0 (Informational) through CJS-4 (Critical) — developed with Glasswing partners Amazon, Microsoft, and Google, scored on four dimensions: capability gain, breadth of capability gain, ease of weaponization, and discoverability. (Source: https://www.anthropic.com/news/fable-safeguards-jailbreak-framework)
