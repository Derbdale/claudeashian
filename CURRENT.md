# Current Discoveries

New items discovered since the last newsletter.

- **Per-message effort (Beta)** — On Claude Fable 5.1, Mythos 5.1, and Opus 5, insert a mid-conversation `role: "system"` message with `output_config.effort` set to change effort for subsequent turns without invalidating the prompt cache. Requires the `mid-conversation-output-config-2026-07-01` beta header. Useful for progressively raising effort as a task deepens, or reducing it to `high` for lightweight follow-up turns on Opus 5. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Progress updates between tool calls (Beta)** — Set `thinking.display: "updates"` with the `thinking-display-updates-2026-08-18` beta header on Claude Fable 5.1, Mythos 5.1, or Fable 5 to receive short text progress updates as streaming events between tool calls. The `thinking` field arrives empty (as under `"omitted"`); at most one thinking block appears before each tool call. Surfaces agent progress to users without the full extended-thinking token cost. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`thinking-binding-controls-2026-08-01` beta header** — When the API silently drops thinking blocks because they were produced by a model newer than the one now receiving them (a version mismatch in multi-turn workflows), adding this header causes the response to include an `input_transformations` field listing the dropped blocks. Helps developers detect and handle thinking-block compatibility issues when orchestrating Fable 5.1 or Mythos 5.1 alongside older models. (Source: https://platform.claude.com/docs/en/release-notes/overview)
