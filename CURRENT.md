# Current Discoveries

New items discovered since the last newsletter.

- **Artifacts in Claude Code (beta)** — Sessions can generate shareable, live-updating web pages (incident reports, PR walkthroughs, dashboards) directly from a Claude Code session. Content is private to the organisation with version history and access controls. Announced June 2026. (Source: https://releasebot.io/updates/anthropic)
- **Consumer lifestyle app connector expansion** — Anthropic expanded Claude's connector directory with 15 consumer apps (June 18, 2026): Spotify, Uber, Uber Eats, Instacart, AllTrails, TripAdvisor, Booking.com, Resy, StubHub, Taskrabbit, Thumbtack, Viator, Audible, Intuit TurboTax, and Intuit Credit Karma. The directory now has 485+ verified integrations. Claude suggests the right app in-conversation based on context. (Source: https://claude.com/blog/connectors-for-everyday-life)
- **Micron and Anthropic strategic partnership** — Announced June 22, 2026; a multi-year agreement between Micron Technology and Anthropic to scale next-generation AI infrastructure, focused on memory and storage technologies for large-scale model training and inference. (Source: https://investors.micron.com/news-releases/news-release-details/micron-and-anthropic-announce-strategic-agreement-scale-next)
