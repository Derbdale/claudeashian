# Current Discoveries

New items discovered since the last newsletter.
- **Billing resumed for bio/frontier_llm/reasoning_extraction pre-output refusals** — As of September 24, 2026, API refusals returned before any output are now billed when `stop_details.category` is `"bio"`, `"frontier_llm"`, or `"reasoning_extraction"`. These three categories had low false-positive rates. The June 2026 policy making all pre-output refusals free remains in effect for all other refusal categories; mid-stream refusals continue to be billed as before. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Compliance API M365 exits beta** — As of September 24, 2026, the Compliance API session endpoints for Claude for Microsoft 365 sessions (Excel, PowerPoint, Word, Outlook) exited beta for Claude Enterprise organisations. Now generally available alongside existing GA coverage of Cowork, local Claude Code, Claude Science, and Chrome sessions — all under the Compliance Access Key with the `read:compliance_user_data` scope. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Activity Feed stops returning file and artifact identifiers** — As of September 24, 2026, the Claude Activity Feed API no longer returns file names, project document names, or artifact titles in its results. Developers needing these identifiers can retrieve them separately using appropriate access keys. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude sets new Riemann zeta function bound of 67.2%** — An unreleased research version of Claude improved the longstanding lower bound for non-trivial zeros of the Riemann zeta function lying on the critical line from 41.6% to 67.2%, surpassing a record dating to the 1970s. Claude coordinated ~60 subagents over ~1.5 days, executing 2,400 shell commands and thousands of numerical validations. Validated by Anthropic mathematicians Levent Alpöge and Ralph Furman, and external experts Brian Conrey and Dan Goldston. Claude produced a formally verifiable proof in Lean. Anthropic notes the techniques are unlikely to lead to a full proof of the Riemann Hypothesis. Published August 10, 2026; widely disclosed September 2026. (Source: https://www.anthropic.com/research/riemann-zeta)
- **Claude deployed in DRC Ebola outbreak response** — Published September 19, 2026. Claude Science is being used to support the Bundibugyo ebolavirus outbreak in eastern DRC in partnership with CEPI, WHO AFRO, and INRB Kinshasa. Key impacts: sitrep compilation cut from a full day to under one hour; simultaneous multi-model disease forecasting (previously constrained to one model); vaccine candidate dashboards via CEPI; and genome assembly using plain-language prompts instead of specialist programming. Human experts retain all decision-making authority. (Source: https://www.anthropic.com/features/ebola-response)
