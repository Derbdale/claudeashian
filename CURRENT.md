# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.332** — Released November 25, 2026. Skills from MCP servers now appear as `server:skill` entries in the slash menu (beta); a new PreSkillShellCommand hook fires before a skill's inline shell commands run and can refuse them. Claude Sonnet 5.5 set as the default model on Microsoft Foundry (deploy with `claude-sonnet-5-5` or set `ANTHROPIC_DEFAULT_SONNET_MODEL`). A new Cyber Verification Program tier expands vetted access to Mythos 5.2 for eligible security research organizations. (Source: https://code.claude.com/docs/en/changelog)
- **Skills over MCP public beta** — MCP servers can now deliver packaged workflow instructions ("skills") alongside their tools; skills from connected servers appear as `server:skill` entries in the Claude and Claude Code slash menu. Part of the broader Agent Skills open standard (now under the Agentic AI Foundation). Available in Claude Code v2.1.332+, launched November 25, 2026. (Source: https://code.claude.com/docs/en/changelog)
- **SDK error codes** — Each API error now includes a machine-readable `error_code` string alongside the existing error type and message, with its own exception class in the SDK. Update to the latest SDK to use typed error codes in error-handling logic. Released November 4, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **IP allowlist for Claude API (beta)** — Restrict Claude API access by IPv4 address, IPv6 address, or CIDR range; up to 1,000 entries per organization. Configure under Organization settings in the Claude Console. Available from November 5, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Opus 4.5 deprecated** — `claude-opus-4-5` announced for retirement on the Claude API on January 22, 2027. Anthropic recommends migrating to Claude Opus 5.5. Announced November 23, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`claude mcp add-json <name> -`** — Reads MCP server JSON configuration from stdin rather than from a command-line flag, keeping tokens and secrets off the shell history and process list. Not available inside a running Claude Code session. Added in v2.1.327 (November 17, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **User profiles API (beta, Oct 20, 2026)** — Each Claude API request can be attributed to a specific end customer via `/v1/user_profiles`. Safety enforcement and usage tracking then apply per end customer rather than to the whole organization, enabling granular policy control in multi-tenant deployments. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Tag API (beta, Oct 23, 2026)** — Use the `experimental-claude-tag-2026-10-21` beta header to read and change Claude Tag settings for Slack channels and workspaces programmatically. Not available to Claude Console organizations. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Organization webhooks (beta, Oct 20, 2026)** — Use the `webhooks-2026-10-07` beta header to subscribe to organization-level events. Launch event types cover user profile restriction and ban start and end, enabling automated compliance and access management workflows. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Compliance API: user preferences endpoint (beta, Oct 15, 2026)** — `GET /v1/compliance/organizations/{org_uuid}/user_preferences` returns "Instructions for Claude" and Cowork "Global instructions" per member. Available to Claude Enterprise organizations. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Admin API: sign member out everywhere (beta, Nov 5, 2026)** — Admins can remotely sign a member out of Claude on all their devices without removing them from the organization, without needing to remove them from the org itself. Available via the Admin API in beta. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`/status` command** — Surfaces broken agent, skill, and command files in the project, plus a list of which provider settings or environment variables are disabling features (e.g., `DISABLE_TELEMETRY=1`). Distinct from `/doctor`, which runs active connectivity and configuration checks. Significantly expanded in v2.1.327 (November 17, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`claude plugin validate` command** — Type-checks a plugin's TypeScript hooks module and reports issues. `--strict` fails the check on any finding; `--json` outputs a machine-readable report suitable for CI. Introduced in v2.1.323 (November 12, 2026). (Source: https://code.claude.com/docs/en/changelog)
