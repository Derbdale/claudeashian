# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.210** — Released July 14, 2026. New features: live elapsed-time counter on collapsed tool summary line so long-running calls visibly tick instead of looking stuck; startup warnings for deprecated `Write(path)`, `Glob(path)`, and `NotebookEdit(path)` permission rules (suggesting `Edit`/`Read` equivalents); screen reader now announces permission mode changes when cycling with Shift+Tab; memory writes that would push `MEMORY.md` over its read limit now produce an explicit error; agent view sessions stay visibly marked after navigation and background agent counts are colour-emphasised. Bug fixes: `isolation: 'worktree'` subagents no longer execute git commands against the main repo; `claude attach` failures during session transitions resolved; Grep pagination false "No matches found" fixed; plugin-provided MCP servers no longer torn down on mid-session resync; plan approvals no longer mislabelled as user edits; ghost frame overlap in alternate-screen mode eliminated. (Source: https://github.com/anthropics/claude-code/releases)
- **Claude for Teachers launched** — Free access to premium Claude for verified US K-12 educators through June 30, 2027. Includes Claude Code, Claude Cowork, a Learning Commons connector carrying academic standards for all 50 states, and integrations with nine EdTech platforms (ASSISTments, Brisk Teaching, Canva Education, Coteach, Diffit, Eedi, MagicSchool, Snorkl, TeachFX). Data is not used for model training; student data is protected under a K-12 DPA compliant with FERPA. An AI Fluency course was developed with Teach for America, and a train-the-trainer program with the American Federation of Teachers. A separate school/district offering is forthcoming. Announced July 14, 2026. (Source: https://www.anthropic.com/news/claude-for-teachers)
