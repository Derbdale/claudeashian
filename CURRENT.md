# Current Discoveries

New items discovered since the last newsletter.

- **Claude Sonnet 5 launched** — Released June 30, 2026. Agentic coding benchmark: 63.2% (vs Opus 4.8's 69.2%, Sonnet 4.6's 58.1%); slightly outperforms Opus 4.8 on knowledge-work benchmarks. Promotional pricing: $2/$10 per MTok through August 31, then $3/$15. Default model for free and Pro plans; also the new default in Claude Code. Native 1M token context window. (Source: https://www.anthropic.com/news/claude-sonnet-5)
- **X (Twitter) hosted MCP server** — Launched July 1, 2026. X released an official hosted MCP server exposing 200+ X API endpoints — search posts, read timelines, user profiles, conversations, and trends — without developers needing to build custom connectors. A separate MCP server for X's developer documentation lets AI coding tools search API references and integration guides. Supports Claude, Cursor, Grok Build, and other MCP-compatible tools. (Source: https://thetechportal.com/2026/07/01/x-launches-hosted-mcp-server-to-offer-easier-integration-for-claude-cursor-and-other-ai-assistants/)
- **Fable 5 and Mythos 5 export controls lifted; global redeployment** — On June 30, 2026, the US Commerce Department lifted the June 12 export controls on Fable 5 and Mythos 5, citing Anthropic's coordination with officials. Fable 5 became globally available July 1 via Claude Platform, Claude.ai, Claude Code, and Cowork. Pro/Max/Team/Enterprise plans: up to 50% of weekly usage limits through July 7, then usage credits at $10/$50 per MTok. Mythos 5 availability for critical-infrastructure organisations restored concurrently. (Source: https://www.anthropic.com/news/redeploying-fable-5)
- **Claude Science launched** — Announced June 30, 2026; an AI workbench designed for scientific researchers that integrates the tools and packages researchers use most, produces auditable artifacts, and provides flexible access to computing resources. Available as a customisable app distinct from Claude.ai. (Source: https://www.anthropic.com/news)
- **Extended thinking blocks are kept in cache prefix on Opus 4.5+ and Sonnet 4.6+** — On Claude Opus 4.5 and above and Claude Sonnet 4.6 and above, prior thinking blocks are kept by default as part of the cached context prefix, enabling efficient multi-turn extended-reasoning sessions. On older models and all Haiku models, thinking blocks are stripped from context after each turn. Changing extended thinking settings (budget, enable/disable) between turns alters the message structure and can break the cache prefix, so avoid toggling settings mid-conversation. (Source: https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
