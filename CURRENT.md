# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.238: keybindingFlavor, Remote Control resilience, memory leak fix** — Released August 21, 2026. New `keybindingFlavor` setting: set to `"readline"` for Ctrl+W to delete back to previous whitespace (Bash-style), default is `"classic"`. Plugin marketplace `headersHelper` runs commands that mint short-lived HTTP headers for catalog and archive fetches. Memory leak fixed: subagent tool results now released after they leave the display window in long sessions. Fixed custom output styles drifting to default mid-session. Extensive Remote Control resilience improvements including cross-session messaging, session crash recovery, model-pick sync from phone/web, and reconnect handling. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Academy launched** — Launched August 20, 2026 as Anthropic's free learning hub for AI fluency, built around the same materials used to train Anthropic employees. Offers 13+ courses, tutorials, badges, and personalized recommendations organized around the 4D AI Fluency Framework. Tracks span all skill levels: Claude 101 for newcomers through technical deep-dives on the Claude API and Claude Code. Available for developers, students, educators, professionals, and nonprofits. (Source: https://claude.com/blog/anthropics-approach-to-teaching-and-learning-ai)
