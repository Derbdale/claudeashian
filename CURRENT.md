# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.234** — Released August 17, 2026. Adds `CLAUDE_CODE_PROJECT_DIR_NAME` env var for custom per-project transcript directory names; a GitLab merge request badge to the footer and statusline (`MR !N` with draft/pending/green states); `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` to tune the WebFetch cache TTL (default: 15 minutes); and automatic session continuation when a claude.ai usage limit resets (configurable in `/config`). Also includes tighter permission and security controls and stronger worktree isolation blocking destructive git commands against the main checkout. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.235** — Released August 18, 2026. Adds an optional `spellcheck` setting that underlines misspelled words in the prompt input using the system-installed `aspell`, `hunspell`, or `ispell` spell-checker. Also fixes whole-prompt-cache invalidation triggered by a language server disconnect, fixes Shift+Tab in a permission prompt bypassing field closure, and resolves several UI rendering issues including list alignment at depth 3+ and prompt-highlight misalignment in multi-line prompts. (Source: https://code.claude.com/docs/en/changelog)
- **42-minute Anthropic service outage on August 16, 2026** — Starting around 21:58 UTC on August 16, 2026, Anthropic experienced a major outage affecting Claude.ai, Claude Code, and Claude Cowork. Users encountered login failures, incomplete requests, and degraded performance. The Claude Console and Claude API remained operational throughout. Services were restored by approximately 22:40 UTC, making the total downtime roughly 42 minutes. Anthropic did not publicly disclose a root cause as of initial reporting. (Source: https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-confirms-claude-is-down-in-major-outage-affecting-multiple-services/)
