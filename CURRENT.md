# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.325** — Released November 13, 2026. Security fix for zstd-compressed response decoding. Bug fixes: sessions on third-party gateways and Foundry no longer fail with context length errors on every turn (now compact correctly); recent turns no longer go missing from resumed sessions after an unclean exit; subagent model selection fixed for `opusplan`/`haiku` settings. New VS Code features: prompt suggestions (Tab accepts; disable with `promptSuggestionEnabled: false`); Console sign-in that creates no API key; redirect URL field for MCP server sign-in over SSH/WSL/container. Policy-blocked requests now tell you to run `/rewind` or `/clear` to continue. Behavior changes (notable): sandboxed Bash commands now follow the normal permission flow — set `sandbox.autoAllowBashIfSandboxed: true` to restore automatic allow; read-only git commands ask first in repos outside your project or trusted directories; scheduled tasks and `/loop` ask before running any skill that declares `allowed-tools` or hooks (add `Skill(name)` to `permissions.allow` to run unattended); sandbox now refuses writes to `.claude` settings and hooks in added directories. 14 other improvements and 88 bug fixes. (Source: https://code.claude.com/docs/en/changelog)
