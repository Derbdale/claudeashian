# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.212** — Released July 17, 2026. `/fork` now duplicates the current conversation into a background session while the main session continues; `/subtask` replaces the previous in-session subagent command. New `claude auto-mode reset` CLI command restores default auto-mode configuration. Session-wide WebSearch limits (default 200 calls) and subagent spawn caps (default 200) prevent runaway agentic loops. MCP tool calls running over 2 minutes are automatically backgrounded to keep the session responsive. `/resume` now shows a picker including previously deleted sessions. Security fixes: auto mode blocks transcript tampering; worktree creation vulnerability involving symlinks patched. Plan mode no longer auto-executes file-modifying Bash commands without a permission prompt. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Mid-conversation system messages now GA without beta header** — As of July 15, 2026, the Messages API now accepts `system` role entries mid-conversation on Claude API, Amazon Bedrock, and Google Cloud without any beta header, for Claude Fable 5, Mythos 5, and Opus 4.8. Previously required a beta opt-in. Enables dynamic context injection mid-turn without disrupting prompt caching. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **`--add-dir` flag and `/add-dir` command** — Launch with `claude --add-dir ~/path/to/other-repo` to give Claude access to an additional directory alongside the working directory, or run `/add-dir <path>` mid-session to add it without restarting. Useful for monorepo work or shared library access. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **`/compact` accepts a retention argument** — Pass a description of what context to preserve: `/compact retain the error handling patterns and current task goal`. Without an argument, `/compact` summarises everything; with an argument, Claude keeps the specified information prominent in the summary. Most useful when you've discussed multiple approaches and want to carry forward only one thread. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
