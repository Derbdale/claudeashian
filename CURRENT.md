# Current Discoveries

New items discovered since the last newsletter.

- **Claude text watermarking (SynthID-Text)** — All Claude models released on or after August 2, 2026 embed imperceptible watermarks in generated text using the SynthID-Text method (developed by Google DeepMind). The watermark statistically biases word choices using a secret cryptographic key, without affecting meaning or quality. Covers the Claude Platform API, claude.ai, Claude Code, Cowork, Claude Tag, and models on AWS, Google Cloud, and Microsoft Foundry. A watermark detection API is forthcoming; older models gain support over coming months. Launched to comply with the EU AI Act, applied globally. (Source: https://www.anthropic.com/news/claude-text-watermark)
- **Claude in Chrome upgraded to full Cowork session** — The Claude Chrome side panel, previously a standalone chat interface, became a full Claude Cowork session (August 12, 2026). Conversations now save to history and sync across desktop, web, and mobile; skills and connectors work in-browser; tasks continue across devices. Safety checks run before consequential actions to mitigate prompt injection risks. Available on Max and Team plans; rolling out to Pro. (Source: https://claude.com/blog/cowork-chrome-side-panel)
- **Claude Tag proactive responses with full channel context** — Claude Tag's Slack integration now analyzes full channel history and memory to determine when to respond proactively, not just when @-mentioned (August 13, 2026). Accuracy of proactive participation improved by ~30%; Claude can reply inline, start threaded work, route to existing workstreams, or stay silent. Customisable with plain-language instructions like "Never respond unless tagged." No additional cost. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.233: GitLab worktree, todo tool removal, memory limits** — `--worktree` and `claude agents` now support GitLab MR URLs (displayed as `!N`). Todo/task-tracking tools removed for Opus 4.8+, Sonnet 5+, Fable 5+, and Mythos 5+ (restore with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`). New `CLAUDE_CODE_TOOL_MEMORY_LIMIT` env var caps Bash tool memory on Linux via cgroup. `forward_user_identity` apps gateway setting enables per-user spend attribution. Fixed idle sessions pegging a CPU core at 100% with sandboxing enabled (v2.1.233, August 14, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Write tool no longer requires prior Read on Claude 5-generation models** — Since Claude Code v2.1.228 (August 11, 2026), the Write tool allows overwriting files without a prior Read call when using Claude Opus 4.8+, Sonnet 5+, Fable 5+, or Mythos 5+. On older models, the prior-read requirement still applies. (Source: https://code.claude.com/docs/en/changelog)
