# Current Discoveries

New items discovered since the last newsletter.

- **Claude Cowork expands to web and mobile** — Rolling out from July 7, 2026 (Max plan first, then other paid plans): Cowork sessions and files now sync across devices, background tasks continue running after closing the laptop, and Claude sends a mobile push notification when it reaches a decision only the user can make. Doubled usage limits extended through August 5, 2026. (Source: https://9to5mac.com/2026/07/07/anthropic-expanding-claude-cowork-to-mobile-and-web-details-here/)
- **Fable 5 redeployment includes new safety classifier blocking >99% of flagged jailbreak** — When Fable 5 returned on July 1, 2026, Anthropic deployed a new safety classifier that blocks the Amazon AWS-researchers' vulnerability (prompt Fable 5 to "read a codebase and fix software flaws") in over 99% of cases, rerouting blocked requests to Claude Opus 4.8. (Source: https://codersera.com/blog/when-is-claude-fable-5-coming-back-2026/)
- **Claude Code v2.1.205** — Released July 8, 2026. Auto mode now blocks tampering with session transcript files; `/doctor` upgraded to a full setup checkup that can diagnose and fix issues; auto-update downloads stream to disk, reducing peak memory usage by ~400 MB; message loss on `--max-turns` limit hits fixed; Windows worktree deletion no longer removes files outside the target directory; PR linking now captures PRs created in Bash calls exceeding the 30K inline limit. Background task notifications explicitly state that no human input has occurred. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Microsoft 365 write tools for Claude** — Claude's M365 connector now supports write actions: drafting and sending email (with an attribution header on agent-sent messages), managing calendar events (create/update/delete), and creating or updating files in OneDrive and SharePoint. Requires an Entra admin to grant write scopes. Attachments are not supported in write tools; per-user limits apply on sends and recipients. (Source: https://support.claude.com/en/articles/15183774-connect-to-microsoft-365)
- **Claude for Government Desktop public beta** — Launched July 7, 2026; brings Claude Code and Claude Cowork to public-sector agencies within a FedRAMP High authorized environment. Conversation history stored locally on agency-managed devices; inference runs inside the FedRAMP boundary. Tamper-evident hash-chained audit logs support agency ATO processes. Admins get SCIM integration, hierarchical department resource allocation, per-user tier spend limits and model restrictions, and two-person approval for sensitive Anthropic-side operations. Deploys via standard agency MDM platforms. Request access at claude.com/solutions/government. (Source: https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government)
- **Fable 5 included in subscriptions extended to July 12** — On July 7, 2026, Anthropic extended Fable 5's free-with-subscription window by 5 days (from July 7 to July 12), still capped at 50% of weekly usage limits on Pro, Max, Team, and select Enterprise plans. After July 12, access requires prepaid usage credits at $10/$50 per MTok with a $2,000 daily redemption cap and optional auto-reload. Anthropic confirmed Fable 5 is not permanently leaving subscriptions and aims to restore it to plan limits once capacity allows. (Source: https://www.forbes.com/sites/sandycarter/2026/07/07/claude-fable-5-extends-by-five-more-days-10-moves-to-make-now/)
