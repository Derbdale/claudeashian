# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.283** — Released September 25, 2026. New features: `x-claude-code-prompt-id` gateway hint header for grouping requests; `availableModelsMatch` managed setting with `"exact"` option for strict model version control; `deniedModels` managed setting to block specific models; MCP tool outputs added to OpenTelemetry spans with `OTEL_LOG_TOOL_CONTENT=1`; `/doctor prompt-audit` audits CLAUDE.md files and prompts for patterns targeting older model generations. Key fixes: SDK sessions losing deferred tool calls or finished tool results; MCP progress notifications discarded during long-running tool calls; stdio MCP servers left running after session end; HTTP 404 from stateless remote MCP servers making them unusable; dynamic workflows incorrectly running on fallback models instead of the configured model. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Tag personal connectors in Slack channels** — Rolled out September 24, 2026 for Team plans (Enterprise to follow). Users' own connectors (Gmail, Calendar, Slack, and others) are now accessible within Slack channel sessions, enabling Claude Tag to pull live personal data when handling requests. Available in review mode (Claude stages the response for approval) or auto mode (Claude posts directly). Stronger admin governance controls included for Enterprise plans. (Source: https://releasebot.io/updates/anthropic/claude)
- **Plugin directory submission portal launched** — Announced September 25, 2026. Developers on paid Claude plans can now submit plugins to the official Claude directory, track them through auto-validation and editorial review, and access post-launch usage analytics. Plugins are packages of MCP connectors, Agent Skills, or both. Submission options: a single remote MCP connector, or a GitHub-hosted plugin bundle (Claude Code plugins can also include LSPs, commands, hooks, and agents). Supports MCP 2.0 (2026-07-28 spec), MCP Apps, and Enterprise Managed Auth. (Source: https://claude.com/blog/build-plugins-for-claude)
- **Nvidia in talks for $10B anchor investment in Anthropic IPO** — Reported September 11–13, 2026: Nvidia is in talks to commit up to $10 billion as a cornerstone investor in Anthropic's planned IPO, which is targeting a valuation as high as $2.3 trillion and a raise of up to $100 billion. An anchor investor commits to buying a portion before the offering is marketed more broadly. The talks remain fluid and could still change or fall through. The IPO is targeted to price before the US midterm elections in November 2026. (Source: https://www.bloomberg.com/news/articles/2026-09-11/nvidia-in-talks-to-invest-up-to-10b-in-anthropic-ipo-reuters)
- **Claude computes nine-loop amplitude in theoretical physics** — Research paper "Yes, Claude Can Do Nine Loops" published September 25, 2026. Claude successfully computed a nine-loop amplitude in N=4 super-Yang-Mills theory — a problem of profound complexity in theoretical physics previously requiring specialized expert knowledge and months of effort by human specialists. Demonstrates frontier scientific reasoning capabilities in pure mathematics and physics. (Source: https://www.anthropic.com/research)
- **Project Swap: Claude agents align with user preferences in multi-agent marketplace** — Research paper published September 25, 2026. A controlled marketplace experiment where Claude agents negotiated book trades on behalf of Anthropic employees, achieving 61% preference alignment from just five-minute conversations. Demonstrates that underlying model capability outweighs prompt engineering in determining multi-agent economic negotiation outcomes. (Source: https://www.anthropic.com/research)
