# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.228** — Released August 11, 2026. Key improvements: synced skills from claude.ai hardened (no longer shadow local commands or MCP prompts; bodies cannot run `!` commands or expand `@` files); cross-session messages now display sender and body inline instead of collapsed; Vertex AI credential failures now surface within seconds rather than retrying for minutes; compaction progress now shows retry countdown and stall hints. Changed: Write tool now lets newer models overwrite unread files without a prior Read (matching Edit tool rules); removed outdated auto-mode cost note from first-use notices for Pro, Max, and Team. Bug fixes: interactive session redraw halt after rare layout error; Windows git detection failure when launched from parent folder; `/tui` reverting to earlier model after `/model` change; cross-session inbox missing after fresh install; Remote Control `/resume` leaking conversation history into new session; session cleanup deleting project memory folder contents. (Source: https://code.claude.com/docs/en/changelog)
- **Compliance API covers Cowork and local Claude Code sessions** — Extended August 11, 2026. Enterprise organizations can now retrieve transcripts and metadata for Claude Cowork and local Claude Code sessions via three new Compliance API endpoints: `GET /v1/compliance/apps/sessions/local` lists all sessions across the org, `GET /v1/compliance/apps/sessions/local/{session_id}` retrieves one session's metadata, and `GET /v1/compliance/apps/sessions/local/{session_id}/messages` returns its transcript. Uses the existing Compliance Access Key with the `read:compliance_user_data` scope. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Sonnet 5 pricing locked permanently at $2/$10 per MTok** — Announced August 10, 2026. The introductory pricing for Claude Sonnet 5 ($2 per million input tokens / $10 per million output tokens) is now the permanent standard price. The previously announced increase to $3/$15 per MTok scheduled for September 1, 2026 was cancelled. (Source: https://platform.claude.com/docs/en/release-notes/overview)
