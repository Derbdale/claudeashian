# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.247** — Released August 27, 2026. New features: `SendFeedback` tool lets Claude draft error reports when issues occur during a session; `/claude-api cost-optimize` subcommand profiles API spending across caching, token usage, batching, and model selection to surface optimization opportunities. Also improves auto-compact handling, permission prompts, and keyboard support; fixes history search, Remote Control connectivity, setup flows, and background session reliability. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude Cowork autonomous built-in browser** — Claude Cowork's desktop app gained a built-in sandboxed browser on August 26, 2026 for autonomous web navigation. Claude uses this private environment to research and act on the web without accessing the user's personal browser history, tabs, bookmarks, or passwords. Complements the Claude Code desktop in-app browser (launched Week 28, July 2026) but is distinct in being a fully sandboxed context that Claude controls autonomously for Cowork tasks. (Source: https://releasebot.io/updates/anthropic)
- **Admin API available in ant CLI and 7 SDKs** — As of August 26, 2026, the Admin API is fully accessible via the `ant` CLI and the Python, TypeScript, C#, Go, Java, PHP, and Ruby SDKs. Coverage includes organisation information, member management, API key administration, rate limits, service accounts, and encryption key oversight. Authenticate with `ANTHROPIC_API_KEY` or an OAuth token via `ANTHROPIC_AUTH_TOKEN`. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Compliance API exits beta; adds Claude Science and M365 transcript coverage** — As of August 26, 2026, the Compliance API session endpoints for Cowork and Claude Code are out of beta for Claude Enterprise organisations. Simultaneously, the API expanded in beta to return transcripts from Claude Science sessions and Claude for Microsoft 365 sessions, giving compliance teams a single API covering all major Claude product surfaces. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Anthropic's $45B Nscale compute deal** — Announced August 26, 2026. Anthropic signed a six-year deal to rent $45 billion in AI compute from Nscale, a British infrastructure company founded in 2024. Nscale will supply Anthropic with Nvidia's Vera Rubin chip systems from its flagship West Virginia data center; capacity is expected to start powering Anthropic's services in late 2027. Extends Anthropic's aggressive compute-acquisition strategy alongside deals with Volta ($10B), AMD ($5B), Riot Platforms ($9.1B), SpaceX, Amazon, and Google. (Source: https://techcrunch.com/2026/08/26/anthropic-continues-compute-gobbling-streak-in-45-billion-deal-with-nscale/)
- **Anthropic pitches $30T TAM to IPO investors; Q2 revenue $11.6B** — In late August 2026, Anthropic disclosed to IPO investors a total addressable market exceeding $30 trillion (larger than SpaceX's $28.5T estimate). Accompanying financial data: Q2 2026 revenue reached $11.6 billion (roughly doubling quarter-over-quarter), with 2028 revenue projected at $190–200 billion. Anthropic aims to raise up to $100 billion in its offering targeting a September or early October 2026 listing. (Source: https://qz.com/anthropic-ipo-investors-30-trillion-market-opportunity-082526)
