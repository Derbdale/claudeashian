# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.282** — Released September 25, 2026. New `maxProseWidth` setting constrains prose width in wide terminals while preserving full width for code blocks and tables. New `allowClaudeInChromeWithManagedMcp` managed setting enables Chrome compatibility with exclusive MCP configs. Startup telemetry variable notices now surface in `/status` and `claude doctor`. Scrollbar added for the `/feedback` drafts list in fullscreen mode. Key fixes: API errors affecting conversations with corrupted web search results; session resumption sending earlier messages in altered forms; permission rule parsing for mid-pattern `:*` patterns across all settings sources; terminal rendering issues including CJK character wrapping and cursor positioning. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Dario Amodei "We Must Pace the Frontier" essay** — Published September 12–13, 2026. Argues the AI industry should deliberately slow capability gains by one to two years so safety work can catch up, citing recursive self-improvement accelerating faster than expected since summer 2026. Outlines a three-step plan: give independent evaluators employee-level access inside AI labs (Anthropic's unilateral first step, leading to the Accenture embedded-evaluator partnership); coordinate shared safety standards among labs in democratic countries; and pursue international agreements on capability limits. Industry response: OpenAI CEO Sam Altman publicly agreed within hours; Elon Musk posted "Dario is right"; Google DeepMind CEO Demis Hassabis also backed the direction. (Source: https://darioamodei.com/post/we-must-pace-the-frontier)
- **Anthropic IPO delayed to November 2026** — Reported September 20–23, 2026. Anthropic postponed its planned October IPO to November 2026 to allow time to present Q3 financial results and respond to competitive pressure. Contributing factors: competing AI models regaining enterprise traction, open-weight models from Chinese developers and Meta compressing prices, and soaring infrastructure costs. OpenAI has similarly delayed its own IPO to 2027. Pre-IPO secondary markets still price Anthropic at $1.05–1.2 trillion; the IPO target remains a $2 trillion valuation with a raise of up to $100 billion. (Source: https://www.investing.com/news/stock-market-news/anthropic-delays-ipo-staging-to-november-amid-ai-fears-wsj-says-4907941)
- **Claude Sonnet 5.5 and Haiku 5.5 confirmed for coming weeks** — Announced September 22, 2026 alongside the Opus 5.5 launch. Anthropic's Mike Krieger confirmed both models will launch in the coming weeks, carrying many of the same improvements in performance, efficiency, and safety as Opus 5.5. No pricing, context window specs, or exact release dates announced; Anthropic's model documentation still lists claude-sonnet-5 as the current Sonnet. (Source: https://www.kucoin.com/news/flash/anthropic-to-launch-claude-sonnet-5-5-and-haiku-5-5-in-coming-weeks)
