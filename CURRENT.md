# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.243** — Released August 25, 2026. New features: `modelPicker` setting lets you curate the `/model` picker with an ordered, labelled list of models; Loops breakdown in `/usage` shows per-loop run count, total tokens, tokens per run, and last run; `promptCacheTtl` and `subagentPromptCacheTtl` settings control prompt cache duration; `modelPricing` managed setting lets organisations configure contracted per-model rates; keyless sign-in via Anthropic Console (under `/login` → "Sign in with your Console account"); remote MCP servers in non-interactive (`-p`) and SDK sessions now auto-reconnect after dropped connections. Performance: native Linux binary zstd-compressed to ~75 MB (down from 340 MB); per-session memory usage reduced 40–70 MB via on-demand code loading. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic IPO targeting September/October 2026 listing** — Following its August 2026 confidential registration filing, Anthropic entered pre-IPO investor roadshow meetings targeting a public listing as early as September or early October 2026. Pre-IPO secondary market activity implied valuations of $1.05–1.2 trillion; the primary offering round sits near $965 billion. Morgan Stanley, Goldman Sachs, JPMorgan, and Citigroup are the four lead underwriters. (Source: https://www.kucoin.com/blog/anthropic-ipo-2026-plans-september-or-early-otcober-listing-amid-965-billion-valuation-talks)
