# Current Discoveries

New items discovered since the last newsletter.

- **Edit no longer requires Read after single-file grep** — After running `grep`/`egrep`/`fgrep` on a single file, Claude Code no longer requires a separate Read call before issuing an Edit; the grep result satisfies the read precondition (v2.1.160). (Source: https://github.com/anthropics/claude-code/releases)
- **`--tools` flag unlocks dedicated Grep/Glob tools** — Explicitly listing `Grep` or `Glob` in the `--tools` flag provides dedicated search tools rather than relying on Bash, improving precision and permission scoping for search-heavy pipelines (v2.1.162). (Source: https://github.com/anthropics/claude-code/releases)
- **Cross-session messaging security hardening** — Messages relayed via `SendMessage` from other Claude sessions no longer carry user authority; relayed messages are treated with reduced trust to prevent privilege escalation across agent boundaries (v2.1.166). (Source: https://github.com/anthropics/claude-code/releases)
- **MCP `list_changed` notifications** — MCP servers can dynamically update their available tools, prompts, and resources at runtime without requiring a disconnect/reconnect; Claude Code subscribes to `list_changed` events and refreshes capabilities automatically. (Source: https://codersera.com/blog/claude-skills-mcp-servers-practitioner-guide-2026/)
- **Claude Partner Network Services Track and Partner Hub** — Announced June 3, 2026: Anthropic introduced a three-tier Services Track (Select, Preferred, Global Premier) based on certified practitioners, production deployments, and customer endorsements. The Claude Partner Hub portal lets customers identify qualified implementation firms and lets partners track their standing against published requirements. $100M partner investment covers training, technical support, and shared marketing. (Source: https://releasebot.io/updates/anthropic)
- **Enterprise custom roles gain admin permissions** — Enterprise plan admins can now assign members access to specific administrative areas (billing, privacy) without granting full Owner access, extending the existing custom roles framework (June 2, 2026). (Source: https://releasebot.io/updates/anthropic)
- **`claude agents --json` includes `waitingFor` field** — The JSON output now shows what a blocked session is waiting on (e.g. a pending permission prompt), enabling scripts to detect and respond to blocked agents (v2.1.162). (Source: https://github.com/anthropics/claude-code/releases)
- **`claude agents` URL filter** — Typing a URL into the agents view filters to the session whose first prompt contained that URL, making it easy to jump to the session that created a PR or file (v2.1.166). (Source: https://github.com/anthropics/claude-code/releases)
