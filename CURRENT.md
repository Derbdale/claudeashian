# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.286** — Released September 30, 2026. UI improvements: permission prompt counter shows "N of M" when multiple permission requests stack; clickable scroll arrows in fullscreen lists. VS Code gains a Bookmarks side panel for saving and keeping Claude responses, question tracking with answer display, and option previews on question cards. Auth fixes: prevents multiple Claude Code processes each opening a login browser when credentials expire; fixes macOS sessions showing "Not logged in" after successful login in another window. Session fixes: `--resume`/`--continue` no longer lose turns after parallel tool calls on crash; Remote Control sessions now disconnect when org policy disables Remote Control. MCP credential values no longer exposed in MCP error messages. (Source: https://code.claude.com/docs/en/changelog)
- **Cache diagnostics out of beta** — As of September 23, 2026, the `cache-diagnosis-2026-04-07` beta header is no longer required. Pass a `diagnostics` object on any Messages API request to receive `cache_miss_reason`; the `diagnostics` field is now always present in responses (null when not requested). Useful for debugging prompt cache prefix divergence in multi-turn conversations. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Inline tools in mid-conversation system messages (Beta)** — With the `inline-tools-2026-09-15` beta header, tools can be defined inside mid-conversation system messages via `tool_addition` blocks, enabling dynamic tool injection without disrupting the prompt cache. MCP toolsets can also be added inline using the `mcp-client-2026-09-15` header; responses include an `mcp_tool_listing` block. Available on Claude Fable 5.1, Mythos 5.1, Opus 5.5, and Sonnet 5.5. Distinct from the July 24 "mid-conversation tool changes" beta which covers adding/removing existing tools. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Sonnet 4.5 deprecated** — `claude-sonnet-4-5-20250929` announced for deprecation on September 30, 2026, with API retirement scheduled for November 30, 2026. Anthropic recommends migrating to Claude Sonnet 5.5. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Sonnet 5.5 and Opus 5.5 breaking API changes: update thinking and tool_choice** — When migrating to Sonnet 5.5 or Opus 5.5: (1) `thinking: {"type": "disabled"}` returns a 400 error — use `thinking: {"type": "between_tools"}` at effort `high` or below instead. (2) Forced tool use (`tool_choice: {type: "any"}` or `{type: "tool"}`) returns 400 — use `auto` with strict tool use. (3) The `computer_20251124` tool is rejected on Claude API and Google Cloud; upgrade to `computer_toolset_20260801`. (4) Preserved thinking blocks are account-bound: thinking blocks produced by one Anthropic account are silently dropped when replayed in a different account's conversation. (Source: https://platform.claude.com/docs/en/release-notes/overview)
