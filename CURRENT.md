# Current Discoveries

New items discovered since the last newsletter.

- **Claude in Chrome generally available** — Claude in Chrome, which provides AI assistance directly in the browser, launched as generally available in Claude Code v2.1.198 (July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Background agents auto-commit, push, and open draft PRs** — Background agents launched from `claude agents` now automatically commit, push, and open a draft PR when they finish code work in a worktree, instead of stopping to ask for input (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Explore agent inherits main session's model** — The built-in Explore agent now runs on the same model as the main session (capped at Opus) rather than always running on Haiku, improving search quality for complex codebase tasks (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Subagents and compaction inherit extended thinking config** — Subagents and context compaction now inherit the main session's extended thinking configuration, improving output quality on delegated and compacted tasks (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Background agent Notification hook events** — Two new events for the `Notification` hook: `agent_needs_input` fires when a background agent is blocked waiting for input; `agent_completed` fires when it finishes. Surfaces session state from `claude agents` without polling (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Managed Agents session event deltas** — Opt in with the `event_deltas[]` query parameter on `GET /v1/sessions/{session_id}/events/stream` to receive `event_start` and `event_delta` previews of agent messages as they stream, before the complete `agent.message` event arrives (June 30, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents backward pagination** — `GET /v1/sessions` now returns a `prev_page` cursor alongside `next_page`, enabling backward pagination through session lists (June 30, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents per-session config override** — When creating a session, pass `agent` with `type: "agent_with_overrides"` to replace the agent's model, system prompt, tools, MCP servers, or skills for just that session without changing the underlying agent definition (June 30, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents vault `injection_location` setting** — Environment variable credentials in vaults now support an `injection_location` setting controlling whether the credential value is injected into outbound request headers, the request body, or both (June 30, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents webhooks for agent and deployment lifecycle** — Webhooks now cover agent, deployment, and deployment run lifecycle events — react to a newly published agent version, a paused deployment, or a failed scheduled run without polling (June 30, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`/dataviz` bundled skill** — Built-in Claude Code skill for chart and dashboard design guidance, including a runnable color-palette validator and chart design system advice (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **`/agents` wizard removed** — The interactive `/agents` wizard command has been removed; create and manage agents by asking Claude directly or by editing `.claude/agents/` files manually (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
