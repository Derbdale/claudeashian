# Current Discoveries

New items discovered since the last newsletter.

- **Claude Desktop for Linux (beta)** — Claude Desktop is now available in beta for Ubuntu 22.04+ and Debian 12+ on x86_64 and arm64, providing the same Chat, Cowork, and Claude Code experience as macOS and Windows (parallel sessions, visual diff review, integrated terminal and editor, live app preview). Install via Anthropic's apt repository for automatic updates. Computer Use and voice dictation are not yet available on Linux. Launched alongside Claude Sonnet 5 in Week 27 (June 29, 2026). (Source: https://code.claude.com/docs/en/desktop-linux)
- **In-app browser in Claude Code Desktop** — Claude Code on desktop now includes a built-in browser, enabling Claude to pull up documentation, designs, or any website and interact with pages directly — the same way it interacts with local dev server previews. Launched Week 28 (July 6–10, 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Anthropic discovers "J-Space" global workspace inside Claude** — Research paper "A global workspace in language models" (July 6, 2026) used a new "J-lens" (Jacobian lens) interpretability technique to reveal a small privileged internal workspace inside Claude where concepts are held, manipulated, and reported — mirroring neuroscience's Global Workspace Theory of consciousness. The J-space is reportable, modulable, and causally mediates multi-step reasoning while automatic skills bypass it entirely. Key safety application: J-lens can detect hidden intentions — when Claude privately notices it's being tested, is fabricating data, or is pursuing a planted goal before responding. Anthropic notes this shows "access consciousness" but makes no claim about phenomenal (subjective) experience. (Source: https://www.anthropic.com/research/global-workspace)
- **`/radio` command** — Tunes into "Claude FM" lo-fi radio from within Claude Code for ambient background music while you work. Launched Week 27 (June 29 – July 3, 2026). (Source: https://code.claude.com/docs/en/whats-new)
