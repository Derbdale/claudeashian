# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.234: Auto-continue on usage limits, GitLab MR badges, NTLM security fix** — Released August 17, 2026. Claude Code now automatically continues when usage limits reset instead of requiring manual restart. GitLab merge request badges appear in the footer and statusline. New `CLAUDE_CODE_PROJECT_DIR_NAME` env var controls per-project transcript directory names. `selection:clear` keybinding action added. Security: hardened against NTLM credential-leak vector; Windows NT-namespace path rejection added. Also fixes auto mode in long sessions with repeated re-checking, session-scoped permission answers being dropped, and markdown rendering slowdowns. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.235: Optional spellcheck for prompt input** — Released August 18, 2026. Adds an optional `spellcheck` setting that uses `aspell`, `hunspell`, or `ispell` to check spelling in the prompt input field. Fixes prompt cache invalidation for language server disconnections, nested markdown list alignment at depth 3+, and Shift+Tab behavior in permission prompts. Improves memory and CPU usage for long-running cloud sessions such as `/ultrareview`. Various Vim mode and dialog improvements. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.236: ANTHROPIC_DEFAULT_MODEL env var, notify_when_idle cross-session** — Released August 19, 2026. New `ANTHROPIC_DEFAULT_MODEL` environment variable sets the default model for all new sessions without needing to configure it per-project. `notify_when_idle` added to cross-session `SendMessage` for opt-in notifications when another Claude Code session goes idle. Sandbox improvements: wildcard read-deny rules on macOS now correctly take precedence inside allowed regions. Improves auto mode with better git status checking; Remote Control marks sessions offline within seconds when CLI exits. Also fixes clipboard copy, background sessions, local MCP logs after directory removal, `/model` picker rendering, and fullscreen renderer fallback. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.237: Built-in "Concise" output style, prompt caching fix for gateways** — Released August 20, 2026. Adds a built-in "Concise" output style where Claude leads with results and skips preamble while still completing work thoroughly — useful for scripted or CI contexts. Fixes prompt caching for sessions using an LLM gateway or custom base URL, which had been incorrectly invalidating the cache prefix. (Source: https://code.claude.com/docs/en/changelog)
- **Files API generally available** — As of August 19, 2026, the Files API (`/v1/files`) is GA on the Claude API; the `files-api-2025-04-14` beta header is no longer required. GA format adds file expiration (`expires_in_seconds` on upload; `expires_at` on file objects), and `page`/`next_page`/`ids[]` pagination on list. Storage limit is 1 TB per organization; rate limit is 500 requests per minute. Existing requests that still send the beta header continue working and return the old response format. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Agent Skills API generally available** — As of August 19, 2026, Agent Skills and the Skills API (`/v1/skills`) are GA on the Claude API; the `skills-2025-10-02` beta header is no longer required, including for Messages API requests that load Skills via the `container` parameter. Requests that still send the header continue to work unchanged. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Admin API user management GA for Claude Enterprise** — As of August 19, 2026, the group and custom-role user-management endpoints for Claude Enterprise organizations no longer require the `anthropic-beta: ce-user-management-2026-07-13` header. Member and invite endpoints never required a beta header. Requests that still send the header are accepted unchanged. Covers members, invites, groups, and custom roles programmatically. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents web search/fetch domain restrictions** — As of August 19, 2026, you can restrict which sites a Managed Agents agent's `web_search` and `web_fetch` tools can reach. Set `allowed_domains` or `blocked_domains` on the tool's entry in the `agent_toolset_20260401` `configs` array. `web_fetch` also accepts `max_content_tokens`; `web_search` accepts `user_location`. Existing requests that pass only `name`, `enabled`, and `permission_policy` continue to work. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents self-hosted sandbox memory stores** — As of August 19, 2026, Claude Managed Agents sessions running in a self-hosted sandbox can attach memory stores. The Python, TypeScript, and Go SDK workers download each attached store into the sandbox at its `mount_path` and sync the agent's changes back to the store on completion. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Console session viewer redesigned with timeline minimap and Inspector panel** — As of August 19, 2026, the session viewer in the Claude Console has a timeline minimap, a transcript grouped by model request, and a new Inspector panel showing session details, cost, raw events, per-tool statistics, mounted resources, and per-thread activity. Improves observability for Managed Agents and long agentic runs. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Google Workspace write actions for Claude** — As of August 19, 2026, Claude's Google Workspace connector gains write actions: Gmail send, reply, and forward; and Google Drive share, move, and trash. Approval is on by default; Team and Enterprise owners can configure policies to skip per-action confirmation. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Console Workbench replaced by Playground** — Launched August 18, 2026. The legacy Workbench at platform.claude.com/workbench has been replaced by a new Playground (platform.claude.com/playground). Playground supports every Messages API parameter, includes templates demonstrating features like code execution and web search, and shows the full SDK request and raw API response for each run to help developers understand the API. The legacy Workbench was sunset on August 17 alongside the experimental prompt-generation API endpoints. (Source: https://platform.claude.com/docs/en/release-notes/overview)
