# Current Discoveries

New items discovered since the last newsletter.

- **Opus 4.8 effort defaults to `high` across all surfaces** — On Claude Opus 4.8, the effort parameter defaults to `high` across all surfaces including Claude Code and the Messages API, enabling deeper reasoning by default without explicit configuration. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Adaptive thinking on Opus 4.8 triggers only when needed** — With adaptive thinking enabled, Opus 4.8 skips extended reasoning on turns that don't require it, reducing wasted thinking tokens compared to Opus 4.7 at the same effort level. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Prompt cache minimum lowered to 1,024 tokens on Opus 4.8** — The minimum cacheable prompt length for prompt caching dropped from the Opus 4.7 threshold to 1,024 tokens on Opus 4.8, making caching accessible for shorter prompts. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Mobile push notifications in Claude Code** — Claude Code pings your phone when a long-running task completes or when Claude is blocked waiting for your input, surfacing session state without keeping the terminal open. Launched Week 16 (April 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Session recap after terminal inactivity** — When you return to an unfocused terminal, Claude Code shows a recap of everything that happened while you were away, so you can quickly re-orient without scrolling history. Launched Week 17 (April 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Advisor tool** — New API tool (public beta, April 9, 2026) that pairs a fast executor model with a higher-intelligence advisor model mid-generation; long-horizon agentic tasks get near-advisor-solo quality while bulk token generation runs at executor rates. Use the `advisor-tool-2026-03-01` beta header. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`ant` CLI** — Anthropic's official command-line client for the Claude API (launched April 8, 2026) enabling faster API interaction, native Claude Code integration, and versioning of API resources as YAML files. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Platform on AWS** — Full Claude API (Messages, Files, Batches, Managed Agents, code execution, tool use) on Anthropic-managed infrastructure accessible via AWS, with AWS billing and IAM authentication. Launched May 11, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Rate Limits API** — New API (April 24, 2026) that lets administrators programmatically query rate limits configured for their organisation and workspaces via `GET /v1/rate-limits`. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents Memory public beta** — Memory for Claude Managed Agents entered public beta April 23, 2026 under the `managed-agents-2026-04-01` beta header, allowing agents to persist and retrieve information across sessions. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents multiagent orchestration public beta** — Multiagent sessions and Outcomes for Claude Managed Agents entered public beta May 6, 2026 under the standard `managed-agents-2026-04-01` header, enabling one agent to spawn and coordinate subordinate agents. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Message Batches API max_tokens raised to 300k** — For Claude Opus 4.6 and Sonnet 4.6, the `max_tokens` cap on the Message Batches API was raised to 300k (March 30, 2026) for long-form content, structured data, and large code generation. Include the `output-300k-2026-03-24` beta header. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Code execution free with web search or web fetch** — API sandboxed code execution is now free when used in the same request as web search or web fetch (February 17, 2026), reducing cost for agentic workflows that combine browsing with computation. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Models API capability fields** — `GET /v1/models` and `GET /v1/models/{model_id}` now return `max_input_tokens`, `max_tokens`, and a `capabilities` object (March 18, 2026), enabling applications to query what each model supports at runtime. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`stop_details` field on refusal responses** — The `stop_details` field on refusal API responses now returns a `category` (`cyber`, `bio`, or `null`) and a human-readable `explanation` (May 28, 2026), so applications can route different classes of refusal to appropriate next steps. No beta header required. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`usage.output_tokens_details.thinking_tokens`** — The Messages API response now reports how many billed output tokens were extended thinking via `usage.output_tokens_details.thinking_tokens` (May 27, 2026). When streaming, the breakdown appears on the final `message_delta` event. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Code rate limits doubled** — Anthropic doubled rate limits for Claude Code across all plan tiers so developers, startups, and enterprises can build more reliably at scale. Change went live alongside the Code with Claude 2026 conference. (Source: https://www.mindstudio.ai/blog/code-with-claude-2026-new-agent-features)
- **`/powerup` command** — Interactive lessons built into Claude Code for learning features hands-on, launched as part of the computer use research preview week (Week 14, v2.1.86). (Source: https://code.claude.com/docs/en/whats-new)
- **`/team-onboarding` command** — Packages your current Claude Code setup (CLAUDE.md, skills, hooks, MCP config) into a replayable onboarding guide for new teammates (Week 15). (Source: https://code.claude.com/docs/en/whats-new)
- **`/autofix-pr` command** — Turns on PR auto-fix from the terminal; Claude monitors CI failures on open PRs and pushes fixes automatically (Week 15). (Source: https://code.claude.com/docs/en/whats-new)
