- **Claude Code v2.1.326** — Released November 16, 2026. Code Mode can now be used with agent teams. New additions: warnings for malformed `--allowedTools`/`--disallowedTools`/`--tools` entries; `OTEL_RESOURCE_INCLUDE_HOST` env var adds `host.name` and `host.id` to OpenTelemetry resource attributes (off by default); Ctrl+O shows hidden startup notices; `claudeCode.promptSuggestions` VS Code setting. Behavior changes: HIPAA-configured org sessions now start in auto mode; sandbox tightened (sensitive home folders no longer writable by default); `"decision": "block"` from hooks holds in more cases; `--add-dir`/`/add-dir` show trust prompt for untrusted folders; Remote Control now connects through CONNECT tunnels; self-hosted runners on Linux/macOS get a built-in `gh api` by default. 59 improvements and 233 bug fixes. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.327** — Released November 17, 2026. New additions: `/install-github-app` now asks for confirmation before changing a repository; `claude mcp add-json <name> -` reads server JSON from stdin (tokens stay off the command line); `/status` and `/config` show more diagnostics including broken agent/skill/command files and overridden settings; `attributionProject` setting for naming a session's billing group on Claude apps gateways; `/tui classic` alias for the non-fullscreen renderer. Behavior changes: `ExitWorktree` asks before removing a worktree that may hold unsaved work; `claude mcp add --scope project` stops instead of overwriting `.mcp.json` when it has no `mcpServers` key; several permission rules tightened; auto mode now ignores more wildcard allow rules (e.g. `Bash(pnpm dlx *)`). 26 improvements and 100 bug fixes. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.328** — Released November 19, 2026. Auto mode added for Claude Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway; interactive sessions with no permission mode now start in auto mode. New additions: `"onFailure": "block"` for `mcp_tool` hooks (matching command and HTTP hooks); `CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME` env var stops `claude -p --resume`/`--continue` from running deferred tool calls; self-hosted runner additions (`--repository-folder`, `--hook-label`, `--metadata key=value` for `claude --environment`, plus orchestrator metrics). Behavior changes: `/code-review` on most models now reports only bugs and CLAUDE.md violations (use `/simplify` for reuse/efficiency cleanups); `/bug` now asks Yes/No before sending; Code Mode no longer runs UserPromptSubmit hooks on script output; managed PostToolUse hooks no longer fire for refused calls. 19 improvements and 91 bug fixes. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Desktop release channels** — Announced November 17, 2026. Users can now select a release channel in Claude Desktop controlling how often they receive updates. **Stable** (default): less frequent updates, more testing. **Latest**: a new version roughly once a day, bringing fixes and features sooner. (Source: https://support.claude.com/en/articles/12138966-release-notes)
- **Anthropic IPO final price confirmed at $83/share; 980M shares sold in record offering** — Anthropic officially priced its IPO at $83.00 per share on November 18, 2026, above the $70–$78 marketed range and above the upsized offering. 980 million Class A shares sold in total (~956M from Anthropic, ~24M from selling stockholders), raising approximately $81.3 billion — the largest IPO on record, surpassing SpaceX. Goldman Sachs and Morgan Stanley led underwriting. Underwriters hold a 30-day greenshoe option on 147M additional shares. Offering closes November 20, 2026; Nasdaq ticker ANT. (Source: https://www.anthropic.com/news/anthropic-prices-initial-public-offering)
