# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.217** — Released July 21, 2026. Adds emoji shortcode autocomplete in prompts, clearer transcript write warnings, and tighter controls for subagents, budgets, and background sessions. Fixes memory leaks in MCP tool outputs, Windows auto-update failures, and background session isolation issues. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Legacy Workbench and experimental prompt API sunset** — Announced July 17, 2026, effective August 17, 2026. The deprecated platform.claude.com/workbench will shut down, and three experimental prompt-tools API endpoints are being removed: `/v1/experimental/generate_prompt`, `/v1/experimental/improve_prompt`, and `/v1/experimental/templatize_prompt`. Requests to these endpoints after removal will return an error. Export any saved workbench data before the deadline. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
