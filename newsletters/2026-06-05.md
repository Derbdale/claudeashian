# Current Discoveries

New items discovered since the last newsletter.

- **Fast mode available for Claude Opus 4.7** — Fast mode (`speed: "fast"`) now supports claude-opus-4-7, providing significantly faster output token generation at premium pricing (Week 20, v2.1.139). (Source: https://code.claude.com/docs/en/whats-new)
- **Parallel tool calls now independent** — In agentic workflows, a failure in one parallel tool call no longer cancels the other calls in the batch; each succeeds or fails independently (v2.1.161). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Slash commands fill into prompt bar before executing** — Selecting a slash command now inserts it into the prompt bar for review and editing before submission, improving discoverability and preventing accidental execution (v2.1.162). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Cache diagnostics public beta** — Pass `diagnostics.previous_message_id` on a Messages API request to receive a `cache_miss_reason` field explaining exactly where the prompt cache prefix diverged from the previous turn, making it easier to debug caching issues. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Web search tool returns richer SEC filing data** — The web search tool now surfaces enriched SEC filing data, grounding financial research agents, earnings analysis, and due-diligence workflows in primary source documents with citations. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Harness MCP server in Claude Connectors** — Harness's official MCP connector entered the Claude Connectors directory on June 1, 2026, giving Claude structured real-time access to CI/CD pipelines, deployments, approvals, security posture, and chaos experiments via the Harness Software Delivery Knowledge Graph. (Source: https://www.harness.io/blog/harness-claude-connector)
- **Shopify AI Toolkit MCP connector** — Official MCP connector for Shopify enabling Claude to query products, orders, customers, analytics, and metafields via natural language without manual API calls. (Source: https://www.explorium.ai/blog/data-for-gtm/top-10-official-claude-connectors/)
- **Plugin version guardrails** — New `requiredMinimumVersion` and `requiredMaximumVersion` settings in plugin manifests prevent a plugin from loading on unsupported Claude Code versions (v2.1.163). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Hooks additionalContext return value** — Hooks can now return an `additionalContext` field to inject information into the model's context without triggering error labels, enabling richer hook-to-model feedback (v2.1.163). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude Sonnet 4 and Opus 4 (2025 versions) retire June 15** — claude-sonnet-4-20250514 and claude-opus-4-20250514 are deprecated with retirement on the Claude API scheduled for June 15, 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **/plugin list command** — New slash command to list all installed plugins with filtering options (v2.1.163). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Use an initializer + coding agent pattern for multi-session agents** — For long-running agents spanning multiple context windows, have a dedicated initializer agent create feature lists, progress files, and structured git commits on the first run; subsequent coding agents resume from those artifacts rather than starting cold. (Source: https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)
- **Tool descriptions are as important as prompts** — For agent-facing tools, the description field significantly impacts performance; treat it with the same care as your system prompt. Use clear namespacing (e.g. `asana_projects_search`), return only relevant data, and implement pagination with sensible defaults — token savings can reach two-thirds compared to verbose responses. (Source: https://www.anthropic.com/engineering/writing-tools-for-agents)
