# Current Discoveries

New items discovered since the last newsletter.

- **Claude Haiku 5.5 launched** — Released October 7, 2026. Third and final model in the Claude 5.5 family. Fastest model by tokens per second (Artificial Analysis benchmark). Priced at $0.10/$0.50 per million input/output tokens for prompts up to 100K tokens. 1M token context window with adaptive thinking. Positioned for high-volume, latency-sensitive workloads such as summaries, classification, subagents, and browser use. Model ID: `claude-haiku-5-5`. Retirement not before October 7, 2027. (Source: https://qcode.cc/en/claude-haiku-5-5-status-tracker)
- **Fast mode on Opus 4.8 deprecated** — Announced October 30, 2026; removal on November 30, 2026. After removal, fast mode requests on Opus 4.8 will return an error rather than falling back to standard speed. Anthropic recommends migrating to Claude Opus 5.5 to continue using fast mode. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Duet research preview** — Launched October 21, 2026 as a research preview with a waitlist for US Pro and Max subscribers. A proactive agent that monitors context and notifies users about important information needing their attention, without requiring users to initiate a conversation. Distinct from Claude's reactive chat and task-completion modes. (Source: https://www.orcarouter.ai/blog/anthropic-launch-week-october-2026-what-shipped)
- **Claude Fable 5.2 and Mythos 5.2 launched** — Released November 9, 2026. Outputs up to 30% faster than the 5.1 versions. API pricing reduced by 20%: Mythos 5.2 priced at $8/$40 per MTok input/output (down from $10/$50). Same underlying model — Fable 5.2 has built-in cybersecurity and biology safeguards; Mythos 5.2 has fewer safeguards and is restricted to organisations verified through Anthropic's Life Sciences and Cyber Verification Programs. Fable 5.2 generally available via paid Claude plans, Claude Code, and all major cloud providers. Safety testing included evaluations by the UK AI Security Institute, Frontier Design, and METR. (Source: https://www.cnbc.com/2026/11/09/anthropic-claude-fable-5-2-mythos-5-2.html)
- **Code Mode in Claude Code (experimental)** — Shipped in Claude Code v2.1.323. An opt-in experimental mode in which Claude writes JavaScript to call its tools rather than issuing tool calls in the conventional way. Can be disabled at the organisation level. (Source: https://code.claude.com/docs/en/changelog)
- **Idle compaction in VS Code and Desktop Code tab** — Added in Claude Code (November 2026). Conversations left idle for a prolonged period (200K+ tokens) in VS Code and the Desktop Code tab are automatically summarised; the summary is used on the next message if the prompt cache has expired, reducing cold-start context costs. (Source: https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-8-2026-485k)
- **Privacy check before network tool calls** — Added in Claude Code (November 2026). Before a web or shell tool call sends the user's account email address to the network, Claude Code now displays a confirmation prompt, preventing silent email leakage through tool calls. (Source: https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-8-2026-485k)
- **Claude Models on Google Cloud (Anthropic-managed) generally available** — Released October 22, 2026. US and Global inference endpoints with Claude Fable 5.1, Opus 5.5, Sonnet 5.5, and Haiku 5.5. New Claude Platform features and betas available on launch day. Part of the Anthropic-managed Claude Platform expanding beyond AWS. (Source: https://blog.memoryplugin.com/claude-new-features-october-2026/)
- **Dynamic workflows for Managed Agents (beta)** — Beta feature released October 9, 2026. Lets Claude Managed Agents write and run multi-phase workflows in the background for complex tasks such as reviewing hundreds of documents, without requiring the user to orchestrate each phase. (Source: https://www.orcarouter.ai/blog/anthropic-launch-week-october-2026-what-shipped)
- **Agent Skills donated to Agentic AI Foundation** — Anthropic donated the Agent Skills open standard to the Agentic AI Foundation (a directed fund under the Linux Foundation) on October 22, 2026, making it a vendor-neutral open standard maintained by the community alongside MCP. (Source: https://claudelog.com/claude-news/)
- **Anthropic IPO roadshow launched; Nasdaq ANT listing November 19** — Anthropic launched its IPO roadshow on November 10, 2026, targeting first trading on Nasdaq under the ticker ANT on November 19, with pricing expected November 18. Offering 825 million Class A shares at an indicative range of $70–$78 per share; at the top of the range the raise would total approximately $64.35 billion. Fully diluted valuation estimated at $1.3–1.4 trillion. Up to 20% of IPO shares are planned for individual investors. Lead underwriters: Morgan Stanley, Goldman Sachs, JPMorgan, and Citigroup. (Source: https://www.kucoin.com/news/flash/anthropic-ipo-nears-claude-maker-to-debut-on-nasdaq-nov-19)
- **Claude Meetings, Whiteboards, and Sheets launched** — Announced November 10, 2026; Claude Meetings rolled out in beta on November 12. Claude Meetings joins Google Meet calls as a visible participant and can work on tasks during the call; available in beta on Team and Enterprise plans. Claude Whiteboards is a beta collaborative canvas (paid plans) that can be built in real time during Meetings calls. Claude Sheets is a beta spreadsheet tool for paid plans, generating working spreadsheets with formulas, multiple tabs, drop-down menus, and formatting, with support for joint editing. On Enterprise plans, Sheets and Whiteboards are off by default until an admin enables them; Claude Data switches on by default for Enterprise on November 19, 2026. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Claude for Manufacturing launched** — Released November 12, 2026 as a plugin with 17 skills for manufacturing tasks including job quoting, failed-inspection investigation, and stopped-machine diagnosis. Connectors to Autodesk Fusion, Infor, Microsoft 365, and Oracle NetSuite. Skills conclude with user review; the plugin does not operate equipment. Available to install on Team and Enterprise plans. (Source: https://letsdatascience.com/news/anthropic-launches-claude-for-manufacturers-plugin-with-17-s-d5b8b867)
