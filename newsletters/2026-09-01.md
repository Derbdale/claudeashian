# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.252** — Released August 31, 2026. Bug-fix release: fixes Bash commands failing with "task output swap refused" on some Macs; "always allow" not saving in projects without `.claude/settings.local.json`; Remote Control sessions stalling for minutes after tool completion during degraded claude.ai connections; background task notifications with large failure output exceeding API request size limits. (Source: https://code.claude.com/docs/en/changelog)
- **Personal and service account API keys in Claude Console** — As of August 27, 2026, admins can create personal keys (tied to a user account, acts with that user's permissions) and service account keys (tied to a service account) from the Claude Console. Keys become invalid when the linked account is removed from the org, making key ownership auditable. Can be scoped to a workspace or granted cross-workspace admin access; workspace API keys remain available as a legacy option. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Computer use and Browser use toolsets on Google Cloud** — As of August 20, 2026, both `computer_toolset_20260801` and `browser_toolset_20260801` are available on Google Cloud (Vertex AI) for Claude Fable 5, Mythos 5, Opus 5, Sonnet 5, and Opus 4.8. Requests use the same `tools` entries as on the Claude API; no additional headers needed. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **SDK beta.files/beta.skills cleanup; BetaSkill renamed** — In Python SDK 1.2.0, TypeScript SDK 0.122.0, Go SDK 1.68.0, Java SDK 2.59.0, Ruby SDK 1.67.0, and C# SDK 12.44.0 (August 27, 2026), `client.beta.files` and `client.beta.skills` no longer send the `files-api-2025-04-14` and `skills-2025-10-02` beta headers. The `BetaSkill` type is renamed `BetaContainerSkill`; `client.beta.skills.delete()` now deletes all versions of a skill. Requests that still send the beta headers keep the old shapes. (Source: https://platform.claude.com/docs/en/release-notes/overview)
