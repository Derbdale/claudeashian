# Current Discoveries

New items discovered since the last newsletter.

- **Claude Fable 5 launched** — Launched June 9, 2026 as Anthropic's most capable widely-released model. State-of-the-art on nearly all benchmarks across software engineering, knowledge work, vision, and scientific research. 1M token context window by default, 128k max output tokens, always-on adaptive thinking. Priced at $10/$50 per MTok. Model ID: `claude-fable-5`. (Source: https://www.anthropic.com/news/claude-fable-5-mythos-5)
- **Claude Mythos 5 launched** — Restricted-access companion to Fable 5, launched June 9, 2026 for Project Glasswing participants. Same underlying architecture with safeguards lifted in certain areas; described as having the strongest cybersecurity capabilities of any available model. Model ID: `claude-mythos-5`. Priced at $10/$50 per MTok. (Source: https://www.anthropic.com/news/claude-fable-5-mythos-5)
- **Fable 5 / Mythos 5 new tokenizer produces ~30% more tokens** — Claude Fable 5 and Mythos 5 use the tokenizer introduced with Opus 4.7; the same text produces roughly 30% more tokens compared to models released before Opus 4.7. Use the token counting API with `model: "claude-fable-5"` to measure prompts before migrating. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Fable 5 requires 30-day data retention** — Fable 5 is not available under zero data retention; API requests must accept a 30-day retention policy. Only model with this requirement as of June 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Workflow keyword trigger setting in /config** — New setting in `/config` prevents the word "workflow" in a prompt from unintentionally launching a dynamic workflow. Backspace pressed immediately after a workflow trigger now dismisses the workflow request (same as alt+w) instead of deleting a character (v2.1.169). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Apple Foundation Models Swift package for Claude** — Anthropic released a Swift package (`ClaudeForFoundationModels`) that makes Claude available as a server-side language model conforming to Apple's `LanguageModel` protocol. Developers use the same `LanguageModelSession` API for Claude as for Apple's on-device model; supported on iOS 27, iPadOS 27, macOS 27, visionOS 27, and watchOS 27. Requests go directly from the app to the Claude API — Apple is not in the request path. (Source: https://claude.com/blog/claude-for-foundation-models)
- **`fallbacks` parameter for Fable 5 refusals** — Opt-in beta parameter on the Claude API and Claude Platform on AWS that automatically re-runs a refused Fable 5 request on a specified fallback model; billed at the fallback model's rates. Not supported on the Message Batches API. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`stop_details.category: "reasoning_extraction"` on Fable 5** — On Claude Fable 5, the `stop_details.category` field on refusal responses now includes `"reasoning_extraction"`, returned when a request is blocked under Anthropic's ToS restrictions on reverse engineering or duplicating model outputs. The existing `"cyber"` and `"bio"` categories are unchanged. No beta header required. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Managed Agents scheduled deployments** — Claude Managed Agents now supports running sessions on a cron schedule without managing your own scheduler, via the new scheduled deployments feature (June 9, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents vault environment variable credentials** — Claude Managed Agents vaults now support environment variable credentials, enabling secure injection of secrets (CLIs, SDKs, API keys) into the agent sandbox without hard-coding them (June 9, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Anthropic S-1 financial context** — Anthropic's confidential S-1 filing (June 1, 2026) was preceded by a $65 billion Series H that set a ~$965 billion pre-IPO valuation. The company reports a $47 billion annual revenue run-rate. The filing targets a potential IPO valuation of $1.75–1.8 trillion with up to $75 billion raised — which would be the largest IPO in history. Anthropic filed 10 days after OpenAI. (Source: https://finance.yahoo.com/markets/stocks/articles/anthropic-files-confidential-1-joins-161008569.html)
- **Backspace dismisses workflow trigger** — Pressing backspace immediately after typing a dynamic workflow trigger keyword cancels the workflow request (same as alt+w), instead of deleting a character. Prevents accidental workflow launches while editing prompts (v2.1.169). (Source: https://releasebot.io/updates/anthropic/claude-code)
