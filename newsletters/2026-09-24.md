# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.281** — Released September 23, 2026. Claude apps gateway gains `assume_role` for Bedrock STS cross-account role assumption, `guardrail: {id, version}` to apply Amazon Bedrock guardrails to requests, and `telemetry.resource_attributes` for fixed telemetry labels. MCP gains URL-mode elicitation support on 2026-07-28 protocol connections and server validation checks in `claude plugin validate`. New `"attribution": false` setting in `settings.json` hides commit/PR attribution. Adds scrollbars to `/skills`, `/mcp`, `/plugin` lists in fullscreen. Fixes 60+ bugs including session resume breaking the prompt cache, responses cut short by proxies showing as complete, and recursive `rm` running unprompted in auto mode. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Marketplace launched** — Announced September 23, 2026. A unified hub bringing plugins and connectors, AI-powered products, and service partners into one place. Three categories: Plugins & Connectors (2,000+ at launch, including Atlassian, Google, Microsoft, Notion, Salesforce); Agents & Products (apply committed Anthropic spend to Claude-powered software from partners like CrowdStrike, Cursor, Harvey, Legora, Lovable, and Snowflake); Service Partners (consulting and system integration firms from the Claude Partner Network including Accenture, BCG, and Deloitte). Built on MCP and Agent Skills open standards. (Source: https://claude.com/blog/claude-marketplace)
- **Anthropic biology lab discovers novel enzyme system** — Announced September 23, 2026. Anthropic's wet biology lab (established spring 2026 in the Bay Area) published its first major discovery: a previously unknown enzyme system found in bacteriophage DNA with CRISPR-like properties — able to cut, copy, and paste DNA. Approximately 950 Claude agents processed 210 million tokens of DNA sequence data over 21 hours to identify the system. All physical experiments were conducted by human scientists in a BSL-1/2 facility; no pathogens involved. CEO Dario Amodei noted Stanford researchers had previously identified a similar system, suggesting the work extends rather than entirely supplants existing research. (Source: https://techcrunch.com/2026/09/23/anthropic-says-its-biology-lab-has-already-found-something-big/)
