# Current Discoveries

New items discovered since the last newsletter.

- **Claude Dreaming for Managed Agents** — Asynchronous process that reviews past agent session transcripts alongside a memory store, merges duplicates, replaces stale entries, and surfaces new insights into a reorganised memory store. Accepts 1–100 past sessions per run; can update memory automatically or hold changes pending your review. Launched at Code with Claude 2026 (May 6) as a research preview. Harvey legal reported a ~6× jump in agent task-completion rates after enabling Dreaming for drafting workflows. (Source: https://platform.claude.com/docs/en/managed-agents/dreams)
- **Claude Code v2.1.181 release** — Released June 17, 2026. New features: `/config key=value` syntax sets settings from the prompt bar; `sandbox.allowAppleEvents` enables macOS Apple Events in sandboxed commands; `CLAUDE_CLIENT_PRESENCE_FILE` suppresses mobile push notifications while at the machine. Improvements: idle subagents auto-hide after 30s in the subagent panel; MCP OAuth browser page auto-closes on success; fullscreen URL opening now requires Cmd+click (macOS) / Ctrl+click. (Source: https://github.com/anthropics/claude-code/releases)
- **Streamable HTTP replaces HTTP+SSE for remote MCP** — The HTTP+SSE (Server-Sent Events) transport for MCP servers has been superseded by Streamable HTTP, introduced in the November 2025 MCP spec. Streamable HTTP is now the standard for any MCP server deployed as a remote, cloud-hosted service; existing SSE-only servers should migrate to remain supported. (Source: https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)
- **`sandbox.allowAppleEvents` setting** — New opt-in macOS setting that allows sandboxed shell commands to send Apple Events, enabling Claude to interact with macOS applications via AppleScript and automation scripts without disabling the sandbox entirely (v2.1.181, June 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Shift+Tab cycles through permission modes** — Press Shift+Tab to cycle: default mode → auto-accept edits mode (⏵⏵) → plan mode (⏸). Third press returns to default. The active mode is displayed in the status bar below the prompt. (Source: https://code.claude.com/docs/en/permission-modes)
- **/config key=value syntax** — Set any Claude Code setting directly from the prompt bar (e.g., `/config thinking=false`); works in interactive, `-p`, and Remote Control modes. Replaces manually editing settings.json for quick one-off changes (v2.1.181, June 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **`CLAUDE_CLIENT_PRESENCE_FILE` suppresses push notifications at your desk** — Set this env var to any file path to tell Claude Code you're present; it won't send mobile push notifications while the file exists. Useful in shell profiles or tmux session startup so pings only reach your phone when you're genuinely away (v2.1.181). (Source: https://github.com/anthropics/claude-code/releases)
