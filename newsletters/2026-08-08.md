# Current Discoveries

New items discovered since the last newsletter.

- **Enterprise skill and plugin security scanning** — Claude Enterprise organizations can enable automated security scanning for third-party skills and plugins. The system checks uploads and edits for malicious content before the extension becomes available to org members, helping prevent supply-chain attacks via untrusted skills. Beta feature, launched August 6, 2026. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.225** — Released August 8, 2026. New features: gateway spend-limit support in the usage warning (the limit-reached message now names the cap, its reset time, and the operator's message); workspace trust prompt added to `claude agents` for untrusted directories, matching the behaviour of the `claude` command; Remote Control now shows photos attached from the Claude mobile app directly to Claude; `SendMessage` can now initiate a conversation with Remote Control sessions on other machines by name. Key fixes: transient 401 replacing a long-lived `CLAUDE_CODE_OAUTH_TOKEN` breaking headless sessions on restart; MCP OAuth servers on macOS intermittently failing with a burst of 401 errors after a keychain read timed out; auto mode incorrectly counting a safety-filter refusal of its own permission check toward the consecutive-block limit; cross-session messages staying parked without notice in headless sessions. (Source: https://code.claude.com/docs/en/changelog)
- **Managed Agents session budgets** — Set a hard cap on a Claude Managed Agents session's spend (priced at public list rates) via the new `budget` field when creating a session or deployment. A session that reaches its budget pauses with a `budget_reached` stop reason instead of starting new model requests; updating or removing the budget resumes it. Deployments apply the same budget to each session they start (August 7, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents advisor model** — Give a Claude Managed Agents session an advisor: a separate model (at least as capable as the agent's own) that the session's primary thread can consult mid-turn for strategic guidance. Configure it as a `{"type": "advisor"}` entry in the agent's multiagent roster, specifying the `model` to consult. Useful for hybrid fast-executor / high-intelligence-advisor workflows (August 7, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents GitHub-loaded skills** — Claude Managed Agents sessions can now load skills from a mounted GitHub repository. When a session mounts a repository, any skills in its root `.claude/skills` directory are discovered automatically at session start and available to the agent for that session — no separate skill configuration required (August 7, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
