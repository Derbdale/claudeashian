# Current Discoveries

New items discovered since the last newsletter.

- **`!` bash commands trigger automatic Claude responses** — In v2.1.186 (June 22, 2026), running a `! <command>` shell command automatically feeds the output back to Claude as a follow-up. Disable with `"respondToBashCommands": false` in settings if you prefer manual control. (Source: https://github.com/anthropics/claude-code/releases)
- **Safer automatic edits in `acceptEdits` mode** — Claude Code now prompts for confirmation before writing files that can execute code (scripts, Makefiles, CI configs) when running in `acceptEdits` mode, preventing silent execution-ready changes (Week 23, v2.1.158–v2.1.165). (Source: https://code.claude.com/docs/en/whats-new)
- **Managed deployment version requirements** — Managed Claude Code deployments can now declare an approved version range (`requiredMinVersion` / `requiredMaxVersion`) so enterprise admins can pin users to validated releases and prevent unreviewed client updates (Week 23, v2.1.158–v2.1.165). (Source: https://code.claude.com/docs/en/whats-new)
- **Skills section in `/plugin` Installed tab** — The `/plugin` Installed tab now surfaces a dedicated Skills section, making it easy to see which skills are loaded alongside full plugins without listing them separately (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **`teammateMode: "iterm2"` setting** — New setting enabling iTerm2 teammate mode in Claude Code, allowing tighter terminal integration with iTerm2's session and pane management on macOS (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **OAuth 2.1 as the standard for remote MCP authentication** — Remote MCP servers now use OAuth 2.1 as the required auth standard (introduced in the June 2025 MCP spec). This replaces simple API key patterns with proper token-based auth including scopes, refresh tokens, and PKCE for any internet-exposed MCP server. (Source: https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)
- **Claude Corps national fellowship launched** — Anthropic launched Claude Corps on June 11, 2026 as a national fellowship program for people early in their careers who want to extend AI benefits across America. Participants embed in public-sector and non-profit organisations to apply Claude to real civic problems. (Source: https://www.anthropic.com/news)
- **John Jumper joins Anthropic from Google DeepMind** — Nobel laureate John Jumper (awarded the 2024 Nobel Prize in Chemistry for AlphaFold2) announced he is leaving Google DeepMind to join Anthropic, reported June 19, 2026. One of the highest-profile scientific hires in Anthropic's history. (Source: https://www.cnbc.com/2026/06/19/john-jumper-to-leave-google-deepmind-for-anthropic.html)
- **`claude mcp login` / `claude mcp logout` CLI auth** — New CLI commands to authenticate named MCP servers directly from the terminal (`claude mcp login <name>`, `claude mcp logout <name>`). `--no-browser` flag supports headless / SSH environments where opening a browser is impractical (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **`f` key filters `/workflows` by status** — In the `/workflows` agent detail view, press `f` to filter the session list by status (running, blocked, done), making it easier to spot specific workflow states in long session lists (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **Use just-in-time context loading for agents** — Rather than pre-loading all relevant data into the system prompt, design agents to retrieve information on demand via tools as they need it. Anthropic's guidance: agents should "dynamically load data via tools rather than pre-loading everything," mirroring human cognition and keeping the context window lean for long-horizon tasks. (Source: https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
- **Goldilocks zone for system prompts** — Aim for system prompts that are specific enough to guide behaviour but flexible enough to handle novel situations. Start minimal and add instructions only when you observe failure modes in production; overly detailed system prompts increase token cost and can introduce conflicting constraints. (Source: https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
