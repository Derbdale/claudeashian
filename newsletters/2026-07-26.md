# Current Discoveries

New items discovered since the last newsletter.

- **Claude Opus 5 benchmark results** — Frontier-Bench v0.1: 43.3% agentic coding (doubles Opus 4.8); ARC-AGI-3: 30.2% (20× improvement over Opus 4.8, 3× the next-best model); OSWorld 2.0: 70.57% (surpasses Fable 5 at one-third the cost); CursorBench 3.2: within 0.5% of Fable 5 at half the cost; Zapier AutomationBench: 26.0% (~1.5× next-best); life sciences gains of +10.2 pp on organic chemistry and +7.7 pp on protein tasks. (Source: https://www.anthropic.com/news/claude-opus-5)
- **Opus 5: disabling thinking restricted at high-effort levels** — On Claude Opus 5, `thinking: {"type": "disabled"}` at effort `xhigh` or `max` returns a 400 error; disabling thinking is only allowed at effort `high` or below. Breaking change from Opus 4.8, where disabling thinking worked at any effort level. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`workflowSizeGuideline` configurable setting** — New settings key to configure the Dynamic workflow size guideline in Claude Code, with a medium-size default targeting fewer than 15 agents per workflow (v2.1.219, July 24, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Subagent spawn depth default raised to 3** — In v2.1.219 (July 24, 2026), subagents can now spawn nested subagents up to depth 3 by default (previously 1); set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to restore the old limit. (Source: https://code.claude.com/docs/en/changelog)
- **Mid-conversation tool changes (beta)** — Add or remove tools between turns of a conversation while preserving the prompt cache, available on Claude Fable 5, Mythos 5, Opus 4.8, and Opus 5. Include the `mid-conversation-tool-changes-2026-07-01` beta header (July 24, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`fallbacks` parameter `"default"` mode** — The API `fallbacks` parameter now supports a `"default"` mode that applies Anthropic's recommended fallback models by refusal category automatically, without manually specifying each model. Requires the `server-side-fallback-2026-07-01` beta header (July 24, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`DirectoryAdded` hook event** — New hook event that fires after `/add-dir` or the SDK `register_repo_root` control request registers a new working directory mid-session, enabling automated responses to working directory additions (v2.1.219, July 24, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **Opus 5 prompting: remove redundancy, control cost via effort** — Anthropic's guidance for adapting to Opus 5: remove verification/double-check instructions (it self-corrects without them); remove high-severity-only filters in code review (ask for everything); avoid `MAX_THINKING_TOKENS=0` at high effort (causes 400 errors); add explicit subagent delegation caps; request brevity separately from effort level; provide the full task spec upfront; use `high` effort as the default and reach for `low`/`medium` liberally — reversing the `xhigh` recommendation used for Opus 4.7/4.8. (Source: https://wmedia.es/en/tips/claude-code-opus-5-prompting-tips)
