# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.227** — Released August 10, 2026. Key fixes and improvements: feature flags no longer evaluated without the user's subscription tier when a session starts with an expired login token; Bash commands no longer fail under `claude-code-action` with `allowed_non_write_users` on GitHub-hosted runners; `/tui` no longer resurfaces conversations rewound before their first message; slash-command menu improved (blue highlights only the selected row, matched characters bolded, emoji/accented names render correctly); fewer event-loop stalls on file-not-found suggestions and at-mention size checks. (Source: https://code.claude.com/docs/en/changelog)
- **Auto mode is now the default for Pro/Max/Team in Claude Code** — Starting August 14, 2026, auto mode replaced "Manual" as the default permission mode for new sessions on Pro, Max, and Team plans. In auto mode, Claude proceeds without prompts unless an action is irreversible, destructive, or targets outside your environment. An Anthropic-controlled study with 1,053 paid testers found auto mode caught 89% of deliberate dangerous commands vs. 13.6% for human reviewers. Users who previously selected a different default may receive a one-time prompt asking whether they want to switch. Enterprise/API users can opt in separately; rollout to those platforms announced for the following month. (Source: https://claude.com/blog/auto-mode-default-in-claude-code)
- **Claude text watermarking (SynthID-Text)** — All Claude models released on or after August 2, 2026 embed imperceptible watermarks in generated text using Google DeepMind's SynthID-Text method. The watermark statistically biases word choices using a secret cryptographic key and preceding context, without hidden characters, added tokens, or quality impact. Less effective on factual or code-heavy content; detection improves on longer passages. No impact on cost or speed. Launched to comply with the EU AI Act Code of Practice on Transparency; older models receive support over coming months. A detection API is forthcoming. (Source: https://www.anthropic.com/news/claude-text-watermark)
- **Claude in Chrome upgraded to full Cowork session** — The Claude Chrome side panel, previously a standalone chat interface, became a full Claude Cowork session on August 12, 2026. Conversations now save to history and sync across desktop, web, and mobile; skills and connectors work in-browser; tasks continue across devices. Also enables browser automation for internal dashboards, legacy systems, and vendor portals. Safety checks run before consequential actions to mitigate prompt injection risk. Available on Max and Team plans; rolling out to Pro. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Tag proactive responses with full channel context** — Claude Tag's Slack integration now analyses full channel history and memory to determine when to respond proactively, not just when @-mentioned (August 13, 2026). Roughly 30% better at determining when, and when not, to proactively respond. Four response strategies: inline replies, threaded discussions, routing to existing workstreams, or staying silent. Customisable with plain-language instructions ("Never respond unless tagged"). No additional cost. (Source: https://releasebot.io/updates/anthropic/claude)
- **Claude Code v2.1.229** — Released August 12, 2026. New features: `claude remote-control --continue` resumes the most recent Remote Control session; server-supplied Claude Code hooks for self-hosted runner sessions; SSE keepalive pings during long thinking pauses (prevents idle-timeout disconnects on Vertex/Bedrock); plugin marketplace `command` sources allow local commands to print plugin directories, re-resolved each session; `ListAgents` now marks disconnected Remote Control sessions as `offline` and cloud sessions as `cloud`. Key fixes: streaming response corruption (long responses partly disappearing then printing twice); crashes on narrow terminals; crashes on Windows with extended-length and UNC paths; GitHub review workflow completing without posting the review; multi-second UI stalls with thousands of IDE diagnostics. (Source: https://code.claude.com/docs/en/changelog)
- **Subagent forking on by default + cross-session @ mentions (v2.1.232)** — Released August 13, 2026. Subagents using `subagent_type: "fork"` now inherit the full conversation and prompt cache by default; non-teammate agents in interactive sessions run in the background by default. Type `@` in any prompt to mention another Claude Code session by name, and `SendMessage` delivers to exact name matches without a confirmation step. GitLab token redaction extended to `glrt-`, `gloas-`, `glptt-`, `glagent-`, and related families. Security fixes: PowerShell permission bypass via variable-writing parameters; Windows Git Bash Cygwin-style symlink bypass; nested git repository trust inheritance now requires own confirmation per repo. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.233: GitLab worktree, todo tool removal, memory limits** — Released August 14, 2026. `--worktree` and `claude agents` now support GitLab MR URLs (displayed as `!N`). Todo/task-tracking tools (TaskCreate, TaskGet, TaskUpdate, TaskList, TodoWrite) removed for Opus 4.8+, Sonnet 5+, Fable 5+, and Mythos 5+ (restore with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`). New `CLAUDE_CODE_TOOL_MEMORY_LIMIT` env var caps Bash tool memory on Linux via cgroup. `forward_user_identity` apps gateway setting enables per-user spend attribution. Fixed idle Linux sessions consuming 100% CPU with sandboxing enabled. Fixed Windows NT `\??\` device paths bypassing UNC path validation (NTLM credential-leak vector). (Source: https://code.claude.com/docs/en/changelog)
- **Compliance API extended to Claude Cowork and Claude Code** — Anthropic expanded its Compliance API (beta) to support Cowork and Claude Code sessions across multiple platforms (August 11, 2026). Provides a consolidated, server-hosted transcript for each session containing prompts, responses, tool activity, verified user information, and timestamps — enabling unified auditing without separate logging infrastructure. (Source: https://releasebot.io/updates/anthropic/claude)
