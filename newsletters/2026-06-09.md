# Current Discoveries

New items discovered since the last newsletter.
- **`requiredMinimumVersion` / `requiredMaximumVersion` managed settings** — Claude Code refuses to start if its version falls outside the configured range, enabling fleet-wide version pinning in enterprise deployments (v2.1.163). (Source: https://code.claude.com/docs/en/changelog)
- **`fallbackModel` setting** — Configure up to three fallback models tried in order when the primary model is overloaded or unavailable; `--fallback-model` flag now also applies to interactive sessions (v2.1.166). (Source: https://code.claude.com/docs/en/changelog)
- **Glob pattern support in deny rules** — Using `"*"` in the tool-name position of a deny rule now blocks all tools, enabling a blanket tool lockdown with a single rule (v2.1.166). (Source: https://code.claude.com/docs/en/changelog)
- **`--safe-mode` flag and `CLAUDE_CODE_SAFE_MODE` env var** — Disables all customisations (CLAUDE.md, plugins, skills, hooks, MCP servers) for a clean troubleshooting environment without a full reinstall (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **`disableBundledSkills` setting and `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` env var** — Hides all built-in bundled skills, workflows, and slash commands, useful for organisations that want only their own skills visible (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **CLAUDE.md "too long" warning scales with model context window** — The warning threshold now adjusts dynamically based on the active model's context size rather than a fixed line count (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **`Stop` / `SubagentStop` hooks support `additionalContext`** — These hook events can now return `hookSpecificOutput.additionalContext` to inject feedback into the running turn and continue execution rather than just stopping it (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **Claude Opus 4.1 deprecation announced** — `claude-opus-4-1-20250805` deprecated June 5, 2026, with API retirement scheduled for August 5, 2026. Anthropic recommends migrating to Claude Opus 4.8. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Windsurf IDE rebranded to Devin Desktop in Claude Code** — Claude Code's `/ide` menu and related IDE commands renamed Windsurf to Devin Desktop following the Windsurf acquisition/rebrand (v2.1.162). (Source: https://code.claude.com/docs/en/changelog)
- **`claude agents --json` `waitingFor` field** — The JSON output now includes a `waitingFor` field showing what a blocked or waiting session is waiting on, making agent orchestration scripts much easier to write (v2.1.162). (Source: https://code.claude.com/docs/en/changelog)
- **`/plugin list` command** — Lists all installed plugins with `--enabled` and `--disabled` filters to see active state at a glance (v2.1.163). (Source: https://code.claude.com/docs/en/changelog)
- **`/cd` command** — Move a session to a new working directory mid-session without resetting the prompt cache (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **`CLAUDE_CODE_NO_FLICKER=1` for smooth streaming** — Set this env var to enable the fullscreen TUI renderer, eliminating terminal flicker during streaming and keeping syntax highlighting stable. Add it to your shell profile for a permanently smoother experience. (Source: https://aiproductivity.ai/guides/claude-code-tips-tricks/)
