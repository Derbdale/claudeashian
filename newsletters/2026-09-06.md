# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.261** — Released September 5, 2026. New: `bashOutputMaxChars` and `taskOutputMaxChars` settings raise inline command and background-task output limits up to 128K characters; organization policy diagnostics added to `/status` and `claude doctor` explaining why org policies fail to load; `--append-subagent-system-prompt-file` flag loads large subagent system prompts from a file; `/skill-doctor` shows unused loaded skills and their context cost. Breaking change: default prompt word-editing keys changed to Bash-style — Ctrl+W deletes to whitespace, Alt+F/Alt+D stop at word end, punctuation separates words (revert with `keybindingFlavor: "classic"`). Fixes character input ordering on fast key repeat. (Source: https://code.claude.com/docs/en/changelog)
- **`ant apply` Infrastructure as Code (ant CLI v1.30.0)** — The new `ant apply` command manages Managed Agents resources — agents, environments, skills, memory stores, and deployments — through code. Describe resources in files, run `ant apply` to preview changes, then commit the resulting `claude-lock.json` lockfile for consistent deployments across environments (September 3, 2026). (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Fable 5.1 breaking API changes** — Released September 1, 2026. (1) `tool_choice` types `any` and `tool` are no longer supported on Fable 5.1/Mythos 5.1; use strict tool use instead. (2) Thinking blocks are only preserved when the receiving model is the same version as or newer than the producing model — older model versions will drop them. (3) Admin API now requires the `anthropic-version` header on all enterprise endpoints (user management, analytics, compliance). (4) Turn-scoped system messages (beta, `mid-conversation-output-config-2026-07-01` header) allow clearing system messages after a single turn to reduce context bloat. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **Anthropic IPO prospectus after Labor Day; Q2 2026 first operating profit disclosed** — Anthropic plans to release its S-1 prospectus after Labor Day 2026, targeting a public listing in late September or early October. Key financial disclosures: Q2 2026 was Anthropic's first-ever profitable quarter (~$559M operating profit); Q2 revenue was $10.9 billion (up from $4.8B in Q1 2026); annual revenue run rate topped $65 billion at end of July 2026. The IPO targets a valuation exceeding $2 trillion and a raise of at least $130 billion — which would be the largest IPO in history. Underwriters: Morgan Stanley, Goldman Sachs, JPMorgan, and Citigroup. (Source: https://www.fool.com/investing/2026/09/03/anthropic-planning-unveil-ipo-details-labor-day/)
- **`/skill-doctor` command** — Lists all loaded skills that went unused in the current session, along with their context cost in tokens. Use it to identify and prune skills that bloat your context window without providing value. Introduced in Claude Code v2.1.261 (September 5, 2026). (Source: https://code.claude.com/docs/en/changelog)
