# Current Discoveries

New items discovered since the last newsletter.

- **Auto mode safety guardrails for destructive commands** — In v2.1.183 (June 19, 2026), auto mode blocks destructive git commands when you didn't ask to discard work (`git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop`) and blocks `git commit --amend` when the commit was not made by the agent in the current session. Infrastructure-destroying commands (`terraform destroy`, `pulumi destroy`, `cdk destroy`) are also blocked unless explicitly requested. (Source: https://code.claude.com/docs/en/changelog)
- **Model deprecation warnings in headless mode** — Claude Code v2.1.183 emits a warning on stderr in print mode (`-p`) and in agent frontmatter when the requested model is deprecated or has been automatically updated to a newer version, making model-migration issues visible in CI pipelines and scripts. (Source: https://code.claude.com/docs/en/changelog)
- **`attribution.sessionUrl` setting** — New setting that controls whether the claude.ai session link is included in commits and PRs. Useful in web and Remote Control sessions where the session URL is ephemeral and the link would be meaningless in the git log (v2.1.183). (Source: https://code.claude.com/docs/en/changelog)
- **Enterprise-managed MCP connector auth with zero-touch Okta SSO** — Enterprise and Team admins can authorize MCP connectors once via an identity provider (Okta supported at launch); employees get zero-touch access on first login through their existing IdP groups and roles, removing the per-user authorization step. Centralized authorization spans Claude Chat, Claude Code, and Cowork. Connectors supported at launch: Asana, Atlassian, Canva, Figma, Granola, Linear, Supabase; Slack coming soon. (Source: https://claude.com/blog/enterprise-managed-auth)
- **`code_execution_20260521` tool version** — Updated code execution tool that discloses the 90-second per-cell execution time limit in the tool description, so Claude can budget long-running cells accurately. No beta header required (June 11, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`web_search_20260318` and `web_fetch_20260318` tool versions** — Updated web search and web fetch tools with a new `response_inclusion` parameter that drops consumed result blocks from the API response, reducing context window usage in agentic workflows. No beta header required (June 11, 2026). (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Anthropic opens Seoul office** — Third Asia-Pacific office (after Tokyo and Bengaluru) opened June 17, 2026, led by KiYoung Choi (former General Manager of Snowflake Korea). Enterprise deployments at launch include NAVER (Claude Code across its full engineering org), Samsung SDS, LG CNS, Nexon, Hanwha Solutions, and Channel Corp (230,000+ businesses). Research partnerships with the National AI Research Lab consortium (KAIST, Korea University, Yonsei, POSTECH) and an MOU with South Korea's Ministry of Science and ICT on public-sector AI adoption, model safety testing, and cybersecurity. (Source: https://www.anthropic.com/news/seoul-office-partnerships-korean-ai-ecosystem)
- **`/config --help` and updated toggle behavior** — `/config --help` lists all available shorthand setting keys. Toggle behavior updated in v2.1.183: Enter and Space now change the setting value; Esc saves and closes (previously Esc reverted without saving). (Source: https://code.claude.com/docs/en/changelog)
