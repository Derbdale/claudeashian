# Current Discoveries

New items discovered since the last newsletter.
- **Claude Voice Mode expanded to Opus and Sonnet models** — Launched July 23, 2026; voice mode now lets users choose between Opus, Sonnet, and Haiku models (previously Haiku-only). Defaults to the last model used in text chat at its fastest available version. Paid subscribers can switch models mid-conversation. Adds cross-app voice automation with Gmail, Google Calendar, Slack, Canva, and Notion. Expanded multilingual support to include English, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Portuguese, and Spanish. Free users are limited to Haiku and one connected app; paid plans unlock all models and multi-app automation. (Source: https://techcrunch.com/2026/07/23/anthropic-updates-claude-voice-mode-with-more-capable-models/)
- **Managed Agents session thread event deltas** — As of July 22, 2026, `GET /v1/sessions/{session_id}/threads/{thread_id}/stream` accepts the `event_deltas[]` query parameter, enabling thread-level previewing of subagent text as it generates — before the complete `agent.message` event arrives. Each connection previews only the thread it's reading. Extends the session-level event deltas (launched June 30) to individual multi-agent thread streams. (Source: https://platform.claude.com/docs/en/release-notes/overview)
