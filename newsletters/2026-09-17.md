# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.274** — Released September 17, 2026. New features: visible warning for critical memory usage with steps to free memory or restart safely; `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` env var bounds MCP server connection wait time; `effort` attribute added to OpenTelemetry trace spans; `claude_code.managed_settings_resolved` OTel event for managed-settings sources. VS Code gains continuation of interrupted steps after window reload, Memory and Instructions in the Customize menu, and a `claudeCode.lockEditorGroups` setting. Web sessions add a "Compare against" branch picker for cloud session diffs. Claude Tag (Slack) adds a Guests setting to channel/workspace forms and fixes Claude not answering when @mentioned after other apps. Key fixes: self-healing corrupted transcripts that caused retrying "unexpected tool_use_id" errors; Streamable HTTP MCP tool calls timing out after 5 minutes; MCP prompts/resources not refreshing without `listChanged`; active `/goal` being lost when resuming compacted sessions; per-turn slowdown with language server project-wide diagnostics. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Cowork and chat unified into one Claude** — Announced September 16, 2026. Anthropic is consolidating Claude from three modes (Chat, Cowork, Claude Code) into two: Claude (chat + Cowork merged) and Claude Code. Claude Docs, Slides, and Design capabilities are now accessible within any conversation. The transition is automatic — "there's nothing to turn on" — starting with Pro and Max subscribers on web, desktop, and mobile, with Free and Team following and Enterprise receiving 30 days' notice. Users previously found switching between Chat and Cowork "frustrating"; the merged interface determines automatically what tools a task requires while preserving existing context and skills. (Source: https://9to5mac.com/2026/09/16/anthropic-merging-claude-cowork-with-chat/)
