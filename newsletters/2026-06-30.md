# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.196 release** — Released June 29, 2026. Adds organisation default models (admins configure in the org console; shows as "Org default" or "Role default" in `/model`), readable default session names, and clickable file attachments (Cmd/Ctrl-click reveals file in Finder/Explorer). Streaming idle watchdog is now on by default for all providers — aborts and retries after 5 minutes of silence; disable with `CLAUDE_ENABLE_STREAM_WATCHDOG=0`. Security: `claude mcp list`/`get` no longer spawns `.mcp.json` servers that a repo self-approved via a committed `.claude/settings.json`; untrusted workspaces show ⏸ Pending approval. `/code-review` token usage cut ~25% by merging five cleanup finders into one. Dozens of bug fixes: background session reliability across restarts/daemon restarts, PowerShell git/grep exit-code handling, MCP OAuth scope failures on enterprise IdPs, and `claude agents` session status accuracy. (Source: https://github.com/anthropics/claude-code/releases)
- **Fast mode removed from Opus 4.6, deprecated on Opus 4.7** — June 29, 2026: fast mode silently removed from `claude-opus-4-6`; requests with `speed: "fast"` now run at standard speed and standard rates without error. June 25, 2026: fast mode deprecated for `claude-opus-4-7` with removal on July 24, 2026 (after which `speed: "fast"` on 4.7 will return an error). Migrate to Claude Opus 4.8 to continue using fast mode. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude in Microsoft Foundry generally available** — Claude Opus 4.8 and Haiku 4.5 launched in Microsoft Foundry on Azure on June 29, 2026, running on NVIDIA GB300 Blackwell Ultra GPUs. Supports Azure-native authentication, billing, and governance; optional US data zone for data residency requirements; single consolidated invoicing with Microsoft Enterprise Agreement support. Two deployment options: hosted on Azure (Azure identity and networking) or hosted on Anthropic (full API feature set). Builds on the Microsoft, NVIDIA, and Anthropic partnership announced November 2025. (Source: https://claude.com/blog/claude-in-microsoft-foundry)
- **Claude API rate limits raised and usage tiers consolidated** — June 26, 2026: Claude Sonnet and Haiku rate limits now match Claude Opus at every tier. API usage tiers consolidated to three: Start, Build, and Scale. Most organisations move to a higher tier; no organisation receives lower limits. Current tier and limits visible in the Claude Console under Settings > Limits. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **California signs Claude deal for all state and local governments at 50% discount** — Announced June 29, 2026: Anthropic and California Governor Gavin Newsom agreed to make Claude the first AI tool available across all California state agencies and local governments at half the standard commercial price, with complimentary workforce training, technical assistance, and workflow support. (Source: https://techcrunch.com/2026/06/29/anthropic-and-gov-newsom-forge-deal-allowing-california-government-to-use-claude-at-half-price/)
- **Fable 5 imminent return expected after 18-day suspension** — As of June 27, 2026, the Trump administration was close to lifting the June 12 export-control suspension of Claude Fable 5, with insiders telling Axios that access could return within days, pending Pentagon and NSA sign-off. As of June 30, Fable 5 remains suspended for general users (Mythos 5 was partially restored June 26 for ~100 US critical-infrastructure organisations). Prediction markets price a ~57% chance of full restoration by July 1 and ~75% by July 17; Anthropic's July 8 ID verification policy is widely seen as the compliance mechanism for a US-first restoration path. (Source: https://www.axios.com/2026/06/27/anthropic-fable-5-return-soon)
