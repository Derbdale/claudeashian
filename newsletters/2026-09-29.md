# Current Discoveries

New items discovered since the last newsletter.
- **Claude Sonnet 5.5 launched** — Released September 28, 2026. Second model in the Claude 5.5 family. Same pricing as Sonnet 5 at $2/$10 per MTok with $0.20 cache reads; generates output 30%+ faster and typically uses up to 30% fewer tokens per task. Scores 70.6% on Terminal-Bench 4.0 agentic coding (up from Sonnet 5's ~10%) and 55.5% on CursorBench, placing it near Opus 5.5 levels on coding. First Sonnet model with cybersecurity safeguards comparable to Opus 5.5; new safety classifiers prevent reasoning extraction attacks. Model ID: `claude-sonnet-5-5`. (Source: https://www.anthropic.com/claude-sonnet-5-5)
- **Claude Code v2.1.284** — Released September 28, 2026. Sets Claude Sonnet 5.5 as the new default model. Adds "Yes, but ask again next time" option in auto mode for file access permission prompts. Gateway improvements include certificate client authentication and Google Cloud telemetry export support. New `/mcp reconnect all` command retries all failed MCP server connections. Numerous fixes across response streams, model availability errors, session handling, plugin marketplaces, and VS Code integration. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Anthropic IPO S-1 prospectus leaked to Reuters** — Reported September 28, 2026. Reuters obtained Anthropic's IPO prospectus, revealing: 2025 revenue of $4.59B (up 1,088% YoY from $386M in 2024); operating loss of $8.1B for 2025; net loss of $42B including a ~$34B accounting charge tied to financing instruments that could convert to equity; infrastructure/compute spending of $7.33B in 2025 (~58% of $12.65B total operating expenses); and $518B in future cloud, compute and infrastructure obligations. Anthropic's IPO is now expected after the US midterm elections in November 2026, targeting a $2 trillion valuation and a raise of up to $100 billion on Nasdaq. (Source: https://wolfstreet.com/2026/09/28/anthropic-lost-42-billion-on-4-6-billion-in-revenues-in-2025-leaked-ipo-prospectus/)
