# Current Discoveries

New items discovered since the last newsletter.

- **Claude Cowork "Record a Skill"** — Launched July 21, 2026 on Pro, Max, and Team plans (phased rollout). Screen-record yourself doing a task once; Claude analyzes the recording and converts it into a reusable, rerunnable skill without any prompt engineering. Extracts semantic intent rather than recording click coordinates, making automations more resilient to UI layout changes than traditional RPA tools. Claude suggests API-based connectors when available for more reliable automation. (Source: https://www.explainx.ai/blog/claude-cowork-record-a-skill-screen-recording-july-2026)
- **Claude Code v2.1.218** — Released July 22, 2026. `/code-review` now runs as a background subagent, keeping review work out of the main conversation and preserving stacked slash commands as its review target. Screen-reader announcements added for word and line deletions (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) in `--ax-screen-reader` mode. Fixed Windows path corruption where `\u`-prefixed segments like `C:\Users\unicorn` were being mangled into CJK characters in tool inputs. Left arrow key after editing now asks for confirmation before discarding conversation; Esc in agent view returns to the backgrounded conversation. `claude mcp list` and `/mcp` now show HTTP status/error text; hidden whitespace in MCP config values triggers a warning. Skills with `context: fork` now run in background by default. Subagent concurrency cap defaults to 20. (Source: https://code.claude.com/docs/en/changelog)
- **Managed Agents API updates (July 22, 2026)** — Three enhancements: (1) Set an `effort` level on an agent's model configuration by passing `effort` inside the `model` object when creating a Managed Agent. (2) Session seeding: pass up to 50 `user.message` and `user.define_outcome` events via `initial_events` on `POST /v1/sessions` to start the agent loop immediately without a separate send-events request. (3) The `version` field is now optional when updating an agent — supply it for optimistic concurrency (mismatch returns 409) or omit it to apply updates unconditionally. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Managed Agents webhooks for environment and memory store lifecycle** — As of July 22, 2026, Managed Agents webhooks cover four `environment.*` event types and three `memory_store.*` event types, enabling automated reactions to environment and memory store creation, update, and deletion events without polling. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Anthropic Economic Index connector** — Launched July 22, 2026. A free connector in the Claude connectors directory that grounds Claude answers in the Anthropic Economic Index — a public dataset measuring how AI is used across the economy. Enable it in claude.ai via the connectors menu; no installation required. Ask questions like "Which occupations use AI the most?" or "What do teachers use Claude for?" with answers drawn directly from the Index data. Works across all Claude models. (Source: https://www.anthropic.com/news/anthropic-economic-index-connector)
- **AMD and Anthropic announce $5B chip-and-investment deal** — Announced July 22, 2026. AMD will invest up to $5 billion in Anthropic — its first equity stake in the company — tied to deployment milestones. In exchange, Anthropic committed to deploying up to 2 gigawatts of AMD Instinct MI450 Series GPUs beginning H1 2027, housed in AMD Helios rack-scale solutions with MI455X GPUs, EPYC Venice CPUs, Pensando networking, and ROCm software. The deal, valued at tens of billions of dollars in chips, is AMD's largest strategic AI partnership to date and strengthens its position against Nvidia in the AI infrastructure market. (Source: https://www.bloomberg.com/news/articles/2026-07-22/amd-to-invest-up-to-5-billion-in-anthropic-chip-deal-wsj-says)
