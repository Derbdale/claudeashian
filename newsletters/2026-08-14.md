# Current Discoveries

New items discovered since the last newsletter.

- **iOS Simulator pane in Claude Code Desktop** — Claude Code Desktop on macOS gets a built-in iOS Simulator pane (public beta on Pro, Max, and Team plans). When Claude builds or launches an app in the simulator, the pane opens alongside the conversation and streams the device screen live, letting you watch Claude tap through the app to verify changes or drive the device yourself. Launched Week 30 (July 20–24, 2026). (Source: https://9to5mac.com/2026/07/21/claude-code-brings-live-ios-app-testing-into-its-mac-app/)
- **Claude Security plugin (multi-agent vulnerability scan)** — A dedicated security plugin that runs a multi-agent scan of your codebase from within a Claude Code session: agents map the architecture, build a threat model, hunt for vulnerabilities, independently review every finding, and produce a report. Distinct from the bundled security-guidance plugin (which reviews changes inline). You pick which findings to turn into patches. Available as a marketplace plugin. Launched Week 30 (July 20–24, 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Claude Code v2.1.229** — Released August 12, 2026. New features: server-supplied hooks for self-hosted runner sessions; SSE keepalive pings on gateway streaming responses during long thinking pauses (prevents Vertex/Bedrock idle-timeout disconnects); plugin marketplace `command` sources allow local commands to print plugin directories, re-resolved each session; `ListAgents` now marks disconnected Remote Control sessions as `offline` and cloud sessions as `cloud`; improved workflow agent staggering for prefix cache reuse. Key fixes: streaming response corruption where long responses partly disappeared and were printed twice; tool call crashes with non-string `glob`/`file_path`/`command` fields; terminal RangeError crashes in very narrow windows; Windows extended-length and UNC path crashes; multi-second IDE stalls with thousands of diagnostics; GitHub workflow not posting code reviews on PRs; dynamic workflows using host core count instead of container limit. (Source: https://code.claude.com/docs/en/changelog)
- **Subagent forking on by default + cross-session @ mentions (v2.1.232)** — Released August 13, 2026. Subagents using `subagent_type: "fork"` now inherit the full conversation and prompt cache by default; non-teammate agents in interactive sessions run in the background by default. Type `@` in any prompt to mention another Claude Code session by name, and `SendMessage` delivers to exact name matches without a confirmation step. Fable 5 `/advisor` is re-offered for organisations with Fable access. Also: GitLab token families now redacted (`glrt-`, `gloas-`, and others); settings aliases `additionalMarketplaces` and `allowedMarketplaces` accepted as alternatives to `extraKnownMarketplaces` and `strictKnownMarketplaces`; PowerShell permission bypass via variable-writing parameters fixed; Windows Git Bash Cygwin-style symlink bypass fixed. (Source: https://code.claude.com/docs/en/changelog)
- **GitLab plugin marketplace support** — Claude Code's plugin marketplace now supports GitLab repositories with nested subgroup paths, enabling organizations hosted on GitLab to publish and distribute plugins through the marketplace using their full repo hierarchy. Added in v2.1.232 (August 13, 2026). (Source: https://code.claude.com/docs/en/changelog)
