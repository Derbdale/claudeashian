# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.224** — Released August 7, 2026. New features: `claude self-hosted-runner` command turns your own machines or containers into environments where Claude Code web, mobile, and desktop sessions can run (Team and Enterprise plans); archive plugin source installs plugins from HTTPS-hosted zip files without git or npm, with optional SHA-256 pinning; cross-session messaging lets Claude Code sessions discover and message each other via `SendMessage` and `ListAgents` tools (macOS and Linux); sandbox credential masking gains `extract`/`onExtractNoMatch` for structured env values, `decode: "jwt"` with `maskClaims` for JWT-aware masking, and `awsPairs`/`sigv4` for AWS SigV4 re-signing; new `crossSessionInbound` and `dialogExpiry` settings manage inter-session message permissions; `ANTHROPIC_BEDROCK_REGION_PREFIX` env var enables Bedrock cross-region inference profile preference; 200-subagent-per-session spawn cap removed. Improvements: fullscreen mode keeps full pre-compaction history in scrollback; Remote Control now shows compaction progress, persistent connection-failure indicators, and archives stale server sessions. Bug fixes: long project paths resolving to wrong session directories; `SendMessage` falsely reporting success on delivery failure; sandbox filesystem deny entries with trailing slashes bypassable on Linux/macOS. (Source: https://code.claude.com/docs/en/changelog)
- **Fable 5 biology safeguards substantially improved** — Announced August 7, 2026. Anthropic rewrote the biology safety classifier's constitution and retrained it using feedback from internal and external experts. Result: 85% reduction in biology-related fallbacks overall; 67% fewer total fallbacks on Claude.ai, 55% fewer on Cowork, 17% fewer on Claude Code, 7% fewer on the Claude Platform. Everyday health and educational queries — interpreting lab results, understanding symptoms, learning biology — are now permitted. Clinical support for healthcare professionals is expanded. Fable 5 continues routing dual-use biology queries (virology, toxicology, molecular design) to Opus 5. (Source: https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards)
