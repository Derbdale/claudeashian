# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.329** — Released November 19, 2026. `/tasks` now shows this session's scheduled tasks, `/loop` wakeups, the goal, and conversation forks; press `x` to stop one. A trust dialog now warns where a folder's hooks are declared, and the conversation warns when managed-settings hooks fail to load. `/mcp` and `/status` show the JSON-RPC error from a remote HTTP MCP server that refuses a connection. Code Mode now works with OpenTelemetry events and metrics. Behavior changes: most tasks saved by earlier versions need rescheduling in new signed-in sessions; `/code-review` with no target now reviews the whole branch against the default branch; a PreToolUse hook that errors no longer blocks a Code Mode script's tool call (use `"onFailure": "block"` to restore blocking); auto mode runs `git status` less often in large repos. 91 bug fixes including `~/.claude.json` reset during network stalls, repeated macOS sign-outs when Keychain is read-only, and PDFs/images served as `application/octet-stream` being saved as `.bin`. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic (ANT) closes first day of trading up 17% at $97.17** — Anthropic shares opened on the Nasdaq on November 19, 2026 at $111.50 — 34% above the $83 IPO price — before closing at $97.17, up 17.1% on the day. Market capitalisation at close was approximately $1.27 trillion. The debut was the largest IPO first-day dollar gain on record. (Source: https://www.bnnbloomberg.ca/business/company-news/2026/11/19/anthropic-set-to-begin-trading-as-a-us15-trillion-company-in-the-biggest-ipo-on-record/)
