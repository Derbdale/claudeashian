New items discovered since the last newsletter.

- **Claude Fable 5.1 & Claude Mythos 5.1 launched** — Released September 1, 2026. New features: time format settings supporting 12h/24h display and UTC options; enhanced auto mode with containment escape rules; subagent model override via environment variables; session-specific effort adjustment with `/effort s`; one-time confirmation prompt before Claude's first file read outside the current working directory. Various bug fixes across Remote Control, background sessions, and MCP servers. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Claude Code v2.1.258** — Released September 2, 2026. Bug-fix release: fixes macOS 12 (Monterey) launch failures introduced in v2.1.255; resolves remote and scheduled session errors that appeared following permission re-approval. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **`/effort s` for session-scoped effort** — Run `/effort s` to set the effort level for the entire current session in one step, rather than adjusting per-turn. Introduced in Claude Code v2.1.257 (September 1, 2026). (Source: https://releasebot.io/updates/anthropic/claude-code)
