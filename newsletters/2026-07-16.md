# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.211** — Released July 15-16, 2026. New `--forward-subagent-text` flag and `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` env var include subagent text and thinking in stream-json output. Bug fixes: parallel logout-on-sleep fixed; plugin MCP servers reconnect after idle; Bedrock/Vertex prompt-caching regression fixed; file upload validation hardened (DOS device suffixes, trailing dots, hard links); subagents no longer revert to parent model on resume; `/loop` no longer hides session from `/resume`; `/clear` now correctly resets session cost counter; background agents no longer auto-respawn after user kill; integer env vars now accept scientific notation (e.g. `1e6`). (Source: https://code.claude.com/docs/en/changelog)
- **Self-serve HIPAA configuration for Enterprise and API orgs** — Launched July 14-15, 2026. Eligible admins can review the Business Associate Agreement (BAA), download the implementation guide, and enable HIPAA configuration in a single flow via Organization settings > Data and privacy > HIPAA Compliance. The BAA is a standard agreement (not modifiable); Claude Code is covered under BAA only with zero data retention (ZDR) enabled on qualified accounts. (Source: https://releasebot.io/updates/anthropic)
- **Admin API user management for Claude Enterprise** — Launched July 14, 2026. Organizations can now manage members, adjust roles, remove participants, handle invitations, and administer groups programmatically through the Admin API. (Source: https://releasebot.io/updates/anthropic)
- **Anthropic commits $10M CAD to Canadian AI research** — Announced July 14, 2026; delivered as Claude API credits to eight institutions spanning Edmonton, Montréal, Toronto, Ottawa, and beyond: Alberta Machine Intelligence Institute, Mila, Vector Institute, CHEO, CAMH, Université Laval, University of Toronto, and University of Saskatchewan. Each receives $1M in Claude credits. Research covers reinforcement learning, AI trust and safety, health research, and language research. Anthropic retains no control over research directions or findings. (Source: https://www.anthropic.com/news/canadian-ai-research)
- **Ode with Anthropic launched** — Announced July 15, 2026; a "Claude-first" AI implementation services firm co-founded by Anthropic, Blackstone, and Hellman & Friedman, built on acquired startup Fractional AI. Led by CEO Chris Taylor and CTO Eddie Siegel. Backed by Goldman Sachs, General Atlantic, Leonard Green, Apollo Global, GIC, and Sequoia Capital. Operates as a "scaled boutique" deploying elite generalist engineers at enterprises where AI adoption is a top CEO priority. Will use rival AI when needed but defaults to Claude. Mirrors OpenAI's "The Deployment Company" strategy. (Source: https://techcrunch.com/2026/07/15/anthropic-blackstone-bet-the-next-trillion-dollar-ai-business-is-implementation-not-models/)
