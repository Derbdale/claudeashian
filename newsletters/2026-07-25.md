# Current Discoveries

New items discovered since the last newsletter.

- **Claude Opus 5 launched** — Released July 24, 2026; described as "a thoughtful and proactive model that comes close to the frontier intelligence of Claude Fable 5 at half the price." Becomes the default model in Claude Code v2.1.219 with a 1M token context window. Priced at $5/$25 per MTok, positioning it between Fable 5 ($10/$50) and Opus 4.8 in cost. (Source: https://releasebot.io/updates/anthropic/claude)
- **`sandbox.network.strictAllowlist` setting** — New in Claude Code v2.1.219 (July 24, 2026); enables a stricter network allowlist for sandboxed commands, restricting outbound connections to an explicit list of approved hosts beyond the existing sandbox network configuration. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Aggressive language degrades output quality** — Phrasing like "CRITICAL!", "YOU MUST", "NEVER EVER" overtriggers newer Claude models and produces worse results than calm, direct instructions. Anthropic's own best-practices guidance recommends straightforward instruction without emphasis inflation. (Source: https://claude.com/blog/best-practices-for-prompt-engineering)
- **Let Claude interview you for complex tasks** — Start with a minimal prompt and ask Claude to interview you about the task. Claude will surface implementation details, edge cases, and tradeoffs you might not have anticipated, producing richer context than trying to specify everything upfront. (Source: https://www.aiforanything.io/blog/claude-prompt-engineering-context-engineering-guide-2026)
