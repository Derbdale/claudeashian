# Current Discoveries

New items discovered since the last newsletter.
- **Claude Reflect usage dashboard** — Beta feature launched July 9, 2026; accessible via Settings > Reflect on the web and desktop app. Shows topics discussed, usage patterns, and task types over selectable 1, 3, 6, or 12 month windows. Includes mindful AI prompts ("What's one thing you'd keep doing yourself?"), quiet hours, and break reminders via Settings > Time and focus. Available to Free, Pro, and Max users with memory enabled; excludes incognito chats and health integration data. (Source: https://www.anthropic.com/news/reflect-with-claude)
- **Claude Code v2.1.206** — Released July 10, 2026. Adds directory path suggestions to `/cd` (matching `/add-dir` behaviour); a `/doctor` check that flags redundant checked-in `CLAUDE.md` files; `/commit-push-pr` now auto-allows `git push` to configured push remotes; agents view gets full-width status column with classifier-written headlines. Fixes: MCP servers now honour per-server `request_timeout_ms`; OAuth MCP tokens no longer require re-auth after refresh; expired login no longer shows misleading model error. `Ctrl+X` in agents view now permanently removes completed sessions. (Source: https://github.com/anthropics/claude-code/releases)
- **API key expiration settings in Claude Console** — July 8, 2026: API keys can now be created with a custom expiration duration or set to "Never" expire. Keys with a lifetime of 7+ days receive email reminders before expiry. The Admin API returns the expiration timestamp via the `expires_at` field on key objects. (Source: https://releasebot.io/updates/anthropic/claude-developer-platform)
- **`Ctrl+X` removes completed sessions** — In the agents view, press `Ctrl+X` to permanently remove a completed session from the list (v2.1.206, July 10, 2026). (Source: https://github.com/anthropics/claude-code/releases)
