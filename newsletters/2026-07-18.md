# Current Discoveries

New items discovered since the last newsletter.

- **Claude memory redesigned as individual categorized entries** — As of July 10, 2026, Claude's memory works as a set of individual, categorized entries that Claude reads and updates in real time during conversations, replacing the previous daily memory summary. The Memory panel lists all entries grouped by category; update entries directly from chat by telling Claude what to remember. Available on Free, Pro, and Max plans with memory enabled. (Source: https://support.claude.com/en/articles/12138966-release-notes)
- **Claude Code v2.1.214** — Released July 18, 2026. Key new feature: the **EndConversation tool** lets Claude end sessions with highly abusive users or jailbreak attempts (as on claude.ai since 2025). Security: extensive permission check fixes — single-segment `dir/**` allow rules now only match `<cwd>/dir`; PowerShell 5.1 permission-check bypass fixed; Bash checks fail closed on file-descriptor redirects; commands over 10,000 characters always prompt; zsh variable subscripts in `[[ ]]` now prompt; `help`/`man` with unsafe options no longer auto-approved; `docker` commands with daemon-redirect flags now require permission. New: periodic progress heartbeat for silent long-running tool calls; ISO `modified` timestamp in memory file frontmatter; `message.uuid`, `client_request_id`, `tool_source` attributes in OTel events; `CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH` to tune OTel truncation. Bug fixes: Bash pkill crash when pattern matches CLI; unbounded memory growth from oversized `--settings` files; Windows PowerShell streaming, Unicode, and `where.exe`/`fc.exe` fixes; background session and daemon reliability. (Source: https://code.claude.com/docs/en/changelog)
- **`agent-memory-2026-07-22` beta header for Managed Agents memory API** — Introduced July 2, 2026. Changes how listing memories (`GET /v1/memory_stores/{id}/memories`) behaves: results now return in stable server-defined order (ignoring `order_by`/`order` params); `depth` accepts only `0`, `1`, or omitted; `path_prefix` must end with `/` and matches whole path segments. Replaces `managed-agents-2026-04-01` on memory store endpoints — sending both headers returns a 400. Python (0.116.0), TypeScript (0.110.0), Go (1.56.0), and other SDKs updated to send the new header automatically. On July 22, 2026, `managed-agents-2026-04-01` will adopt this same list behaviour. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Anthropic "Inviting Hard Questions" initiative** — Launched July 9, 2026; a brand and research campaign with a 90-second film and public submission website where people can ask their hardest questions about AI (jobs, safety, families, scientific impact). Anthropic committed to publicly tracking and answering submissions. Built on prior research: the Anthropic Public Record surveyed 52,000 Americans; the Anthropic Interviewer surveyed 81,000 Claude users across 159 countries. The campaign generated backlash over its apocalyptic visual tone; Sam Altman quote-posted it saying he thought it was satire, driving 1M+ views. (Source: https://www.anthropic.com/news/hard-questions)
