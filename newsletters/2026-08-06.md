# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.223** — Released August 6, 2026. New: owner wildcard entries (`"owner/*"`) in `strictKnownMarketplaces` and `blockedMarketplaces` managed settings to allow/block all repos under a GitHub org; `/teleport` hint in cloud sessions showing `claude --teleport <session id>` to continue locally; `/review` is now an alias of `/code-review` (use `/code-review ultra` for deep cloud review); `CLAUDE_CODE_DISABLE_1M_CONTEXT` now applies auto-compaction to all 1M-window models to hold them at 200K (previously only a fixed list). Security: fixed Bash permission bypass where crafted commands could hide parts of themselves from permission checks; fixed permission prompts bypassed by tabs or invisible Unicode padding; fixed workflow scripts using dynamic `import()` to escape the workflow sandbox; fixed agent `bypassPermissions` mode ignoring the org-level bypass-permissions disable policy. Bug fixes: resuming sessions after `/cd` returning empty; gateway model discovery for provider-prefixed IDs; `modelOverrides` ignoring non-Anthropic keys; sandbox commands failing on Linux when `denyWrite` covers working directory; forked background agents stuck "already resuming"; `/code-review` reusing stale effort level from last invocation. (Source: https://code.claude.com/docs/en/changelog)
- **Inference hooks for Claude Enterprise (DLP beta)** — Launched August 5, 2026. Routes every employee prompt and tool call through the organisation's own security server for an allow-or-deny verdict before Claude processes anything, enabling real-time data loss prevention across chat, Claude Code, Cowork, MCP connectors, and plugins — all with a single org-level config. Uses a webhook-based protocol compatible with existing DLP platforms (Netskope, Palo Alto Networks Prisma AIRS, Proofpoint, Zscaler, or custom-built servers). Shadow mode lets teams monitor before enforcing; role-based exclusions and percentage-based rollouts enable phased deployment; configurable timeouts and failure policies define behaviour when the DLP server is unavailable. (Source: https://claude.com/blog/claude-enterprise-inference-hooks)
- **Anthropic brings in-country Claude inference to India via Amazon Bedrock** — Announced August 3–4, 2026. Requests sent to the India endpoint are processed on domestic servers, addressing data residency and compliance requirements for banking, insurance, and government sectors. Major enterprise deployments at launch include Axis Bank, NPCI, IndusInd Bank, and Godrej Industries. Anthropic is also hosting its first Claude Certification for Partners in Bengaluru, targeting 5,000 certified professionals across its Indian partner network. India has emerged as one of the strongest-performing markets in the Claude Partner Network by registrations since its global launch in March 2026. (Source: https://www.business-standard.com/technology/artificial-intelligence/anthropic-brings-claude-in-country-inference-to-india-via-aws-cloud-126080301168_1.html)
