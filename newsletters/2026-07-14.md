# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.208** — Released July 14, 2026. New features: screen reader mode (`claude --ax-screen-reader`, `CLAUDE_AX_SCREEN_READER=1` env var, or `"axScreenReader": true` in settings) renders the TUI as plain text for screen reader compatibility; `vimInsertModeRemaps` setting maps two-key vim insert-mode sequences (e.g. `jj` → Escape); `CLAUDE_CODE_PROCESS_WRAPPER` routes every self-spawned Claude Code process through a corporate launcher executable. Performance: session transcript size reduced up to 79× in edit-heavy sessions by pruning superseded file-history backups; per-tool-call CPU overhead reduced up to 7× when many MCP tools are present; multiple memory leaks fixed (MCP stdio server stderr capped at 64 MB, LSP documents capped to LRU-50, async hook output, tool-result payload accumulation); per-turn permission rule matching now compiled once and cached, eliminating multi-second slowdowns with many deny/ask rules. Also fixed: fast mode not restoring after switching back to a compatible model; background agent replies lost on delivery failure now re-delivered on restart; context window briefly resetting to 200k after auto-updates. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.209** — Released July 14, 2026. Single fix: `/model` picker and other dialogs were incorrectly blocked in `claude agents` background sessions due to an overly broad guard introduced in v2.1.208; now reverted. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Dreaming (Managed Agents) adds Fable 5 and Sonnet 5 support** — As of July 10, 2026, the Claude Dreaming research preview supports Claude Fable 5 and Claude Sonnet 5 in addition to previously supported Opus-tier models. See the Managed Agents dreams documentation for the full supported-models list. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Fable 5 subscription access extended again to July 19** — On July 13, 2026, Anthropic extended Fable 5's free-with-subscription window a second time, pushing the deadline from July 12 to July 19, 2026 at 11:59:59 PM PT. The extension coincided with the launch of OpenAI's competing GPT-5.6 Sol. Terms unchanged: up to 50% of weekly usage limits on Pro, Max, Team, and select Enterprise plans; after July 19, usage credits required at $10/$50 per MTok. Anthropic reaffirmed that Fable 5 is not permanently leaving subscriptions and will return to plan limits once capacity allows. (Source: https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/)
- **OpenAI GPT-5.6 Sol launched** — OpenAI released GPT-5.6 Sol on July 9, 2026 as its flagship frontier model, directly competing with Claude Fable 5. The GPT-5.6 family has three tiers: Luna, Terra, and Sol. OpenAI claims Sol scores 80 on the Artificial Analysis Coding Agent Index (vs. Fable 5's ~77), while using less than half the output tokens, less than half the time, and approximately one-third the cost. Some independent evaluators rate them comparably across tasks. The launch contributed to Anthropic extending Fable 5 subscription access through July 19. (Source: https://techcrunch.com/2026/07/09/openai-launches-its-new-family-of-models-with-gpt-5-6/)
