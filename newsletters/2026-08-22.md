# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.239** — Released August 22, 2026. Cost estimates (`/cost`, status line, `--max-budget-usd`) now include the 1.1× US-only-inference premium for data-residency workspaces. Fullscreen renderer offer added to Bedrock, Vertex, Foundry, and other previously excluded setups. New `/claude-api upgrade` skill migrates Python projects from `anthropic` 0.x to 1.x. Cloud sessions: plugins synced from claude.ai show as `name@synced` and work with `claude plugin enable/disable`. Alpine/musl builds: native image paste, clipboard, and audio-capture add-ons now load. Many bug fixes: Bedrock streaming behind proxies, JetBrains IDE terminal 5-second pauses, WebFetch cache expiry, race conditions in session transitions, MCP server resilience, and dozens more. (Source: https://code.claude.com/docs/en/changelog)
- **Computer Use tool GA (`computer_toolset_20260801`)** — The computer use tool is out of beta on the Claude API (August 19, 2026). No beta header required. Key changes: batch actions (several actions in one turn), `zoom` enabled by default, and per-member configuration through `configs`. Earlier beta versions remain available; upgrading changes the request shape and tool handling. Available for Claude Fable 5, Mythos 5, Opus 5, Sonnet 5, and Opus 4.8. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Browser Use tool (`browser_toolset_20260801`)** — New client toolset launched August 19, 2026 for driving a browser that your application hosts. Unlike computer use (which targets desktop screenshots by pixel coordinates), it reads the page's accessibility tree, DOM elements, forms, and tabs, and targets elements by reference as well as coordinates. Includes 27 default member tools (navigate, read_page, left_click, scroll, form_input, tab management, etc.) plus 4 opt-in tools (javascript_exec, file_upload, read_console, read_network). Available for Claude Fable 5, Mythos 5, Opus 5, Sonnet 5, and Opus 4.8 on the Claude API only. (Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/browser-use-tool)
- **Python SDK v1.0 released** — Released August 20, 2026. The `anthropic` Python SDK moves from `httpx` to `httpx2` (a maintained fork) for its HTTP layer; build custom clients from `httpx2` and call `httpx2.alias_httpx()` if your code patches `httpx`. Breaking changes: requires Python 3.10+; removes the legacy Text Completions API; removes the `temperature`, `top_p`, and `top_k` parameters on Messages methods; removes the tool runner's `compaction_control`; `.with_raw_response` results now need `await response.parse()` on the async client; `AnthropicBedrock` now raises an error instead of defaulting to `us-east-1` when no region is set. A full v1 migration guide is available on GitHub. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Mythos 5 in Claude Security + $35M Defender Advantage Fund** — Announced August 21, 2026. Claude Mythos 5 now powers vulnerability scans in Claude Security, available in public beta for all Claude Enterprise customers. Scans classify findings by CWE, severity, confidence, and suggested fixes, billed through standard Enterprise token usage — no separate add-on. Anthropic also launched the $35M Defender Advantage Fund (0xDAF), providing Claude credits to organisations improving open-source software security in three focus areas: patching live vulnerabilities in widely used projects, automating scanning and patching for replication, and pursuing whole-class security improvements. (Source: https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders)
