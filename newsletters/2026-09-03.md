# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.259** — Released September 3, 2026. Introduces managed MCP servers, letting organisations provide HTTP/SSE MCP servers to all members centrally. New `--permission-prompts none` flag automatically denies all permission requests for unattended headless environments. GitLab merge request references now surface as `MR !N` in tool summaries. `claude plugin validate --json` outputs machine-readable validation reports. Key fixes: concurrent sessions no longer revert each other's configuration changes; Bash read-deny rules now correctly cover files given as option values and operands; OAuth token refresh no longer invalidates the prompt cache in telemetry-disabled sessions; fullscreen mode handles conversations with hundreds of tool calls without freezing; worktree isolation no longer incorrectly blocks common Bash loops and xargs pipelines. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Sony Music and Warner Chappell sue Anthropic for large-scale copyright infringement** — Filed August 29–31, 2026 in the US District Court for the Northern District of California. Sony Music Publishing and Warner Chappell Music accuse Anthropic of obtaining copyrighted song lyrics and sheet music through piracy archives (Library Genesis, Pirate Library Mirror) to train Claude, including works like "Livin' On a Prayer," "Hallelujah," and "Great Balls of Fire." Dario Amodei and Benjamin Mann are named as individual defendants. Plaintiffs seek a jury trial and statutory damages of up to $150,000 per composition across "thousands if not tens of thousands" of works, placing potential damages in the billions. Anthropic denies all allegations. (Source: https://techcrunch.com/2026/08/29/sony-music-warner-sue-anthropic-alleging-a-brazen-campaign-of-intellectual-property-theft/)
- **Enterprise Frontier Safeguards (EFS) launched** — Announced September 1, 2026 alongside Fable 5.1. EFS lets enterprise customers keep the 30-day safety-monitoring data in their own cloud infrastructure (AWS S3, Azure Blob Storage, or Google Cloud Storage) under their own encryption keys and access policies, rather than on Anthropic's servers. Automated misuse detection still scans for policy violations; no Anthropic human review is required. Developed with 100+ enterprise customers including a quarter of the Fortune 100, every US global systemically important bank, Comcast, KPMG, Mastercard, Salesforce, and Visa. Available at no extra charge; rolling out to customers in phases this fall. Supported on Claude Code, Claude Enterprise, Claude Platform, Bedrock, Claude Platform on AWS, Google's Agent Platform, and Microsoft Foundry. (Source: https://www.anthropic.com/news/enterprise-frontier-safeguards)
- **Claude Commerce Agents open-sourced** — Announced September 2, 2026. Anthropic open-sourced reference implementations for shopping and merchant agents across retail, travel, telecom, and ticketing. The shopping agent makes preference-based suggestions and adds items to carts with anti-manipulation controls; the merchant agent monitors inventory, recommends pricing and promotions, and drafts marketing campaigns — but requires human approval before changes go live. Early results: ~30–35% cart size increase and 60% higher purchase completion. Deployable via Claude API, Amazon Bedrock, Microsoft Foundry, or Google Cloud Vertex AI. (Source: https://claude.com/blog/claude-for-commerce-agents)
