# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.319** — Released November 6, 2026. MCP tasks run as background tasks in the terminal; `permissions.denyInsteadOfPrompting` setting blocks tool calls that would cause a permission prompt, letting the turn continue instead of pausing; `/claude-api latency-optimize` finds latency bottlenecks in Claude API code; `/tasks` gains an "Earlier in this session" row for finished subagents. Behavior changes: auto mode with telemetry or feature flags off no longer falls back to the built-in classifier (set `CLAUDE_CODE_AUTO_MODE_SERVER=0` to restore); self-paced `/loop` ends when a turn finishes without rescheduling (set `CLAUDE_CODE_LOOP_KEEPALIVE=1` for old behavior). (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.321** — Released November 9, 2026. Claude Fable 5.2 (`claude-fable-5-2`) set as new default Fable model at $8/$40 per MTok (down from $10/$50 for Fable 5.1) with $0.20/MTok cache reads. New `claude remote-control --settings <file>` applies a settings file to every Remote Control session it starts. Saved Fable 5.1 model selections migrate to the `fable` alias; use `/model claude-fable-5-1` to switch back. Mods Claude writes no longer load in `dontAsk` mode. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.322** — Released November 10, 2026. Adds fast mode on Vertex AI in the global, US, and EU regions; falls back automatically to standard speed if Vertex refuses the fast-mode request. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.323** — Released November 12, 2026. New features: **Code Mode** (experimental, opt-in) — Claude writes JavaScript to call its tools rather than natural language; `engines["claude-code"]` in `plugin.json` enforces a Claude Code version range, preventing plugins from loading outside it; `CLAUDE_CODE_RESUME_HINT_COMMAND` for a custom resume command shown on exit; 30-second hook heartbeat in headless (`claude -p`) and SDK sessions; `MCP_SDK_GENERATION=v1` runs the v2 MCP client in compatibility mode (v1 client removed); TypeScript hook type-checking in `claude plugin validate`. Behavior changes: `/security-review` now asks before running; unrecognised model IDs assume a 1 M context window (up from 200 K — set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` to keep 200 K); org policy requests no longer use `ALL_PROXY` — set `HTTPS_PROXY` instead. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Meetings launched (beta)** — Announced November 10, 2026. Claude joins Google Meet calls as a visible participant, taking structured notes and completing work in real time (drafting plans, populating whiteboards, answering questions through connected tools). After the call, notes, action items, transcripts, and outputs are saved to claude.ai. External guests trigger an automatic leave by default; admins can override. Notes and transcripts are free during beta; documents and whiteboards are free until February 10, 2027. Available on Team and Enterprise plans; Google Meet only at launch. Transcript-forwarding integrations include Gong, Attention, Granola, Fireflies.ai, and Otter. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Claude Whiteboards launched (beta)** — Announced November 10, 2026. A collaborative canvas where Claude turns brainstormed plans into visual timelines and action items. Works inside Claude Meetings (live) and standalone. Exports to a document or slide deck. Available on paid plans across web, desktop, and mobile. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Claude Sheets launched (beta)** — Announced November 10, 2026. Collaborative spreadsheets that Claude builds from a description, with multi-tab files supporting formulas, dropdowns, and Excel export. Edits are outlined for user review before applying. Available on paid plans across web, desktop, and mobile; a Google Workspace plugin is included. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Claude Data generally available** — Announced November 10, 2026. Claude Dashboards has been renamed Claude Data and is now generally available. Connects Claude to company data systems, letting users request dashboards, data stories, and narrated data videos. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Claude Enterprise Security Center & Inference Hooks generally available** — Announced November 5, 2026. Security Center (beta) lets admins compare their organization's Claude settings against Anthropic's recommended configuration. Inference Hooks are now generally available (from beta since August 5, 2026): prompt hooks and pre-tool-call hooks let enterprises connect existing DLP and security tools to inspect and block sensitive data before it reaches Claude. Both are managed under Organisation settings in Claude Enterprise. (Source: https://claude.com/blog/claude-enterprise-security-updates)
- **Interactive Connectors generally available** — Announced November 10, 2026. Full versions of partner apps — including Adobe, Atlassian, HubSpot, Salesforce, NetSuite, and Workday — can now open their complete interfaces inside Claude and take actions with user approval, replacing the previous screenshot-only or API-only integration model. (Source: https://techcrunch.com/2026/11/10/anthropic-launches-claude-meetings-to-turn-workplace-discussions-into-plans-and-tasks/)
- **Anthropic IPO roadshow launched** — Announced November 10, 2026. Anthropic began marketing its IPO with a proposed price range of $70–$78 per share for 825 million Class A shares (Nasdaq ticker: ANT). At the top of the range the company is valued at approximately $1.4 trillion fully diluted. Pricing expected November 18, first trading November 19. Underwriters include Morgan Stanley, Goldman Sachs, JPMorgan, and Citigroup. Seven strategic investors including Google and Nvidia agreed to buy $26 billion of non-voting stock at the IPO price. The offering includes ~801 M shares from Anthropic plus ~24 M from existing stockholders; underwriters hold an option on 123.75 M additional shares. (Source: https://finance.yahoo.com/markets/stocks/articles/anthropic-launches-roadshow-825-million-152044003.html)
