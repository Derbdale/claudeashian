# Current Discoveries

New items discovered since the last newsletter.

- **Claude Code v2.1.265** — Released September 8, 2026. New features: `--plugin-dir` now accepts a directory of plugins (each child folder with a manifest auto-loads; additions and removals are detected at runtime); 1 GB cap on tool results saved to disk (conversation preview says when truncated); VS Code "Archive inactive sessions" setting auto-archives sessions idle for 14 days by default; improved `/workflows` agent detail view with tool call status, subagent task lists, and expand/fold controls; faster `--worktree` startup on large repos via parallel checkout (git 2.32+). Key fixes: resuming a foreground-spawned subagent no longer changes its tool list or system prompt; resume after process crash mid-tool; MCP servers configured with legacy HTTP+SSE transport now connect correctly; Windows Read/Write/Edit permissions refusing files in AppContainer or restricted-token sandboxes fixed; various Remote Control and VS Code reliability improvements. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.266** — Released September 8, 2026. Single bug fix: the `CLAUDE_CODE_USE_GATEWAY` environment variable, previously ignored unless paired with both `ANTHROPIC_BASE_URL` and `ANTHROPIC_AUTH_TOKEN`, began forcing Cloud-gateway sign-in on its own in v2.1.265, breaking configurations that set it alongside an API key or custom auth headers. The variable is now ignored again when set alone. (Source: https://code.claude.com/docs/en/changelog)
- **Anthropic $35B Lambda compute deal** — Anthropic signed a six-year cloud-computing deal worth $35 billion with Lambda, a San Jose-based cloud provider backed by Nvidia, announced August 31, 2026. Lambda will deploy Nvidia capacity from a Texas data center (developed by Hut 8, leased by Nvidia) to power Claude at scale. Together with earlier 2026 commitments (Nscale $45B, Riot Platforms $9.1B, SpaceX $45B, Volta $10B, and others), Anthropic's total compute deals in 2026 exceed $135 billion. (Source: https://www.bloomberg.com/news/articles/2026-08-31/anthropic-seals-35-billion-cloud-deal-with-nvidia-backed-lambda)
- **Anthropic $5M AI wellbeing research grants** — Announced August 25, 2026. Anthropic launched a $5 million grant program funding independent research into how AI affects user wellbeing, providing direct funding, model access, and technical support for open-source evaluations that measure AI's psychological and emotional impact. Grants emphasise clinical expert involvement, real multi-turn conversation data, and context-dependent harm assessment covering mental health support, companionship-seeking, and vulnerable users. Applications close September 21, 2026; full proposals due October 5. (Source: https://www.anthropic.com/news/wellbeing-research-grants)
