# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code v2.1.272 and v2.1.273** — Both released September 15, 2026. v2.1.272 contains only bug fixes and reliability improvements. v2.1.273: introduces opt-in `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` env var that adds request-class headers (`x-claude-code-request-class`, `x-claude-code-agent-type`, etc.) to API calls, enabling LLM gateways to route and prioritise requests by type; remote-control sessions can now be forked as local background sessions; MCP servers that disconnect mid-session show a notification pointing to `/mcp` for reconnection; auto mode now blocks dangerous `rm` commands that were previously bypassed in subshells; Claude Tag (Slack) fixes for OAuth connections and scheduled task connector access. (Source: https://code.claude.com/docs/en/changelog)
- **Compact-on-demand Messages API (Beta)** — As of September 14, 2026, the Messages API supports developer-controlled context compaction via the `compact-2026-09-04` beta header. Pass a `compaction` parameter; the API returns a signed `compaction` block summarising the specified messages. On later requests, send that block in place of the original messages to reduce context size. You control exactly when compaction occurs, can keep recent turns verbatim, and can run compaction as a background request. Thinking blocks in preserved turns remain valid on supported models. Enables effectively infinite conversations without automatic server-side summarisation. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude for Small Business expands to 43 workflows and 27 integrations** — Announced September 15, 2026. Anthropic expanded its Claude for Small Business package (originally launched May 13, 2026) with 43 workflow templates and 27 new integrations covering Shopify, Salesforce, TikTok, Atlassian, Zoom, Xero, Gusto, Square, Stripe, and Zapier. Includes a default approval mode where Claude stages work for user review before execution. Accompanied by a fall workshop series in 10 US cities with 750+ community-run sessions through November 2026. (Source: https://www.anthropic.com/news/claude-for-small-business)
