# Current Discoveries

New items discovered since the last newsletter.
- **Claude Opus 5.5 launched** — Released September 22, 2026. First model in the new 5.5 family. Performs at Claude Fable 5.1 level on most work but costs 40% less than Opus 5: $4/$20 per MTok input/output (down from $5/$25), cache reads at $0.20/MTok (60% reduction), output 30% faster. Scores 66.4% on Terminal-Bench 4.0 agentic coding and 81.8% on OSWorld 2.0 computer use. Uses ~40% fewer tokens and steps than Opus 5 on comparable tasks. Launches with preserved thinking (anti-distillation safeguard from Fable 5.1), enhanced alignment, and EU AI Act watermarking. Claude Sonnet 5.5 and Haiku 5.5 expected within weeks. Available on all major platforms. (Source: https://www.anthropic.com/claude-opus-5-5)
- **Claude Code v2.1.280** — Released September 22, 2026. Sets Claude Opus 5.5 as the new default Opus model; changes default model on Pro/Team Standard from Sonnet to Opus. Adds mouse support to more fullscreen lists (wheel scrolls `/skills`, clickable options in `/plugin`); adds `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` env var to customise MCP tool description character cap (default 2,048); improves `/cost` to name thinking mode and show cache-miss causes; VS Code gains Skills dialog with on/off toggle, Status/Sandbox/Chrome dialogs, Export conversation, and `/plan` command; Claude Tag adds Slack native Working indicator, Stop button, and thread title. Key fixes: symlinked path writes judged by actual landing location; auto mode no longer retries declined safety checks; voice dictation now stops on Ctrl+C (Esc cancels); model switch from host app no longer causes prompt-cache miss; conversations no longer fail with "role 'system' must precede 'assistant'" API error. (Source: https://code.claude.com/docs/en/changelog)
