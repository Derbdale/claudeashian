# Current Discoveries

New items discovered since the last newsletter.
- **Claude Code Projects redesigned with parallel cloud sessions (beta)** — Launched September 17, 2026. Projects now coordinate parallel threads — each a full Claude Code cloud session running on its own repository branch — managed by an AI coordinator that delegates tasks, reviews outputs, and assembles results. Every thread runs Opus at high effort by default and keeps running after you close your laptop. Threads share memory and a project library of user-added files and Claude-generated artifacts. Beta open to select Pro and Max cloud-session users; expansion to all Claude Code users and Team/Enterprise plans follows over coming weeks. (Source: https://claude.com/blog/projects-redesigned)
- **Claude Code v2.1.277** — Released September 18, 2026. Adds `AGENTS.md` support: projects with no `CLAUDE.md` now read `AGENTS.md` instead (configurable under "Project instructions" in `/config`; not yet available on Bedrock, Vertex, or Foundry). New Claude apps gateway settings: `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` routes every outbound request through a forward proxy by hostname rather than resolving locally; optional `headers:` map on gateway upstreams sends static headers to a proxy. Key fixes: `claude -p` and Agent SDK sessions hanging with no result after internal errors now report the error and exit with code 1; "text content blocks must be non-empty" conversation crashes; unexpected logouts when two Claude Code builds coexist on the same machine. VS Code gains Sign out row in the panel menu, background shells and running tasks in the agent map with a Stop button, a Copy response button, and session cost/token usage in Account & usage. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.278** — Released September 19, 2026. Auto mode now defaults to the server-side classifier for Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway deployments — the server-side classifier does not charge for classifier overhead, reducing auto mode costs. Opt out on non-API providers with `CLAUDE_CODE_AUTO_MODE_SERVER=0`. A new "Auto mode server" row in `/status` shows whether the session's auto mode classifier runs locally or on the server. (Source: https://code.claude.com/docs/en/changelog)
- **Compliance API covers Claude in Chrome sessions** — As of September 18, 2026, the Compliance API returns transcripts from Claude in Chrome sessions within the local session endpoints, in beta for Claude Enterprise organizations. Uses the existing Compliance Access Key with the `read:compliance_user_data` scope. Extends prior coverage of Cowork, local Claude Code, Claude Science, and M365 sessions to the Chrome side panel. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`/design` command** — Research preview bringing Claude Design's artboard workflow into the CLI and Claude Code Desktop. Claude drafts several editable artboards for your UI built on Artifacts, you pick the direction, and Claude implements it. Launched Week 34 (August 17–21, 2026). (Source: https://code.claude.com/docs/en/whats-new)
