# Shortcuts & Commands

Keyboard shortcuts, CLI commands, and slash commands for Claude Code.

- **/loop command** — Run a prompt or slash command on a recurring interval (e.g., `/loop 5m /kuwtc-research`). New in March 2026. (Source: https://code.claude.com/docs/en/changelog)
- **/effort command** — Set model effort level via slash command (v2.1.76). (Source: https://code.claude.com/docs/en/changelog)
- **/copy N command** — Copy the Nth-latest assistant response to clipboard. Previously only copied the most recent (v2.1.77). (Source: https://github.com/anthropics/claude-code/releases)
- **/color command** — Set prompt-bar color for the current session, available to all users (v2.1.75). (Source: https://code.claude.com/docs/en/changelog)
- **/branch command** — Renamed from /fork. Fork still works as alias (v2.1.77). (Source: https://github.com/anthropics/claude-code/releases)
- **Ctrl+R for history search** — Press Ctrl+R to activate reverse history search, enter text to search previous commands, press again to cycle through older matches. (Source: https://code.claude.com/docs/en/interactive-mode)
- **-n / --name flag** — Set a display name for the session at startup with `claude -n "my session"` (v2.1.76). (Source: https://github.com/anthropics/claude-code/releases)
- **/simplify and /batch bundled commands** — New bundled slash commands for code simplification and batch operations (v2.1.63). (Source: https://code.claude.com/docs/en/changelog)
- **`w` key in /copy writes to file** — Press `w` in the /copy picker to write the selection directly to a file instead of clipboard (v2.1.72). (Source: https://code.claude.com/docs/en/changelog)
- **/reload-plugins command** — Reload all plugins without restarting the session (v2.1.69). (Source: https://code.claude.com/docs/en/changelog)
- **`claude agents` command** — Opens Agent View: a single screen showing all Claude Code sessions with their state (running, blocked, done). `claude agents --json` outputs the session list for scripting. (Source: https://code.claude.com/docs/en/whats-new)
- **/usage command** — Breaks down what's driving plan limits by skill, subagent, plugin, and MCP server, with per-category cost analysis and streaming reads for large session files (v2.1.145+). (Source: https://code.claude.com/docs/en/whats-new)
- **/ultrareview command** — Dispatches a fleet of cloud bug-hunting agents; findings land back in your CLI or Desktop automatically. Also available as `claude ultrareview` for CI/scripts (v2.1.114). (Source: https://code.claude.com/docs/en/whats-new)
- **/code-review command** — Reports correctness bugs with configurable effort levels. `--fix` applies findings to working tree; `--comment` posts findings as inline GitHub PR comments. Replaces the earlier /simplify command (v2.1.147). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **/goal command** — Keeps Claude working across turns until a specified completion condition holds, replacing the need to re-prompt between steps (v2.1.139). (Source: https://code.claude.com/docs/en/whats-new)
- **Ctrl+T to toggle task list** — New keyboard shortcut to show/hide the active task list within a session. (Source: https://www.decodesfuture.com/articles/claude-shortcuts-keyboard-guide-2026)
- **`claude project purge`** — Cleans up local project state without touching the remote; useful for removing stale session data (v2.1.120). (Source: https://code.claude.com/docs/en/whats-new)
- **`--plugin-dir` / `--plugin-url` flags** — Load plugins from `.zip` archives on disk (`--plugin-dir`) or fetch a plugin archive from a URL (`--plugin-url`) for the current session (v2.1.128). (Source: https://code.claude.com/docs/en/whats-new)
- **/reload-skills command** — Rescans skill directories mid-session to pick up new or edited skill files without restarting (v2.1.152). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **`! <command>` in agents view** — Run background shell commands from the agents view without switching to a terminal (v2.1.154). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **/plugin list command** — New slash command to list all installed plugins with filtering options (v2.1.163). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **`claude agents --json` includes `waitingFor` field** — The JSON output now shows what a blocked session is waiting on (e.g. a pending permission prompt), enabling scripts to detect and respond to blocked agents (v2.1.162). (Source: https://github.com/anthropics/claude-code/releases)
- **`claude agents` URL filter** — Typing a URL into the agents view filters to the session whose first prompt contained that URL, making it easy to jump to the session that created a PR or file (v2.1.166). (Source: https://github.com/anthropics/claude-code/releases)
- **`/powerup` command** — Interactive lessons built into Claude Code for learning features hands-on, launched as part of the computer use research preview week (Week 14, v2.1.86). (Source: https://code.claude.com/docs/en/whats-new)
- **`/team-onboarding` command** — Packages your current Claude Code setup (CLAUDE.md, skills, hooks, MCP config) into a replayable onboarding guide for new teammates (Week 15). (Source: https://code.claude.com/docs/en/whats-new)
- **`/autofix-pr` command** — Turns on PR auto-fix from the terminal; Claude monitors CI failures on open PRs and pushes fixes automatically (Week 15). (Source: https://code.claude.com/docs/en/whats-new)
- **`/cd` command** — Move a session to a new working directory mid-session without resetting the prompt cache (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **Backspace dismisses workflow trigger** — Pressing backspace immediately after typing a dynamic workflow trigger keyword cancels the workflow request (same as alt+w), instead of deleting a character. Prevents accidental workflow launches while editing prompts (v2.1.169). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Search bar in `/plugin` for browsing marketplace plugins** — The `/plugin` command now includes a search bar to filter and find plugins in the marketplace without scrolling through the full list (v2.1.172). (Source: https://github.com/anthropics/claude-code/releases)
- **VSCode `/usage` shows cache miss and context attribution** — The Account & usage dialog in VS Code now breaks down usage by cache misses, long context, subagents, and per-skill/agent/plugin/MCP server, with 24h or 7d time windows (v2.1.174). (Source: https://github.com/anthropics/claude-code/releases)
- **Enhanced `/doctor` command** — `/doctor` now shows a consistent flat tree layout across all sections, clearer section status icons, and highlighted command names for faster diagnosis of configuration and connectivity issues (v2.1.178). (Source: https://code.claude.com/docs/en/changelog)
- **Shift+Tab cycles through permission modes** — Press Shift+Tab to cycle: default mode → auto-accept edits mode (⏵⏵) → plan mode (⏸). Third press returns to default. The active mode is displayed in the status bar below the prompt. (Source: https://code.claude.com/docs/en/permission-modes)
- **/config key=value syntax** — Set any Claude Code setting directly from the prompt bar (e.g., `/config thinking=false`); works in interactive, `-p`, and Remote Control modes. Replaces manually editing settings.json for quick one-off changes (v2.1.181, June 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **`/config --help` and updated toggle behavior** — `/config --help` lists all available shorthand setting keys. Toggle behavior updated in v2.1.183: Enter and Space now change the setting value; Esc saves and closes (previously Esc reverted without saving). (Source: https://code.claude.com/docs/en/changelog)
- **`?` key displays shortcuts for your environment** — Press `?` on an empty prompt to show all available keyboard shortcuts for the current terminal and IDE surface, accounting for platform-specific differences. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **Ctrl+O opens verbose full transcript view** — Press Ctrl+O to switch to a detailed, full-content transcript of the current session, including complete tool inputs and outputs. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **/btw command for side questions** — `/btw <question>` lets you ask Claude a quick side question mid-task without adding it to the main conversation history, so the primary task context stays clean. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **`claude mcp login` / `claude mcp logout` CLI auth** — New CLI commands to authenticate named MCP servers directly from the terminal (`claude mcp login <name>`, `claude mcp logout <name>`). `--no-browser` flag supports headless / SSH environments where opening a browser is impractical (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **`f` key filters `/workflows` by status** — In the `/workflows` agent detail view, press `f` to filter the session list by status (running, blocked, done), making it easier to spot specific workflow states in long session lists (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **`/rewind` command** — Resumes a conversation from a point before `/clear` was run, allowing you to recover context that would otherwise be lost (v2.1.191, June 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`/dataviz` bundled skill** — Built-in Claude Code skill for chart and dashboard design guidance, including a runnable color-palette validator and chart design system advice (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **`/agents` wizard removed** — The interactive `/agents` wizard command has been removed; create and manage agents by asking Claude directly or by editing `.claude/agents/` files manually (v2.1.198, July 1, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **Stacked slash-skill invocations** — Claude Code v2.1.199 (July 2, 2026) adds support for stacking multiple slash-skill invocations in sequence, enabling chained skill execution in a single prompt. (Source: https://github.com/anthropics/claude-code/releases)
- **`claude --continue` and `claude --resume` session flags** — `claude --continue` picks up the most recent session without prompts; `claude --resume` opens an interactive picker to choose from all saved sessions by name. Use `/rename` to give sessions descriptive names (e.g. `oauth-migration`) so they're easy to find later. (Source: https://code.claude.com/docs/en/best-practices)
- **`Ctrl+G` opens plan in text editor during plan mode** — In plan mode, press `Ctrl+G` to open the current plan draft in your configured text editor for direct annotation and editing before Claude proceeds with implementation. (Source: https://code.claude.com/docs/en/best-practices)
- **`claude --worktree [name]`** — Start a new Claude Code session in an isolated git worktree; optionally name the worktree. Add `--tmux` to launch it in its own Tmux window, keeping worktree sessions visually separate from your main session. (Source: https://awesomeclaude.ai/code-cheatsheet)
- **`claude --teleport`** — Move an in-progress cloud (web/remote) session to your local terminal to continue it with full CLI access; mirrors session state from the cloud environment onto your machine. (Source: https://support.claude.com/en/articles/14554000-claude-code-power-user-tips)
- **`/remote-control` command** — Allow your phone or the claude.ai web interface to view and steer a local Claude Code terminal session in real time; pairs with mobile push notifications for away-from-desk supervision. (Source: https://support.claude.com/en/articles/14554000-claude-code-power-user-tips)
- **`/voice` command** — Activate hands-free voice dictation mode for Claude Code; approximately 3× faster than typing for extended input. Customisable push-to-talk keybinding via `voice:pushToTalk` in keybindings.json. (Source: https://support.claude.com/en/articles/14554000-claude-code-power-user-tips)
- **`/statusline` command** — Configure and customise the Claude Code status bar display; supports custom text, colours, and session metadata. Build reusable status-line plugins or use community packages from the marketplace. (Source: https://support.claude.com/en/articles/14554000-claude-code-power-user-tips)
- **`Ctrl+X` removes completed sessions** — In the agents view, press `Ctrl+X` to permanently remove a completed session from the list (v2.1.206, July 10, 2026). (Source: https://github.com/anthropics/claude-code/releases)
- **`/radio` command** — Tunes into "Claude FM" lo-fi radio from within Claude Code for ambient background music while you work. Launched Week 27 (June 29 – July 3, 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **`--add-dir` flag and `/add-dir` command** — Launch with `claude --add-dir ~/path/to/other-repo` to give Claude access to an additional directory alongside the working directory, or run `/add-dir <path>` mid-session to add it without restarting. Useful for monorepo work or shared library access. (Source: https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **`/subtask` command** — Launches an in-session subagent for a focused sub-task while keeping the main conversation active. Introduced in v2.1.212 (July 17, 2026) as the replacement for the previous in-session subagent command; `/fork` was simultaneously repurposed to duplicate the full current conversation into a background session. (Source: https://releasebot.io/updates/anthropic/claude-code)
- **`claude auto-mode reset`** — CLI command that restores the default auto-mode configuration, undoing any manual customisations without editing settings files (v2.1.212, July 17, 2026). (Source: https://releasebot.io/updates/anthropic/claude-code)
