# Features

Claude and Claude Code features, capabilities, and model updates.

- **Claude Opus 4.6 launched** — Released February 5, 2026 with 1M token context window, stronger coding, better planning/debugging, and improved financial analysis. (Source: https://its.northeastern.edu/2026/02/26/anthropics-latest-claude-models-are-here-and-theyre-a-big-leap-forward/)
- **Claude Sonnet 4.6 released** — Launched February 17, 2026 with near-Opus performance on coding and document comprehension, plus improved computer use. (Source: https://releasebot.io/updates/anthropic/claude)
- **1M context window generally available** — Available on Max, Team, and Enterprise plans for Opus 4.6 and Sonnet 4.6 at standard pricing. No beta header required. (Source: https://code.claude.com/docs/en/changelog)
- **Opus 4.6 output tokens increased to 64k** — Default max output tokens raised to 64k, upper bound to 128k for both Opus 4.6 and Sonnet 4.6 (v2.1.77). (Source: https://github.com/anthropics/claude-code/releases)
- **Voice mode in Claude Code** — Push-to-talk via spacebar, customisable keybinding (voice:pushToTalk in keybindings.json), rolling out progressively. (Source: https://pasqualepillitteri.it/en/news/381/claude-code-march-2026-updates)
- **MCP Elicitation support** — MCP servers can now request structured input mid-task via interactive dialog. New Elicitation and ElicitationResult hooks added (v2.1.76). (Source: https://code.claude.com/docs/en/changelog)
- **Worktree sparse checkout** — New worktree.sparsePaths setting for large monorepos to check out only needed directories (v2.1.76). (Source: https://github.com/anthropics/claude-code/releases)
- **Context command improvements** — /context now gives actionable suggestions identifying context-heavy tools, memory bloat, and optimisation tips (v2.1.74). (Source: https://code.claude.com/docs/en/changelog)
- **Custom auto-memory directory** — New autoMemoryDirectory setting to choose where auto-memory files are stored (v2.1.74). (Source: https://code.claude.com/docs/en/changelog)
- **Model overrides setting** — New modelOverrides setting to map model picker entries to custom provider model IDs (v2.1.73). (Source: https://code.claude.com/docs/en/changelog)
- **Fast mode for Opus 4.6** — Research preview providing up to 2.5x faster output token generation via the `speed` parameter at premium pricing. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Compaction API** — Server-side context summarization in beta, enabling effectively infinite conversations on Opus 4.6. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Extended thinking display control** — New `thinking.display: "omitted"` option omits thinking content from responses for faster streaming while preserving signatures for multi-turn continuity. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Automatic prompt caching** — Single `cache_control` field automatically caches the last cacheable block and moves the cache point forward as conversations grow. No manual breakpoint management required. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **600 media items per 1M context request** — Media limit raised from 100 to 600 images or PDF pages per request when using the 1M token context window. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Plugin data persistence** — New `${CLAUDE_PLUGIN_DATA}` variable provides persistent storage for plugin state across sessions (v2.1.78). (Source: https://github.com/anthropics/claude-code/releases)
- **StopFailure hook event** — New hook event fires on API errors like rate limits and auth failures, enabling automated error handling (v2.1.78). (Source: https://github.com/anthropics/claude-code/releases)
- **Data residency controls** — New `inference_geo` parameter lets you specify where model inference runs. US-only inference available at 1.1x pricing for models released after February 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Opus 4.7 launched** — Released April 13, 2026 as the new default on Max and Team Premium. Introduced `xhigh` effort level as the recommended setting for most coding work, with an interactive `/effort` slider. (Source: https://code.claude.com/docs/en/whats-new)
- **Auto mode** — A classifier-based permission system that handles safe actions without interruption and blocks risky ones. Research preview in March 2026, now available on Pro, Bedrock, Vertex, and Foundry for Opus 4.7 and 4.8 (v2.1.83+). (Source: https://code.claude.com/docs/en/whats-new)
- **Computer use in CLI** — Claude can open native apps, click through UI, and verify changes from the terminal. Research preview launched in v2.1.86 (Week 14, March–April 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Claude Managed Agents** — Sandboxed agent platform with checkpointing and credential scoping, enabling production agents to run in environments you control with MCP access. Announced at Code with Claude 2026. (Source: https://www.infoq.com/news/2026/05/code-with-claude/)
- **Claude Opus 4.8 launched** — Released May 28, 2026. Benchmarks: agentic coding 64.3%→69.2%, reasoning with tools 54.7%→57.9%, computer use 82.8%→83.4%. High-effort defaults, fast mode at 2× standard rate for 2.5× speed. Pricing unchanged from 4.7. (Source: https://9to5mac.com/2026/05/28/anthropic-upgrades-claude-with-new-opus-4-8-model-heres-whats-new/)
- **Dynamic workflows** — Orchestrate dozens to hundreds of subagents from a Claude-written script; trigger with the keyword "ultracode" (violet highlighting). Research preview in v2.1.154. (Source: https://code.claude.com/docs/en/whats-new)
- **Plugin auto-loading from .claude/skills** — Plugins in `.claude/skills` directories load automatically without marketplace requirement. `claude plugin init <name>` scaffolds new plugins with autocomplete (v2.1.157). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **MessageDisplay hook** — New hook event that fires on each message, enabling message transformation before display (v2.1.152). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Messages API mid-conversation system entries** — Messages API now accepts system entries mid-conversation without disrupting prompt caching, enabling dynamic context injection. (Source: https://9to5mac.com/2026/05/28/anthropic-upgrades-claude-with-new-opus-4-8-model-heres-whats-new/)
- **Self-hosted sandboxes for Managed Agents** — Tool execution now runs in your own infrastructure while orchestration stays on Anthropic's servers, keeping files within your security perimeter. Available as public beta on Claude Platform on AWS (announced May 2026). (Source: https://claude.com/blog/code-w-claude-london-2026-rethinking-how-we-build)
- **Security-guidance plugin** — Automatically reviews Claude's changes for security vulnerabilities as it works, surfacing issues inline without a separate review step. Bundled in Week 22 (v2.1.150–v2.1.157). (Source: https://code.claude.com/docs/en/whats-new)
- **Safety warning before writing shell startup files** — Claude now prompts for confirmation before writing to shell startup files (e.g. `.bashrc`, `.zshrc`) or build-tool config files, preventing accidental environment changes (v2.1.160). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Fast mode available for Claude Opus 4.7** — Fast mode (`speed: "fast"`) now supports claude-opus-4-7, providing significantly faster output token generation at premium pricing (Week 20, v2.1.139). (Source: https://code.claude.com/docs/en/whats-new)
- **Parallel tool calls now independent** — In agentic workflows, a failure in one parallel tool call no longer cancels the other calls in the batch; each succeeds or fails independently (v2.1.161). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Slash commands fill into prompt bar before executing** — Selecting a slash command now inserts it into the prompt bar for review and editing before submission, improving discoverability and preventing accidental execution (v2.1.162). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **`fallbackModel` setting** — Configure up to three backup models tried in order when the primary model is overloaded or unavailable; `--fallback-model` flag also applies to interactive sessions (v2.1.166). (Source: https://github.com/anthropics/claude-code/releases)
- **Thinking fully disabled on default-thinking models** — `MAX_THINKING_TOKENS=0`, `--thinking disabled`, and the per-model thinking toggle now disable thinking computation (not just display) on models that think by default, reducing latency and cost when extended reasoning is unneeded (v2.1.166). (Source: https://github.com/anthropics/claude-code/releases)
- **Edit no longer requires Read after single-file grep** — After running `grep`/`egrep`/`fgrep` on a single file, Claude Code no longer requires a separate Read call before issuing an Edit; the grep result satisfies the read precondition (v2.1.160). (Source: https://github.com/anthropics/claude-code/releases)
- **`--tools` flag unlocks dedicated Grep/Glob tools** — Explicitly listing `Grep` or `Glob` in the `--tools` flag provides dedicated search tools rather than relying on Bash, improving precision and permission scoping for search-heavy pipelines (v2.1.162). (Source: https://github.com/anthropics/claude-code/releases)
- **Opus 4.8 effort defaults to `high` across all surfaces** — On Claude Opus 4.8, the effort parameter defaults to `high` across all surfaces including Claude Code and the Messages API, enabling deeper reasoning by default without explicit configuration. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Adaptive thinking on Opus 4.8 triggers only when needed** — With adaptive thinking enabled, Opus 4.8 skips extended reasoning on turns that don't require it, reducing wasted thinking tokens compared to Opus 4.7 at the same effort level. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Prompt cache minimum lowered to 1,024 tokens on Opus 4.8** — The minimum cacheable prompt length for prompt caching dropped from the Opus 4.7 threshold to 1,024 tokens on Opus 4.8, making caching accessible for shorter prompts. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Mobile push notifications in Claude Code** — Claude Code pings your phone when a long-running task completes or when Claude is blocked waiting for your input, surfacing session state without keeping the terminal open. Launched Week 16 (April 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **Session recap after terminal inactivity** — When you return to an unfocused terminal, Claude Code shows a recap of everything that happened while you were away, so you can quickly re-orient without scrolling history. Launched Week 17 (April 2026). (Source: https://code.claude.com/docs/en/whats-new)
- **`--safe-mode` flag and `CLAUDE_CODE_SAFE_MODE` env var** — Disables all customisations (CLAUDE.md, plugins, skills, hooks, MCP servers) for a clean troubleshooting environment without a full reinstall (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **`disableBundledSkills` setting and `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` env var** — Hides all built-in bundled skills, workflows, and slash commands, useful for organisations that want only their own skills visible (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **CLAUDE.md "too long" warning scales with model context window** — The warning threshold now adjusts dynamically based on the active model's context size rather than a fixed line count (v2.1.169). (Source: https://code.claude.com/docs/en/changelog)
- **Claude Fable 5 launched** — Launched June 9, 2026 as Anthropic's most capable widely-released model. State-of-the-art on nearly all benchmarks across software engineering, knowledge work, vision, and scientific research. 1M token context window by default, 128k max output tokens, always-on adaptive thinking. Priced at $10/$50 per MTok. Model ID: `claude-fable-5`. (Source: https://www.anthropic.com/news/claude-fable-5-mythos-5)
- **Claude Mythos 5 launched** — Restricted-access companion to Fable 5, launched June 9, 2026 for Project Glasswing participants. Same underlying architecture with safeguards lifted in certain areas; described as having the strongest cybersecurity capabilities of any available model. Model ID: `claude-mythos-5`. Priced at $10/$50 per MTok. (Source: https://www.anthropic.com/news/claude-fable-5-mythos-5)
- **Fable 5 / Mythos 5 new tokenizer produces ~30% more tokens** — Claude Fable 5 and Mythos 5 use the tokenizer introduced with Opus 4.7; the same text produces roughly 30% more tokens compared to models released before Opus 4.7. Use the token counting API with `model: "claude-fable-5"` to measure prompts before migrating. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Claude Fable 5 requires 30-day data retention** — Fable 5 is not available under zero data retention; API requests must accept a 30-day retention policy. Only model with this requirement as of June 2026. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **Workflow keyword trigger setting in /config** — New setting in `/config` prevents the word "workflow" in a prompt from unintentionally launching a dynamic workflow. Backspace pressed immediately after a workflow trigger now dismisses the workflow request (same as alt+w) instead of deleting a character (v2.1.169). (Source: https://releasebot.io/updates/anthropic/claude-code)
- **Sub-agents can spawn nested sub-agents up to 5 levels deep** — In v2.1.172 (June 10, 2026), Claude Code sub-agents gained the ability to recursively spawn their own sub-agents, up to 5 levels of nesting. Enables more sophisticated multi-agent hierarchies without manual orchestration. (Source: https://github.com/anthropics/claude-code/releases)
- **Fable 5 / Mythos 5: adaptive thinking only, `thinking: disabled` not supported** — On Claude Fable 5 and Claude Mythos 5, adaptive thinking is the sole thinking mode. Setting `thinking: {"type": "disabled"}` returns a 400 error, as do manual extended thinking budgets and assistant prefill. Pass thinking blocks back unchanged in multi-turn conversations; set `display: "summarized"` to receive readable thinking summaries. (Source: https://platform.claude.com/docs/en/release-notes/overview)
- **`enforceAvailableModels` managed setting** — When enabled, the `availableModels` allowlist also constrains the Default model (a Default that would resolve to a disallowed model falls back to the first allowed model), and user or project settings can no longer widen a managed `availableModels` list. Useful for organisations enforcing model governance across workspaces (v2.1.175, June 12, 2026). (Source: https://code.claude.com/docs/en/changelog)
- **`wheelScrollAccelerationEnabled` setting** — New setting to disable mouse-wheel scroll acceleration in fullscreen mode; useful if you find the acceleration jarring in the TUI renderer (v2.1.174). (Source: https://github.com/anthropics/claude-code/releases)
- **Session titles in conversation language** — Session titles are now generated in the language of your conversation. Set the `language` setting to pin a specific language (v2.1.176). (Source: https://github.com/anthropics/claude-code/releases)
- **`footerLinksRegexes` setting** — Add regex-matched link badges to the footer row; configurable in user or managed settings for quick navigation to related docs or dashboards (v2.1.176). (Source: https://github.com/anthropics/claude-code/releases)
- **Nested `.claude/skills` directories auto-load** — Skills inside nested `.claude/skills` directories now load automatically when working on files in that directory. On name clash, the nested skill appears as `<dir>:<name>` to disambiguate from the parent-level skill (v2.1.178). (Source: https://code.claude.com/docs/en/changelog)
- **Nearest `.claude/` directory wins on name collision** — For agents, workflows, and output styles, the `.claude/` directory closest to the current working directory takes precedence on name collision; project-scope workflow saves target the closest existing `.claude/workflows/` (v2.1.178). (Source: https://code.claude.com/docs/en/changelog)
- **Auto Mode pre-launch classifier for subagents** — Auto Mode now evaluates each subagent spawn through the classifier before the subagent launches, catching risky delegations earlier in the pipeline rather than only after the child agent starts running (v2.1.178). (Source: https://code.claude.com/docs/en/changelog)
- **Workflow keyword requires explicit phrase to trigger** — The dynamic workflow trigger now fires only on explicit phrases like "run a workflow" or "workflow:" rather than the keyword alone, reducing accidental workflow launches while composing prompts. Highlight colour changed from violet to purple shimmer (v2.1.178). (Source: https://code.claude.com/docs/en/changelog)
- **Claude Code v2.1.179 stability release** — Released June 16, 2026. Key fixes: partial responses now preserved on mid-stream connection drops instead of showing raw errors; WSL2 mouse-wheel scroll regression (introduced in v2.1.172) fixed in Windows Terminal and VS Code; Linux sandbox `denyRead`/`allowRead` glob patterns over large directory trees no longer cause enormous Bash tool descriptions and unusable sessions; Ctrl+O now correctly shows subagent transcripts; remote session background tasks no longer appear stuck between turns. (Source: https://code.claude.com/docs/en/changelog)
- **Claude Dreaming for Managed Agents** — Asynchronous process that reviews past agent session transcripts alongside a memory store, merges duplicates, replaces stale entries, and surfaces new insights into a reorganised memory store. Accepts 1–100 past sessions per run; can update memory automatically or hold changes pending your review. Launched at Code with Claude 2026 (May 6) as a research preview. Harvey legal reported a ~6× jump in agent task-completion rates after enabling Dreaming for drafting workflows. (Source: https://platform.claude.com/docs/en/managed-agents/dreams)
- **Claude Code v2.1.181 release** — Released June 17, 2026. New features: `/config key=value` syntax sets settings from the prompt bar; `sandbox.allowAppleEvents` enables macOS Apple Events in sandboxed commands; `CLAUDE_CLIENT_PRESENCE_FILE` suppresses mobile push notifications while at the machine. Improvements: idle subagents auto-hide after 30s in the subagent panel; MCP OAuth browser page auto-closes on success; fullscreen URL opening now requires Cmd+click (macOS) / Ctrl+click. (Source: https://github.com/anthropics/claude-code/releases)
- **Auto mode safety guardrails for destructive commands** — In v2.1.183 (June 19, 2026), auto mode blocks destructive git commands when you didn't ask to discard work (`git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop`) and blocks `git commit --amend` when the commit was not made by the agent in the current session. Infrastructure-destroying commands (`terraform destroy`, `pulumi destroy`, `cdk destroy`) are also blocked unless explicitly requested. (Source: https://code.claude.com/docs/en/changelog)
- **Stream-stall detection threshold extended to 20s** — In v2.1.185 (June 20, 2026), the hint that appears during API silence changed from "No response from API · Retrying in …" to "Waiting for API response · will retry in …", and the silence threshold before the hint appears was extended from 10s to 20s, reducing false-alarm interruptions on slow responses. (Source: https://code.claude.com/docs/en/changelog)
- **Model deprecation warnings in headless mode** — Claude Code v2.1.183 emits a warning on stderr in print mode (`-p`) and in agent frontmatter when the requested model is deprecated or has been automatically updated to a newer version, making model-migration issues visible in CI pipelines and scripts. (Source: https://code.claude.com/docs/en/changelog)
- **`attribution.sessionUrl` setting** — New setting that controls whether the claude.ai session link is included in commits and PRs. Useful in web and Remote Control sessions where the session URL is ephemeral and the link would be meaningless in the git log (v2.1.183). (Source: https://code.claude.com/docs/en/changelog)
- **`!` bash commands trigger automatic Claude responses** — In v2.1.186 (June 22, 2026), running a `! <command>` shell command automatically feeds the output back to Claude as a follow-up. Disable with `"respondToBashCommands": false` in settings if you prefer manual control. (Source: https://github.com/anthropics/claude-code/releases)
- **Safer automatic edits in `acceptEdits` mode** — Claude Code now prompts for confirmation before writing files that can execute code (scripts, Makefiles, CI configs) when running in `acceptEdits` mode, preventing silent execution-ready changes (Week 23, v2.1.158–v2.1.165). (Source: https://code.claude.com/docs/en/whats-new)
- **Managed deployment version requirements** — Managed Claude Code deployments can now declare an approved version range (`requiredMinVersion` / `requiredMaxVersion`) so enterprise admins can pin users to validated releases and prevent unreviewed client updates (Week 23, v2.1.158–v2.1.165). (Source: https://code.claude.com/docs/en/whats-new)
- **Skills section in `/plugin` Installed tab** — The `/plugin` Installed tab now surfaces a dedicated Skills section, making it easy to see which skills are loaded alongside full plugins without listing them separately (v2.1.186). (Source: https://github.com/anthropics/claude-code/releases)
- **Artifacts in Claude Code (beta)** — Sessions can generate shareable, live-updating web pages (incident reports, PR walkthroughs, dashboards) directly from a Claude Code session. Content is private to the organisation with version history and access controls. Announced June 2026. (Source: https://releasebot.io/updates/anthropic)
